# تلخيص الدروس العربية

حوّل الدرس إلى ملاحظات عربية أمينة ومنظمة تحافظ على ترتيب الأفكار والتفاصيل اللازمة للفهم. اقرأ [مرجع التلخيص](references/summary-workflow.md) عند إعداد المخرجات.

## اختيار مسار المادة

- إذا قدّم المستخدم تفريغًا، استخدمه مع بيان مصدره وحدود دقته. إذا لم يتوفر تفريغ وكان مصدر الفيديو أو الصوت متاحًا، استخرج ما يلزم لفهمه. عند الحاجة إلى خطوات استخراج النص، اتبع [مهارة التفريغ العربية](../arabic-media-transcription/SKILL.md)، لكن لا تُسلّم ملف تفريغ كاملًا لمجرد إعداد الملخص.
- إذا طلب المستخدم التفريغ والملخص معًا، استخدم المهارتين وقدّم ملف تفريغ منفصلًا وملف ملخص منفصلًا. لا تكرر التفريغ الكامل داخل الملخص.
- فعّل وضع الإيجاز تلقائيًا عند طلب الاختصار أو السرعة أو صيغة موجزة: ملاحظة درس واحدة، بلا ملفات أجزاء أو فهرس أو اختبار أو خطة أو ملف مجمّع منفصل إلا إذا طلب المستخدم ملفًا بعينه.

## قواعد أساسية

- حافظ على تسلسل المحاضرة ومعناها، واستخرج المعلومات دون اختراع أو نسبة كلام إلى غير مصدره. اعرض كل معلومة في الملخص مرة واحدة في موضعها الأنسب.
- لا تخترع توقيتات أو كلمات غير مسموعة أو نتائج تشغيل. اذكر المصدر والحدود، وميّز ما تحققت منه عمّا لم تتحقق منه.
- لا تحفظ بيانات الحساب أو عناوين البريد أو كلمات المرور أو مفاتيح API أو أي أسرار داخل الملخص أو ملفات المهارة.
- اكتب بالعربية أولًا مع المصطلحات التقنية بالإنجليزية وشرح معناها بالعربية. راعِ RTL (اتجاه الكتابة من اليمين إلى اليسار) في الفقرات والقوائم والاقتباسات والجداول.
- لا تنشئ ملفات مراجعة داخلية. لا تنفّذ `commit` (تسجيل تغييرات Git) أو `push` (رفعها إلى المستودع) تلقائيًا كجزء من إعداد الملخص؛ افعل ذلك فقط إذا طلبه المستخدم صراحةً في المهمة الحالية. أخبره بالعربية بما أُنشئ وأين، وبأي قيد أو تحقق فعلي.
