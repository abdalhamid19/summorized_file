# تفريغ الفيديو والصوت بالعربية

استخدم هذه المهارة عندما يكون المطلوب تفريغ الكلام أو الحصول على نص موثوق لفهم الدرس. اقرأ [مرجع سير عمل التفريغ](references/transcription-workflow.md) عند الحاجة إلى استخراج النص أو إعداده للتسليم.

## حدود المخرج

- لا تُسلّم تفريغًا كاملًا لمجرد أن المستخدم طلب ملخصًا. أنشئ ملف التفريغ عندما يطلبه المستخدم أو يوجبه سير العمل المحدد للمهمة.
- إذا طلب المستخدم التفريغ وحده، فسلّم التفريغ فقط؛ لا تضف ملخصًا لم يطلبه.
- إذا طلب المستخدم التفريغ والملخص معًا، أنشئ ملف تفريغ مستقلًا وملف ملخص مستقلًا. استخدم [مهارة التلخيص العربية](../arabic-media-summary/SKILL.md) للملخص.
- لا تحوّل إعادة الصياغة أو ناتج التعرّف الآلي على الكلام (ASR) إلى نص حرفي منسوب للمتحدث. سمِّ نوع النص ومصدره وحدود التحقق بوضوح.

## قواعد أساسية

- افترض صلاحية المستخدم لمعالجة الفيديو أو التسجيل الذي أرسله مباشرة؛ لا تطلب إثبات ملكية. لا تتجاوز تسجيل الدخول أو قيود المنصة، ولا تطلب بيانات الدخول، ولا تقبل شروطًا جديدة أو تبدأ دفعًا نيابةً عنه.
- لا تحفظ بيانات الحساب أو عناوين البريد أو كلمات المرور أو مفاتيح API أو أي أسرار داخل التفريغ أو ملفات المهارة.
- حافظ على ترتيب الكلام ومعناه. لا تخمّن الكلمات أو التوقيتات؛ علّم المواضع غير الواضحة واستخدم مرجعًا نصيًا إذا لم يتوفر توقيت يمكن التحقق منه.
- ابدأ بالعربية في العناوين والتوضيحات والجداول التي تضيفها لمراعاة RTL (اتجاه الكتابة من اليمين إلى اليسار). لا تغيّر نص المتحدث الحرفي لمجرد ضبط اتجاهه.
- لا تدّعِ مراجعة التفريغ كاملًا أو مطابقته كلمةً كلمة إلا إذا قارنت النص كاملًا بالمصدر.
- عند إنشاء ملف، اذكر رابط المصدر وطريقة الحصول على النص وحدود دقته، وأضف سجل زمن الخطوات المقاس وفق المرجع. اجعل صندوق «المصدر» آخر المحتوى.
- لا تنفّذ `commit` (تسجيل تغييرات Git) أو `push` (رفعها إلى المستودع) تلقائيًا ضمن مهمة التفريغ؛ افعل ذلك فقط إذا طلبه المستخدم صراحةً في المهمة الحالية. أخبره بالعربية بما أُنشئ وأين، وبأي قيد أو تحقق فعلي.
