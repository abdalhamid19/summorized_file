# أتمتة Firefox والحاويات باستخدام Selenium

توجّه هذه المهارة مهام Firefox التي تتطلب Selenium (واجهة أتمتة المتصفح) وgeckodriver (وسيط WebDriver الخاص بـFirefox)، خصوصًا عند فتح التبويبات أو التحقق منها داخل Multi-Account Containers (حاويات تفصل ملفات الارتباط بين هويات التصفح).

## سير العمل

1. افحص الإصدارات، والملف الشخصي المطلوب، وما إذا كان Firefox يستخدمه الآن. لا تفترض أن Selenium يستطيع الاتصال بأي نافذة Firefox مفتوحة. لا تُنهِ عملية Firefox بالقوة؛ اطلب إغلاق الجلسة التي تستخدم الملف الشخصي أو استخدم ملفًا مخصصًا منفصلًا.
2. استخدم Selenium Manager (مدير التعريفات المضمّن مع Selenium) لاكتشاف geckodriver ما لم توجد مشكلة محددة تستدعي مسارًا يدويًا. راجع [أفضل الممارسات](references/selenium-best-practices.md).
3. استخدم WebDriver في content context (سياق محتوى صفحة الويب) للتنقل والتفاعل مع المواقع. لا تستخدم execute_script لاستدعاء browser.contextualIdentities؛ هذه واجهة إضافة Firefox وليست كائنًا متاحًا لصفحة الويب.
4. عند فتح حاوية، استخدم إضافة Firefox محلية موثوقة تتعامل مع واجهات contextualIdentities وtabs الرسمية. ابحث عن الحاوية باسمها وقت التشغيل، ثم افتح التبويب باستخدام cookieStoreId الحالي. إذا احتاج Selenium إلى إرسال أوامر للإضافة، استخدم قناة محلية واضحة مثل Native Messaging (رسائل بين الإضافة وبرنامج محلي)، ولا تفتح واجهة تحكم غير محمية على الشبكة. اقرأ [دليل الحاويات](references/firefox-containers.md).
5. لا تعتبر نجاح أمر فتح التبويب إثباتًا. تحقّق من الرابط الحالي، ومن أن التبويب نفسه مرتبط بمخزن الحاوية المقصود عبر الإضافة أو واجهتها. لا تستخدم رقم الحاوية وحده للتحقق.
6. استخدم chrome context (سياق واجهة Firefox الداخلية) كخيار احتياطي فقط إذا تعذّر مسار الإضافة وكان المطلوب يستلزم التحكم بواجهة المتصفح. اشرح أن --allow-system-access يعطي WebDriver صلاحيات مرتفعة، وتحقق من توافق الإصدارات قبل تشغيله.
7. استخدم WebDriverWait (انتظار صريح لشرط محدد) بدل فترات النوم الثابتة، وأنهِ جلسة Selenium التي بدأتها بـ driver.quit() داخل finally.
8. إذا ظهرت صفحة تحقق بشري أو CAPTCHA (اختبار يميّز الإنسان من البرنامج)، أو رفض مزود الخدمة جلسة الأتمتة، أوقف الأتمتة عندها واترك الخطوة للمستخدم. لا تستخدم التخفي أو حل CAPTCHA أو تجاوز حماية تسجيل الدخول.

## الخصوصية والسلامة

- استخدم ملف Firefox مخصصًا أو الملف الذي حدده المستخدم صراحة. الملف الشخصي يحفظ الجلسات وملفات الارتباط؛ لا تنسخه إلى المستودع ولا تكتب أسراره في السجلات أو لقطات الشاشة.
- لا تشغّل Firefox العادي وSelenium على الملف الشخصي نفسه بالتزامن. لا تدّعِ أن ملفًا مؤقتًا يحافظ على تسجيل الدخول بعد انتهاء الجلسة.
- راجع مصدر أي إضافة قبل تثبيتها. اطلب أقل الصلاحيات اللازمة؛ cookies (صلاحية ملفات الارتباط) حساسة لأنها مطلوبة عند فتح تبويب عبر cookieStoreId، وقد تتيح للإضافة التعامل مع جلسات المواقع. اشرح الصلاحيات قبل التثبيت.
- أبقِ geckodriver محليًا على 127.0.0.1 (عنوان الجهاز نفسه). لا تفتح منفذه على الشبكة ولا تسمح بمصادر Origin (الموقع الذي أرسل الطلب) إضافية بلا سبب واضح.
- لا تحفظ كلمات المرور أو رموز التحقق في السكربت أو الملفات أو المخرجات. دع المستخدم يكمل تسجيل الدخول يدويًا.
