## الأسباب المحتملة لفشل الاستخراج

### 1️⃣ **حظر IP (السبب الأكثر احتمالاً)**

**الأعراض:**
- رسالة خطأ: `RequestBlocked` من `youtube_transcript_api`
- جربتُ الأداة فعلياً على الفيديو وحصلتُ على هذا الخطأ مباشرة

**التفاصيل:**
- يوتيوب يحظر الطلبات الآلية من عناوين IP الخاصة بمزودي الخدمات السحابية (AWS, Google Cloud, Azure, Vercel, إلخ)
- قد يحظر أيضاً IP المنزل بعد عدة طلبات متتالية
- عند معالجة قوائم تشغيل كاملة، يزداد احتمال الحظر

**متى يحدث:**
- عند استخراج ترجمات متعددة بتتابع سريع
- من بيئات سحابية (الخادم يقع في data center)
- بدون تأخير/throttling بين الطلبات

---

### 2️⃣ **الفيديو بلا ترجمات أصلاً**

**الأعراض:**
- الأداة تعيد `None` أو `"Subtitles may be disabled or unavailable"`
- حتى عند الدخول اليدوي للفيديو، خيار "إظهار النص" لا يظهر

**التفاصيل:**
- بعض فيديوهات المحاضرات العربية بلا ترجمات تلقائية
- صاحب القناة قد يعطّل الترجمات التلقائية
- يوتيوب قد لا يولّد ترجمات لبعض اللغات/المحتوى

**التحقق اليدوي:**
1. افتح الفيديو على يوتيوب
2. اضغط الثلاث نقاط (`...`)
3. اختر "إظهار النص" (Show transcript)
4. إذا لم يظهر الخيار ← الفيديو بلا ترجمات

  - ❌ "معرف الفيديو غير صحيح"
- كل الحالات تعيد نفس الرسالة العامة

## الحلول المقترحة (مرتبة بالأولوية)

### ✅ الحل 1: استخدام Residential Proxy (الأفضل)

**الفكرة:** استخدام proxies من IP سكنية حقيقية بدلاً من data center IPs

[[residential proxy]]

**المميزات:**
- يوتيوب لا يحظر residential IPs بسهولة
- حل دائم وموثوق

**العيوب:**
- تكلفة مالية (خدمات مدفوعة)
- بطء قليل (routing عبر proxies)

**التطبيق:**
```python
proxy = "http://user:pass@residential-proxy-ip:port"
requests.get(url, proxies={"http": proxy, "https": proxy})
```

**الخدمات المشهورة:**
- Oxylabs
- BrightData
- Smartproxy
- ProxyMesh

---

### ✅ الحل 2: استخدام Browser Cookies

**الفكرة:** تمرير كوكيز المتصفح إلى `yt-dlp` لتجاوز كشف الروبوتات

**المميزات:**
- مجاني
- أسرع من الـ proxies

**التطبيق:**
```bash
# تصدير الكوكيز من Chrome
yt-dlp --cookies-from-browser chrome \
       --skip-download --write-auto-sub \
       -o "subs" "https://www.youtube.com/watch?v=rMORt-RUisY"
```

**الخطوات:**
1. ثبّت متصفح Chrome
2. سجّل دخولك إلى يوتيوب يدوياً في Chrome
3. استخدم `--cookies-from-browser chrome` في yt-dlp

---

### ✅ الحل 3: تهدئة الطلبات (Throttling)

**الفكرة:** إضافة تأخير بين الطلبات المتتالية

**المميزات:**
- مجاني وبسيط
- يقلّل احتمال الحظر

**المشاكل:**
- يزيد وقت المعالجة بشكل كبير

**التطبيق:**
```python
import time
for video_id in video_ids:
    result = extract_transcript(video_id)
    time.sleep(5)  # انتظر 5 ثواني بين الطلبات
```

**التوصيات:**
- للقوائم الصغيرة (< 10 فيديوهات): 3-5 ثواني
- للقوائم الكبيرة (> 50 فيديوهات): 10+ ثواني أو استخدم proxies

### ✅ الحل 4: تحسين رسائل الخطأ في الأداة

**الفكرة:** استخراج الخطأ الفعلي وعرضه للمستخدم

**التطبيق:**
```python
def extract_transcript(video_id):
    try:
        # حاول استخراج الترجمات
        return YouTubeTranscriptApi.get_transcript(video_id)
    except TranscriptsDisabled:
        return {"error": "ترجمات معطّلة من قبل صاحب القناة"}
    except NoTranscriptFound:
        return {"error": "لا توجد ترجمات لهذا الفيديو"}
    except RequestBlocked:
        return {"error": "يوتيوب حظر هذا الطلب - جرّب proxy أو انتظر قليلاً"}
    except Exception as e:
        return {"error": f"خطأ غير معروف: {type(e).__name__}: {str(e)[:200]}"}
```

**الفوائد:**
- تشخيص أسرع للمشاكل
- توجيه المستخدم لحل مناسب
- تسهيل تصحيح الأخطاء

### ✅ الحل 5: مسار احتياطي باستخدام Whisper

**الفكرة:** إذا فشل استخراج الترجمات، استخدم OpenAI Whisper لتحويل الصوت إلى نص

**المميزات:**
- يعمل حتى لو لا ترجمات على يوتيوب
- يدعم اللغات المتعددة

**المشاكل:**
- أبطأ بكثير (تحميل + معالجة الصوت)
- قد يكون غير دقيق 100%
- تكلفة API (عند استخدام OpenAI)

**التطبيق:**
```python
def extract_transcript(video_id):
    # محاولة 1: استخراج الترجمات من يوتيوب
    try:
        return YouTubeTranscriptApi.get_transcript(video_id)
    except Exception as yt_error:
        print(f"فشل: {yt_error}")
    
    # محاولة 2: استخدام Whisper
    print("يحاول استخراج الصوت وتحويله باستخدام Whisper...")
    audio_path = download_audio(video_id)
    transcript = whisper.transcribe(audio_path, language="ar")
```

## المسار المقترح للحل الفوري

بناءً على نتائج الاختبار الفعلي:

1. **الخطوة 1:** جرّب [[residential proxy]] أو cookies-from-browser
   - إذا نجح ← استخدم هذا كحل دائم
   
2. **الخطوة 2:** إذا فشل الاثنان ← تأكد من:
   - هل الفيديو نفسه يحتوي ترجمات؟ (تحقق يدوياً)
   - هل المعرف الصحيح يُستخرج؟ (افحص URL مع قائمة التشغيل)

3. **الخطوة 3:** حسّن رسائل الخطأ في الكود (الحل 4)
   - سيساعدك تشخيص أسرع في المستقبل

4. **الخطوة 4:** (اختياري) أضف مسار Whisper احتياطي
   - للفيديوهات النادرة بلا ترجمات
