# 📜 دليل وشرح آلية عمل مشروع استخراج تفريغ يوتيوب (`yt_transcript_extractor`)

## 1. 🌟 نبذة عن المشروع والأهداف
مشروع **`yt_transcript_extractor`** هو مكتبة وأداة سطر برمجية (CLI) مكتوبة بلغة Python، مُصممة لاستخراج التفاريغ النصية (Transcripts & Subtitles) لمقاطع فيديو YouTube بكفاءة واستقرار عاليين.

### الأهداف الرئيسية:
1. **الاعتمادية العالية (High Reliability):** توفير آلية سحب احتياطية (**Fallback Mechanism**) تضمن الحصول على التفريغ حتى في حال حجب أو فشل الـ API المباشر.
2. **التكامل مع Obsidian والذكاء الاصطناعي:** تحويل التفاريغ إلى صيغ متعددة أبرزها Markdown مع التوقيتات الزمنيّة لربطها بملفات التلخيص داخل **Obsidian Vault**.
3. **الدعم متعدد اللغات:** دعم اللغات العربية والإنجليزية وغيرها تلقائياً واستخراج الترجمات البشرية والآلية.

---

## 2. 🏗️ الهيكلية البرمجية للمشروع (Architecture)

يتكون المشروع من أربعة مكونات رئيسية متميزة باتباع مبدأ المسؤولية الواحدة (**Single Responsibility Principle - SRP**):

```
yt_transcript_extractor/
├── yt_transcript_extractor/
│   ├── __init__.py       # تصدير الفئات الرئيسية
│   ├── extractor.py      # النواة الرئيسية وآلية الاستخراج والـ Fallback
│   ├── formatters.py     # محول صيغ التصدير (TXT, JSON, SRT, MD)
│   ├── utils.py          # أدوات تنظيف روابط يوتيوب ومعالجة التوقيتات
│   └── cli.py            # واجهة السطر البرمجي (Command-Line Interface)
└── tests/
    └── test_extractor.py # اختبارات الأداء الموحدة (Unit Tests)
```

## 3. ⚙️ كيف تعمل آلية الاستخراج المزدوجة (Extraction Pipeline)

يعتمد المحرك الرئيسي في `extractor.py` على استراتيجية محاولة واستجابة تضمن عدم التوقف (**Fail-Safe Strategy**):

```
                       ┌────────────────────────┐
                       │  إدخال الرابط / ID     │
                       └───────────┬────────────┘
                                   ▼
                       ┌────────────────────────┐
                       │   extract_video_id()   │
                       └───────────┬────────────┘
                                   ▼
                       ┌────────────────────────┐
                       │  المحاولة 1: API المباشر │
                       │  YouTubeTranscriptApi  │
                       └───────────┬────────────┘
                                   │
                     ┌─────────────┴─────────────┐
                     │                           │
              [نجاح الاستخراج]             [فشل / حجب API]
                     │                           │
                     ▼                           ▼
        ┌────────────────────────┐  ┌────────────────────────┐
        │ Normalization & Return │  │  المحاولة 2: Fallback   │
        └────────────────────────┘  │      yt-dlp JSON3      │
                                    └───────────┬────────────┘
                                                │
                                  ┌─────────────┴─────────────┐
                                  │                           │
                           [نجاح Extraction]           [فشل تام]
                                  │                           │
                                  ▼                           ▼
                     ┌────────────────────────┐  ┌────────────────────────┐
                     │ Parse Events & Clean   │  │   RuntimeError Exception│
                     └────────────────────────┘  └────────────────────────┘
```

### خطوات العمل بالتفصيل:

#### 1️⃣ معالجة المعرفات وتجهيز الرابط (`utils.py` & `extractor.py`):
- يقوم التابع `extract_video_id` بمسح المدخلات عبر تعبيرات نمطية (Regex) لاستخراج معرّف يوتيوب المكون من 11 حرفاً، سواءً كان المدخل رابطاً كاملاً (`youtube.com/watch?v=...`) أو رابطاً مصغراً (`youtu.be/...`) أو مقطع Shorts أو معرفاً مجرداً.

#### 2️⃣ محاولة الاستخراج السريعة عبر API (`_get_transcript_via_api`):
- يحاول النظام أولاً استخدام مكتبة `youtube-transcript-api` المباشرة.
- يتم إرسال طلب لقائمة اللغات المتاحة واختيار أفضل لغة مطابقة وفق تفضيلات اللغة (الافتراضية: العربية `ar` ثم الإنجليزية `en-US`, `en`).
- في حال توفر التفريغ، يتم تحويل الاستجابة إلى هيكل قاموس موحد يحتوي على:
  - `text`: النص المفرغ.
  - `start`: بداية المقطع بالثواني.
  - `duration`: مدة ظهور النص بالثواني.

#### 3️⃣ آلية السحب الاحتياطي عبر `yt-dlp` (`_fetch_via_ytdlp`):
- في حال حدوث خطأ أو حجب (مثل IP block) في المكتبة المباشرة، تنتقل الأداة تلقائياً إلى الاستدعاء الفرعي (`subprocess`) لمكتبة `yt-dlp`.
- تُرسل الأداة خيارات استخراج التسميات التوضيحية دون تحميل الفيديو بالكامل (`--skip-download --write-sub --write-auto-sub --sub-format json3`).
- يتم تحليل ملف الأحداث `json3` وتفكيك الفقرات وتجميع النصوص مع تحويل التوقيتات الملي-ثانية إلى ثوانٍ.
- يُنفذ التابع `_cleanup_temp_files` مسحاً آلياً ونهائياً لجميع الملفات المؤقتة التي أنشأتها `yt-dlp` للحفاظ على نظافة النظام.

## 4. 📄 صيغ التصدير والتحويل (`formatters.py`)

تتيح فئة `TranscriptFormatter` تحويل التفريغ الموحد إلى 4 صيغ أساسية:

1. **Markdown (`md`):**
   - مُصممة بأسلوب عصري ومتوافق مع **Obsidian Vault**.
   - تتضمن الترويسة الرئيسية، رابط الفيديو الشغال، اللغة، عدد المقاطع النصية، وقائمة منسقة بالتوقيتات الزمنيّة مثل: `- **[01:25]** النص المفرغ`.
2. **SubRip Subtitles (`srt`):**
   - صيغة الترجمة القياسية المتوافقة مع مشغلات الفيديو والبرامج والمُقسمة بأرقام الفقرات والتوقيتات الدقيقة (`HH:MM:SS,mmm --> HH:MM:SS,mmm`).
3. **JSON (`json`):**
   - صيغة بيانات مهيكلة تشمل بيانات الميتا المتقدمة (العنوان، المعرف، الرابط، عدد المقاطع) بالإضافة إلى مصفوفة التفاريغ الكاملة.
4. **Plain Text (`txt`):**
   - ملف نصي مبسط ومقروء يحتوي على التوقيتات وبداية المقطع والنص الصريح مناسب للقراءة السريعة.

## 5. 💻 طرق الاستخدام والتنفيذ (Usage Guide)

### أولاً: الاستخدام البرمجي داخل Python (Code Library)
```python
from yt_transcript_extractor.extractor import YouTubeTranscriptExtractor
from yt_transcript_extractor.formatters import TranscriptFormatter

# 1. إنشاء الكائن مع إعطاء رابط الفيديو أو المعرف
extractor = YouTubeTranscriptExtractor("https://www.youtube.com/watch?v=dQw4w9WgXcQ")

# 2. جلب التفريغ النصي (باللغة العربية أو الإنجليزية)
transcript_data = extractor.get_transcript(preferred_languages=["ar", "en"])

# 3. جلب البيانات الوصفية للفيديو
metadata = extractor.fetch_metadata()

# 4. تنسيق النتيجة إلى Markdown
markdown_output = TranscriptFormatter.format(
    fmt="md",
    transcript=transcript_data,
    title=metadata.get("title", ""),
    video_id=extractor.video_id
)

print(markdown_output)
```

### ثانياً: الاستخدام عبر السطر البرمجي (CLI)
```bash
# استخراج التفريغ بصيغة Markdown وحفظه في المجلد المحدد
python -m yt_transcript_extractor.cli "https://www.youtube.com/watch?v=VIDEO_ID" --format md --output output/

# استخراج التفريغ باللغة العربية بصيغة SRT
python -m yt_transcript_extractor.cli "VIDEO_ID" --lang ar --format srt -o output/subtitles.srt
```

## 6. 🔗 التكامل مع Obsidian والذكاء الاصطناعي (Obsidian & AI Integration)

يرتبط هذا المشروع بشكل مباشر مع نظام الملاحظات والتأملات في **Obsidian Vault** عبر الميزات التالية:

1. **الربط مع تلقينات التلخيص (Summarization Prompts):**
   - بعد استخراج ملف الـ Markdown المنظم من يوتيوب، يتم تمريره إلى التلقينات المعالجة في مجلد `main_obsidian/prompt/summarized_video_and_audio/` (مثل التلقينة العلمية والشرعية).
2. **الروابط الداخلية (Internal WikiLinks):**
   - مخرجات التفريغ تُسهل الربط المباشر مع المفاهيم والموضوعات الأخرى بداخل Obsidian باستخدام وسوم مثل `[[اسم المفهوم]]`.
3. **تكامل المهارات (Agent Skills Integration):**
   - مشروع التلخيص يستفيد من المهارات المثبتة (`baoyu-youtube-transcript`, `summarize`, `openai-whisper`, `obsidian-markdown`) لمعالجة وتنظيم واستخراج النصوص بسرعة وجودة عالية.
