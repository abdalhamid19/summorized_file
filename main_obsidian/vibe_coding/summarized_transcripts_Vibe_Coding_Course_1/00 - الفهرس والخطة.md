## ما يجب أن يبقى في الذهن

1. الكورس على YouTube مجاني؛ الأدوات المدفوعة والدعم على School والـ Code نفسه ليست مجانية بالكامل.
2. Vibe Coder لا يحتاج كتابة الـ Code بيده؛ يحتاج ست مهارات: رؤية، عقلية Business، اكتشاف الـ Bug، VS Code+GitHub، Docker، قشور إدارة الـ Server.
3. أهم مفهوم معماري ذكره المصدر: [[Headless]] = فصل الـ Frontend عن الـ Backend عبر API أو GraphQL.
4. اختيار Framework يتبع استراتيجية Rendering لا العكس.
5. عند غياب التوقيتات استُخدمت أرقام الأسطر فقط، ولم تُختلق أي دقائق أو ثوانٍ.
