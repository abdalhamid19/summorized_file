# 03 - المفاهيم: Frontend وBackend وHeadless

## الخلاصة العلمية المنظمة

- Vibe Coding **لا يحتاج فهم لغات البرمجة ولا كيف يُكتب الـ Code**؛ الذكاء الاصطناعي يكتب الـ Code ويحل المشاكل. المطلوب: فهم **كل لغة تُستعمل في ماذا**، ومميزاتها، والمفاهيم المستخدمة وأنت تعمل الـ Application.

### أهم مفهوم: Frontend / Backend / Headless

| المصطلح | التعريف كما ورد |
|---|---|
| [[Frontend]] | واجهة ما يراه المستخدم. في هذا الكورس: نظام JavaScript. |
| [[Backend]] | دائمًا: قاعدة بيانات + API + بحث. عند المبرمجين «كله API». |
| [[Headless]] | Frontend في ناحية وBackend في ناحية، ويرتبطان عبر [[API]] أو [[GraphQL]]. |

- مدرسة WordPress (ومنها المتحدث) تظن WordPress Backend و Frontend معًا، وهو كذلك. نظام Headless — من سنة 2021 — يقول: **افصل الاثنين**. إن حصلت مشكلة في الـ Frontend تغيّره مع الحفاظ على الـ Backend، والعكس. إن كان الـ Business كله على Core واحد تُعاد برمجة كل شيء من الصفر.

### مزايا Headless كما ذكرها المصدر

1. **تغيير أحد الطرفين دون الآخر.**
2. **Security:** إن كان كل الـ Code على Application واحد يدخل الناس Chrome Console ويأخذون الـ API والبيانات. Headless يمنع ذلك بنظام Proxy ويجعل Security «100%» بحسب عبارته.
3. **السرعة:** Frontend وBackend ليسا شرطًا على Server واحد؛ يمكن نفس Server لكن كل واحد في Stack، وهذا يعطي سرعة قوية للـ Web Application.

يطلب قراءة مميزات Headless على الذكاء الاصطناعي؛ الخلاصة أنه من المفاهيم اللازمة.

### تفصيل Backend في عصر الذكاء الاصطناعي

يفصل المصدر API عن قاعدة البيانات لأن API غالبًا سيكون خاصًا بالذكاء الاصطناعي، وقاعدة البيانات لحفظ بياناته. البحث لأداة فيها بحث أو Marketplace؛ أفضل شيء ذكره اسمًا: **Typesense** (قال إنه لا يريد الدخول في الأسماء الآن، ثم سمّاه).

### Frontend المختار

- لا Ruby on Rails ولا .NET Core ولا اللغات تلك.
- لا PHP؛ لها مشاكلها مع Vibe Coding. Laravel يُذكر كBackend PHP لا يُركَّز عليه هنا.
- التركيز: **JavaScript**. أشهر الFrameworks: Next وAstro وReact وNuxt وVue وRemix وSvelte.
- للمبرمج: «ما أعرفش إلا Next / React / Vue». للVibe Coder: **كلهم واحد**؛ المهم تحقيق الهدف.

مفاهيم يجب فهم أسمائها سريعًا قبل التفصيل: Frontend، Headless، Backend، Database، API، Search، Deployment على **Serverless** أو **Server / Self-hosting container**.
