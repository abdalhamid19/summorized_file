# 12 - ملخص المراجعة السريعة

## جدول المراجعة

| الموضوع | الخلاصة المركزة | الجزء |
|---|---|---|
| اسم المجال | Vibe Coding = برمجة بالذكاء الاصطناعي / برمجة حدثية | 01 |
| المجاني | الفيديو على YouTube مجاني؛ الأدوات والدعم وCode ليست مجانية بالكامل | 01 |
| الست مهارات | رؤية، عقلية Business، اكتشاف الـ Bug، VS Code+GitHub، Docker، قشور الـ Server | 02 |
| Vibe Coder | يحقق الفكرة بلا كتابة الـ Code؛ حتى المطوّر بلا المهارات الست لا يعمل Vibe Coder | 02 |
| Headless | Frontend و Backend منفصلان يرتبطان بـ API أو GraphQL | 03 |
| Backend | API + قاعدة بيانات + بحث (Typesense) | 03، 07 |
| طلب الصفحة | Routing ثم Authentication ثم جلب بيانات ثم Rendering | 04 |
| CSR | Rendering في المتصفح؛ توفير Server؛ ليس SEO | 05 |
| SSR | Rendering على Server؛ SEO؛ يحتاج Serverًا قويًا | 05 |
| SSG | HTML محفوظ ثابت؛ Landing لا يتغير | 05 |
| ISR | HTML مع تعديلات بسيطة عند الطلب/الUpdate | 05 |
| اختيار الـ Framework | على أساس Rendering لا العكس؛ Next أشهر؛ Astro للـ SEO | 05 |
| Serverless Static | Cloudflare Pages حتى 500 زائر/يوم ثم 5 دولار | 06 |
| Serverless Dynamic | Railway المفضّل عنده؛ البعد عن Vercel | 06 |
| Self-host | Docker + Portainer؛ Full Control ومشكلة Security | 06 |
| API | Python + FastAPI + DSPy | 07 |
| Postgres | الأعلى؛ Neon/Supabase/Railway Serverless | 07 |
| Redis | Memory وVector DB معًا | 07 |
| ربط GitHub | Extension Pull Requests + Git for Windows | 08 |
| Hetzner | أرخص؛ يفتح كل الPorts؛ تفعيل حساب | 09 |
| Vultr | أقوى وأغلى؛ لا Verification؛ يقفل الPorts | 09 |
| Portainer | واجهة Docker مجانية؛ Stacks + Volumes | 10 |
| NPM | Port 81؛ Proxy + SSL + WebSocket عند الحاجة | 10 |
| Railway | لا بيانات Server؛ `railway.toml`؛ قوالب Docker بنقرة | 11 |
| هذا الفيديو | بوابة/قشور الجانب الأيمن؛ الجانب الأيسر في الدرس القادم | 11 |
