# 02 - أنواع Web Applications وأربعة أنواع للربح

## 📌 الملخص العلمي

### 1) تعريف [[web applications]]

| العنصر | التعريف |
|--------|---------|
| <span style="color:#0D9488; font-weight:bold;">Web Application</span> | أي برنامج ويب أو موقع إنترنت يتفاعل معه الزائر ليُخرِج بيانات بناءً على طلبه (مثل [[ChatGPT]]، [[Htrfiz]] Search). |
| <span style="color:#0D9488; font-weight:bold;">Static Website</span> | موقع يعرض بيانات ثابتة (موقع شركة، صيدلية، عيادة...). |
| <span style="color:#0D9488; font-weight:bold;">Blog / WordPress</span> | مدوّنة الكاتب فقط هو من يتفاعل، القارئ لا يُنتج بيانات. |

> <span style="color:#D97706; font-weight:bold;">جوهر الـ Web Application:</span> الزائر هو الذي يُحرّك التطبيق ويُخرج البيانات منه.

### 2) أشهر أنواع Web Applications

| النوع | الشرح |
|-------|--------|
| <span style="color:#0D9488; font-weight:bold;">E-commerce / Marketplace</span> | متجر إلكتروني أو سوق يتصفّح المنتجات ويطلب الشراء ([[Amazon]]). |
| <span style="color:#0D9488; font-weight:bold;">Directory</span> | دليل مواقع أو خدمات يتفاعل معه الزائر ويقارن. |
| <span style="color:#0D9488; font-weight:bold;">SaaS Application</span> | خدمة سحابية باشتراك ([[ChatGPT]]، Notion...). |
| <span style="color:#0D9488; font-weight:bold;">Chrome Extension</span> | إضافة للمتصفّح تُقدّم خدمة معيّنة. |

### 3) طرق الربح الأربعة من Web Applications

| الطريقة | الشرح |
|---------|--------|
| <span style="color:#0D9488; font-weight:bold;">Direct Payment</span> | اشتراك مباشر (مدفوع شهريًا، مثل SaaS أو اشتراك E-commerce). |
| <span style="color:#0D9488; font-weight:bold;">Affiliate Marketing</span> | عرض منتجات شركات أخرى وأخذ عمولة عند البيع. |
| <span style="color:#0D9488; font-weight:bold;">AdSense</span> | إعلانات AdSense. يحتاج اليوم أحد الخيارات التالية: Directory، SaaS، أو Chrome Extension (المدوّنات لم تعد تُحقّق دخلًا كافيًا). |
| <span style="color:#0D9488; font-weight:bold;">بيع المنصة</span> | بيع الأداة/المنصة كاملة لمشترٍ مهتم (بعد بناء عدد مستخدمين أو نجاح ملحوظ). |

> 💡 **مثال البيع:** SessionBuddy — إضافة Chrome بسيطة مبنيّة على صفحة WordPress واحدة، عدد مستخدمين مليون، بيعت بمبلغ كبير رغم أنها مجانية 100% (الهدف كان الـ tracking).

## نص المتحدث الكامل

طيب أنواع الـ Web Applications المشهورة هو طبعاً Marketplace أو E-commerce الاتنين واحد، الزائر بيدخل مثلاً على أي E-commerce أو المتجر، المتجر يُعتبر Web Application بيدخل مثلاً يشوف المنتجات اللي عنده إيه وهو اللي بيتفاعل هو اللي بيطلب المنتج ده والمنتج ده عشان كده اسمه Web Application. كذلك الـ Marketplace، كذلك الـ Directory، المواقع المستخدم مثلاً داخل على دليل المواقع برضو حابب إنه يتف... يتفاعل معاه ويبدأ يشوف أو دليل مثلاً أي خدمات أو بشكل عام يبدأ إنه يقارن دي بدي مثلاً فيبدأ إن يحصل interaction بالزائر. كذلك بقى الـ SaaS Application وده اللي هنبدأ نعملها إن شاء الله، الـ SaaS Application يعني خدمة عبارة عن اشتراك أو حاجة، الزائر يبدأ يدخل عليها أو المستخدم يدخل عليها يبدأ إنه زي الـ ChatGPT، ما هو الـ ChatGPT عبارة عن SaaS برضو أو Cloud أو غيرها والحاجات دي كلها عبارة عن SaaS، الزائر يبدأ يدخل يبدأ إنه باشتراك بتاعه وحسب الـ limit بتاعه يبدأ يتفاعل مع الخدمة دي بما بناءً على الباكدج أو الـ limit اللي هو محطّه في الخدمة دي. وأخيراً طبعاً الـ Chrome Extension برضو من أحد الحاجات اللي هي صور الـ Web Application.

طيب إزاي إن أنا أكسب فلوس من الـ Web Application دي؟ عندي أربع حاجات زي ما أنا عندي أربع أنواع. عندي أربع حاجات أقدر أكسب فيها فلوس. أول حاجة ممكن إن أنا أكسب منها Direct Payment، يعني الناس مثلاً فكرة الـ SaaS Application إن الناس هيبدأوا يشتركوا مني مثلاً خدمة الاشتراك في الإعدادات ويبدأ إن هم يدفعوا لي عشان ياخدوا الخدمة دي. طيب كذلك بردو الـ Directory وكذلك الـ E-commerce بيبدأوا يدفعوا لي بشكل مباشر. طيب في برضو Affiliate Marketing، مش شرط إن هم يدفعوا لي بشكل مباشر ممكن يدفعوا لي من خلال الـ Affiliate، يعني أنا مثلاً Affiliate مثلاً لمنتجات معينة لحد لشركة معينة ببدأ إن أنا أعرضها مثلاً في Chrome Extension مثلاً أو في Directory أو في Marketplace، واللي هيشتري عن طريق المنتج ده هبدأ آخذ عمولة من صاحب المنتج. في برضو الـ AdSense، الربح من AdSense برضو إعلانات AdSense. يعني دلوقتي إحنا طبعاً عارفين المدوّنات في النزول بشكل كبير ما حدش عارف بيدخل مدوّنات والموضوع في النازل. فالنهارده عشان تبدأ تشتغل من AdSense، النهارده عشان تكسب ربح من AdSense، فاللي هيجيب معاك يا إما Directory يا إما SaaS يا إما طبعاً Chrome Extension مش مسموح تحط فيها AdSense، فيا إما SaaS Application يا إما Directory تمام، فعشان تكسب من AdSense النهارده محتاج حاجة زي كده.

طيب آخر برضو طريقة إنك ممكن تبيع الـ Platform ده. تمام، يعني لو أنا عاوز مثلاً عامل Platform زي SaaS أو Directory أو أي حاجة، الحاجات دي ممكن تتناع بكل سهولة وتقدر تجيب منها فلوس. يعني لو عملت SaaS مثلاً Application وعملت فيه نسبة نجاح وعملت مثلاً أو عملت Chrome وعملت فيه نسبة نجاح وعدد مشتركين تقدر تبيع الحاجة دي بمبلغ كويس. طبعاً عندنا أكثر مثال اتباع ومشهور عندنا مثلاً SessionBuddy ده عبارة عن Extension على الـ Chrome، عبارة عن موقعه عبارة عن صفحة واحدة بسيطة جداً بالـ WordPress، لكن عدد المشتركين مليون، طبعاً اتباع للكيان بمبلغ كبير وهو مجاني 100%. لكن طبعاً هدفه إنه يعمل tracking. فده من أحد الحاجات وهكذا برضو أنت سهل موضوع بيع الأدوات أو موضوع الـ Chrome Extension، الحاجات دي سهلة بيعها. فأنت عندك أربع أنواع من Application وأربع أنواع من طرق الربح من خلالها. طيب دي أول نقطة حابب أتكلم فيها.
