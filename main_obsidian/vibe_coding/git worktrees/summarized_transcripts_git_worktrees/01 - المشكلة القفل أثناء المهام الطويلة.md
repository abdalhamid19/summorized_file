# 01 - المشكلة: القفل أثناء المهام الطويلة

## 📌 الملخص العلمي

### المشكلة

عندما يعمل [[Claude Code]] على مهمة طويلة المدى (<span style="color:#0D9488; font-weight:bold;">long horizon tasks</span>) — مثل إصلاح الاختبارات ([[tests]]) على فرع ([[branch]]) معيّن — فأنت <span style="color:#E11D48; font-weight:bold;">مقفل تمامًا</span> عن أي عمل آخر مع Claude Code حتى تنتهي المهمة.

### بدائل المتحدث أثناء الانتظار (كما ذكرها)

| البديل | الوصف |
|--------|-------|
| التفكير في الميزات القادمة | [[feature]] التالية المراد بناؤها |
| تدوين الملاحظات | تسجيل ما يلاحظه أثناء عمل الأداة |
| لا شيء | «أقلّب إبهامي» — انتظار بلا إنتاجية |

### الفكرة المطروحة (الحل المختصر)

> <span style="color:#D97706; font-weight:bold;">تشغيل عدة نسخ (instances) من Claude Code على فروع مختلفة تعمل على ميزات متعددة في نفس الوقت</span> — مما يجعلك «وحش إنتاجية» (performance beast) في التعامل مع الأداة.

| المفهوم | التعريف |
|---------|---------|
| <span style="color:#0D9488; font-weight:bold;">Multi-instance workflow</span> | أكثر من نسخة Claude Code تعمل بالتوازي، كل نسخة على فرع مستقل |
| <span style="color:#0D9488; font-weight:bold;">Isolation</span> | كل نسخة تعمل في مجلد/فرع معزول فلا تتداخل مع الأخرى |

> 💡 **إضافة من المُلخِّص (ليست في المصدر):** مصطلح «Multi-Agent» في عنوان الفيديو يشير إلى أن كل نسخة Claude Code تعمل كوكيل ([[agent]]) مستقل موازٍ للبقية؛ المتحدث نفسه لم يشرح المصطلح صراحةً.
