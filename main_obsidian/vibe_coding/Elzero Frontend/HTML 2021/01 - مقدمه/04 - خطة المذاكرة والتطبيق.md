# خطة المذاكرة والتطبيق

- [ ] حدّد هدفك من تعلم HTML قبل بدء الدورة.
- [ ] شاهد الدرس بتركيز، ودوّن النقاط التي تحتاج إلى الرجوع إليها.
- [ ] افتح [صفحة دروس HTML](https://elzero.org/category/courses/html-course/) وراجع Code (التعليمات البرمجية) المرافق للدروس.
- [ ] حل تدريبًا من [تدريبات HTML](https://elzero.org/category/assignments/html-assignments/) بعد المشاهدة.
- [ ] ابحث أولًا عند ظهور سؤال، ثم دوّن ما بقي غير واضح.

## تحقق ذاتي

- [ ] أستطيع شرح معنى HTML وفق الشريحة.
- [ ] وصلت إلى صفحة Code (التعليمات البرمجية) والتدريبات.
- [ ] كتبت هدفًا وبدأت الدراسة بتركيز.
