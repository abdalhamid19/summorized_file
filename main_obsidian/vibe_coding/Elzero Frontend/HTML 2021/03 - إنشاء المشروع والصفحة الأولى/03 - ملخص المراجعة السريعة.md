# ملخص المراجعة السريعة

- أنشئ مجلدًا واضحًا لكل مشروع وافتحه كاملًا في محرر الأكواد.
- أنشئ `index.html` للبدء بملف HTML؛ `index` اسم شائع للصفحة الافتراضية بحسب إعداد الخادم.
- يعرّف امتداد الملف نوع الملف، بينما الاسم `index` اصطلاح للتسمية.
- يتكون العنصر غالبًا من وسم فتح ومحتوى ووسم إغلاق؛ توجد عناصر لا تستخدم وسم إغلاق منفصلًا.
- `<html>` هو جذر مستند HTML، والعناصر الأخرى تتداخل تحته.
- المسافات البادئة تساعد على قراءة البنية، والإكمال التلقائي مساعدة من المحرر.
- التفريغ الآلي المتاح ينقطع قبل نهاية الفيديو؛ لا يغطي هذا الملخص الدرس كاملًا.

## تذكّر الفرق

| المصطلح | معناه |
|---|---|
| `element` | عنصر داخل بنية مستند HTML |
| `tag` | وسم يحدد بداية العنصر أو نهايته |
| `file extension` | امتداد يبين نوع الملف |
| `indentation` | مسافة بادئة توضح التداخل في الشيفرة |
| `root` | العنصر الأعلى الذي تبدأ تحته بقية البنية |
