# الدرس 03: إنشاء المشروع والصفحة الأولى

> [!warning] حالة التفريغ
> هذه خلاصة بالمعنى للمعاينة الآلية التي ظهرت في Transkriptor، وليست نقلًا حرفيًا ولا تغطي الفيديو كاملًا. مدته في YouTube 09:04، بينما عرضت المعاينة الصوتية 05:31 وانقطع النص أثناء مثال مصدر الصفحة. محاولة إعادة التفريغ من الحساب الجديد لم تصل إلى الفيديو مباشرة، وتنزيل النسخة السابقة وجّه إلى الترقية. لم أستكمل المحتوى المفقود بالتخمين.

## الفكرة الرئيسية

ابدأ مشروع HTML بمجلد منظم وافتحه في محرر الأكواد. أنشئ داخله `index.html`، ثم ابدأ بعنصر `<html>` بوصفه جذر المستند. استخدم وسوم الفتح والإغلاق المناسبة، ونظّم العناصر المتداخلة بمسافات بادئة لتسهيل قراءة البنية. يعرض الدرس كذلك تلميحات المحرر عند الوقوف على العنصر، ويبدأ مثالًا على قراءة مصدر صفحة غير منسق قبل أن تنقطع المعاينة.

## التفريغ بالمعنى حسب العلامات المتاحة

### 00:00:05 إلى 02:57 تقريبًا: إعداد المشروع

ينصح المدرّس بتخصيص مجلد للمشروع بدل وضع ملفات التجارب عشوائيًا على سطح المكتب. ويقترح اسمًا قصيرًا يمكن كتابته في المسارات والأوامر، ثم يشرح فتح المجلد كاملًا في Visual Studio Code أو Atom. بعد ذلك ينشئ ملفًا جديدًا باسم `index.html`، ويميز بين الاسم وامتداد الملف `.html`.

### 02:58–03:19: اسم الملف الرئيسي

يشير الشرح إلى شيوع `index` لملف البداية في إعدادات الخوادم، مع إمكان اختلاف الامتداد حسب التقنية. هذه تسمية عملية شائعة وليست قاعدة تفرضها لغة HTML.

### 03:20–03:40: عنصر HTML

يبدأ بناء الصفحة بعنصر `<html>`. يشرح المحاضر وسمي الفتح والإغلاق، ويشير إلى أن بعض العناصر لا تتطلب وسم إغلاق منفصلًا. يحتوي عنصر HTML على محتوى وعناصر أخرى داخله.

### 03:41–05:31: تلميحات المحرر والتنسيق

تعرض المعاينة أن Visual Studio Code قد يقدم معلومات عن العنصر عند الوقوف عليه، ومنها وصف `<html>` بأنه جذر المستند. وتشرح فائدة المسافات البادئة عند الكتابة داخل العناصر: إظهار التداخل وفصل البنية بصريًا. بعد ذلك يبدأ المدرّس مثالًا على مصدر صفحة غير منسق وملف تجريبي للمقارنة، لكن النص المتاح يتوقف قبل أن يكتمل المثال.

## المحاور التي ذكرها تعليق مثبت فقط

يذكر تعليق مشاهد مثبت `<head>` و`<body>` عند 06:31، و`<title>` عند 07:33. يتكرر توقيت 06:31 للعنصرين في التعليق نفسه. هذه إشارات فهرسة غير مراجعة مقابل الصوت، فلا أضيف شرحًا أو تفريغًا تفصيليًا لها.

## مصطلحات أساسية

- **HTML (HyperText Markup Language):** لغة ترميز لبناء بنية صفحات الويب.
- **element:** عنصر داخل بنية المستند.
- **tag:** وسم يكتب لبدء العنصر أو إنهائه.
- **file extension:** امتداد يوضح نوع الملف.
- **root:** العنصر الأعلى الذي تبدأ تحته البنية.
- **indentation:** مسافة بادئة تُظهر التداخل في الشيفرة.
- **ASR (Automatic Speech Recognition):** التعرّف الآلي على الكلام وتحويله إلى نص.
