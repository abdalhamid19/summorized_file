1. المقدمة وإعادة إعداد الدورة

## المقدمة وإعادة إعداد الدورة

تبدأ الشرائح بعنوان Learn HTML In 2021، ثم تعرض عنوان Remastering For Old People. وتسرد نقاطًا منها: محتوى جديد، جودة جديدة، إزالة CSS (لغة تنسيق صفحات الويب) وCanvas (عنصر رسم داخل صفحة الويب)، دمج HTML 4 وHTML 5، وأن المحتوى القديم ليس سيئًا، ثم سؤال عمّا يتعلق بالمحتوى القديم. نُقلت النقاط كما في الشرائح دون استنتاج تفاصيل إضافية.

## ما لغة HTML؟

HTML اختصار Hypertext Markup Language، وتصفها الشريحة بأنها اللغة المستخدمة لبناء الويب. وتعرض إلى جانبها كلمات Ship (سفينة) وBuilding (بناء) وSkeleton (هيكل عظمي).

## الإصدارات

تذكر الشريحة الرقمين 4 و5.

## دوافع التعلم

تحت عنوان Why I Need To Learn تسرد الشريحة: Front-End Developer (مطوّر الواجهة الأمامية التي يراها المستخدم)، وBack-End Developer (مطوّر الجزء الخلفي)، وMobile Developer (مطوّر تطبيقات الهاتف)، وReports (تقارير).

## الأدوات والاستعداد

تذكر الشرائح Visual Studio Code أو Atom كمحرر نصوص، وGoogle Chrome أو Firefox Developer Edition كمتصفح، ومعرفة أساسية بنظام Windows (نظام تشغيل الحاسوب) والإنترنت. كما تؤكد وجود هدف والتركيز والبحث قبل السؤال والبدء بتنفيذ الأفكار.

## طريقة دراسة الدورة

توصي الشرائح بمشاهدة الدروس بتركيز، ومراجعة Code (التعليمات البرمجية) من صفحة دروس HTML الرسمية، ثم حل التدريبات الرسمية.

## حالة التفريغ الحرفي

لم يتوفر تفريغ نصي للفيديو على YouTube؛ لذلك لا يمكن إيراد النص الحرفي دون تخمين. يعتمد هذا الملف على الشرائح الرسمية والعناوين المنشورة للفيديو.
