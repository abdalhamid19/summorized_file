# 01 - مقدمة وماذا تحتاج لتتعلم HTML

> [!info] المصدر وحدود التفريغ
> المدرّس أسامة الزيرو. مدة الفيديو 11:04. التفريغ النصي غير متاح في YouTube؛ لذا هذا شرح منظم لما أمكن التحقق منه في الشرائح الرسمية والعناوين المثبتة، وليس نقلًا حرفيًا للصوت.

## المقدمة وإعادة إعداد الدورة — 00:00–02:25

تبدأ الشرائح بعنوان Learn HTML In 2021، وتعرض عنوان Remastering For Old People. وتسرد: محتوى جديد، جودة جديدة، إزالة CSS (لغة تنسيق صفحات الويب) وCanvas (عنصر رسم داخل صفحة الويب)، دمج HTML 4 وHTML 5، وأن المحتوى القديم ليس سيئًا، ثم سؤالًا عمّا يتعلق بالمحتوى القديم؛ والإيضاحات العربية بين القوسين للتسهيل فقط.

## ما لغة HTML؟ — 02:25–04:14

<span style="color:#0D9488; font-weight:bold;">HTML اختصار Hypertext Markup Language، وتصفها الشريحة بأنها اللغة لبناء الويب.</span> كما تعرض الكلمات Ship (سفينة) وBuilding (بناء) وSkeleton (هيكل عظمي) باعتبارها تشبيهًا مرافقًا لفكرة البناء والهيكل.

## الإصدارات — 04:14–05:30

تذكر شريحة الإصدارات الرقمين 4 و5.

## لماذا أتعلم HTML؟ — 05:30–06:10

تحت عنوان Why I Need To Learn تذكر الشريحة المسميات:
- Front-End Developer (مطوّر الواجهة الأمامية التي يراها مستخدم الموقع).
- Back-End Developer (مطوّر الجزء الخلفي من الموقع).
- Mobile Developer (مطوّر تطبيقات الهاتف).
- Reports (تقارير).

## ما الذي أحتاجه للتعلم؟ — 06:10–09:35

الأدوات والمعرفة المذكورة:
- Text Editor (محرر لكتابة Code؛ أي التعليمات التي ينفذها الحاسوب): Visual Studio Code أو Atom.
- Internet Browser (متصفح الإنترنت لفتح صفحات الويب): Google Chrome أو Firefox Developer Edition.
- معرفة أساسية بنظام Windows (نظام تشغيل الحاسوب) والإنترنت.

وتؤكد الشريحة على البحث باستمرار، ووجود هدف، والتركيز، والبدء بتنفيذ الأفكار، والبحث قبل السؤال؛ وتتكرر عبارة Always Search.

## كيف أدرس الدورة؟ — 09:35–11:04

1. شاهد الدروس بتركيز.
2. راجع Code (التعليمات البرمجية) من [صفحة دروس HTML الرسمية](https://elzero.org/category/courses/html-course/).
3. حل [تدريبات HTML الرسمية](https://elzero.org/category/assignments/html-assignments/).

## حالة التفريغ الحرفي

> [!warning] التفريغ الحرفي غير متاح
> لم يوفّر YouTube نصًا أو ترجمة قابلة للاستخراج للفيديو. لا أضع نصًا تخمينيًا مكان كلام المدرّس. راجع [الفيديو والشرائح الرسمية](https://elzero.org/html-introduction-and-what-you-need-to-learn/).

## مراجعة المصدر

طابقت ترتيب الموضوعات مع العناوين الزمنية في تعليق القناة المثبت، وقارنت النقاط الظاهرة بالشرائح الرسمية ذات الصفحات السبع. المطابقة كلمة بكلمة مع الصوت غير ممكنة لغياب التفريغ.
