# ملخص المراجعة السريعة

- HTML اختصار Hypertext Markup Language، وتصفها الشريحة بأنها لغة بناء الويب.
- تظهر الإصدارات 4 و5 في شريحة الإصدارات.
- المجالات المذكورة: Front-End Developer وBack-End Developer وMobile Developer وReports.
- المحررات: Visual Studio Code وAtom؛ المتصفحات: Google Chrome وFirefox Developer Edition.
- الاستعداد: معرفة Windows والإنترنت، وتحديد هدف، والتركيز، والبحث قبل السؤال.
- أسلوب الدراسة: مشاهدة مركزة، مراجعة Code (التعليمات البرمجية)، ثم حل التدريبات.
