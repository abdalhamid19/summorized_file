# ملخص المراجعة السريعة

- الهدف من الدرس هو التعرف الأولي على عناصر HTML قبل تعلمها وكتابتها بالتفصيل.
- صفحة الويب تتكون من عناصر مختلفة، ولكل عنصر اسم.
- Inspect (أداة فحص العناصر) تتيح مشاهدة بنية الصفحة من المتصفح وربط جزء مرئي، مثل النص أو الصورة، بعنصره.

  ![[لقطة 01 - قبل النقر بزر الفأرة الأيمن.png]]

  *الخطوة 1 — 01:30: صفحة المثال قبل النقر بزر الفأرة الأيمن.*

  ![[لقطة 02 - قائمة النقر بزر الفأرة الأيمن مع خيار Inspect.png]]

  *الخطوة 2 — 01:32: تظهر قائمة النقر بزر الفأرة الأيمن؛ اختر Inspect (فحص العنصر).*

  ![[لقطة 03 - بعد Inspect وتحديد العنصر.png]]

  *الخطوة 3 — 01:35: بعد الاختيار، تفتح أدوات المطوّر ويظهر عنصر العنوان محددًا.*
- HTML تبني البنية الأساسية؛ CSS تنسق المظهر المرئي.
- يعرض الدرس Visual Studio Code وAtom كمحررين؛ وتذكر الملاحظات الرسمية Brackets أيضًا.
- لا حاجة إلى حفظ جميع العناصر في هذه المقدمة؛ المهم فهم شكل الصفحة وطريقة استعراضها.
