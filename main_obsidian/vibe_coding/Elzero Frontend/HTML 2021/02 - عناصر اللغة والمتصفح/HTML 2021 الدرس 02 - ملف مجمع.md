# HTML 2021 — الدرس الثاني: عناصر اللغة والمتصفح

## الفكرة العامة

يقدّم هذا الدرس جولة أولى في عناصر HTML (HyperText Markup Language، لغة ترميز لبناء بنية صفحات الويب) وكيفية ملاحظتها في المتصفح. المقصود تكوين فكرة عامة قبل أن يبدأ المتعلم في إنشاء العناصر وكتابتها بنفسه.

## صفحة الويب وعناصرها

تتكون صفحة الويب من مجموعة عناصر، ولكل عنصر اسم يميّزه. لا يتطلب الدرس حفظ هذه العناصر من البداية؛ بل يعرض الصفحة كمثال يساعد المتعلم على رؤية أن المحتوى الظاهر له بنية وراءه.

يمكن فتح أدوات المتصفح بزر الفأرة الأيمن واختيار Inspect (أداة فحص عناصر الصفحة ضمن أدوات المطوّر). وباستخدام أداة اختيار العنصر، يمكن الإشارة إلى جزء مرئي مثل نص أو صورة وملاحظة العنصر المقابل في لوحة المطوّر.

## HTML وCSS

HTML توفر الهيكل الأساسي لصفحة الويب، ويشبّهها الدرس بالهيكل العظمي. أما CSS (Cascading Style Sheets، لغة تنسيق صفحات الويب) فتهتم بمظهر الصفحة وتنسيقها. من دون التنسيق يبقى المحتوى والبنية الأساسيان ظاهرين لكن المظهر يصبح أبسط.

## محررات الأكواد

يعرض الدرس Visual Studio Code وAtom للتجربة في كتابة الأكواد. تختلف واجهات المحررات، ويختار المتعلم النسخة المناسبة لنظامه وما يناسبه من واجهة. وتذكر صفحة ملاحظات الدرس الرسمية Brackets ضمن البرامج الإضافية التي يمكن تجربتها.

- Code Editor (محرر الأكواد): برنامج كتابة ملفات وتعليمات المشروع.
- Browser (المتصفح): برنامج عرض صفحات الويب، ويمكن عبر أدواته فحص عناصر الصفحة.

## خلاصة الدراسة

1. افهم أن الصفحة مبنية من عناصر HTML.
2. استعمل Inspect لمشاهدة البنية المرتبطة بنص أو صورة.
3. ميّز بين HTML للبنية وCSS للتنسيق.
4. جرّب محرر أكواد واحدًا، ثم انتقل إلى التطبيق العملي في الدرس التالي.
5. راجع [[vibe_coding/Elzero Frontend/HTML 2021/summarized_transcripts_HTML_2021/01 - مقدمة وماذا تحتاج لتتعلم HTML]] قبل إكمال ترتيب الدورة.
