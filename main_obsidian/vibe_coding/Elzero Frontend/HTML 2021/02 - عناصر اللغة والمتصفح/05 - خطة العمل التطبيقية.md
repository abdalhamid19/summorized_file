# خطة العمل التطبيقية

## بعد مشاهدة الفيديو

- [ ] اكتب بجملة واحدة ما المقصود بعنصر HTML وفق الشرح.
- [ ] اختر صفحة ويب تريد استكشافها.
- [ ] انقر بزر الفأرة الأيمن واختر Inspect (أداة فحص عناصر الصفحة).
- [ ] استخدم أداة تحديد العنصر للإشارة إلى نص أو صورة، ثم لاحظ العنصر الذي تعرضه أدوات المتصفح.
- [ ] لخّص الفرق بين بنية HTML وتنسيق CSS بكلماتك.
- [ ] اختر محررًا لتجربته؛ يعرض الدرس Visual Studio Code وAtom، وتسرد الملاحظات الرسمية Brackets أيضًا.
- [ ] انتقل إلى الدرس التالي: [إنشاء مشروعك الأول وصفحتك الأولى](https://www.youtube.com/watch?v=QG5aEmS9Fu0).
- [ ] بعد مراجعة الدروس 01–05، حل [تكليفات Elements And Comments الرسمية](https://elzero.org/html-assignments-lesson-from-1-to-5/).

## تحقق ذاتي

- [ ] أستطيع شرح فكرة العناصر دون محاولة حفظ القائمة كاملة.
- [ ] أستطيع فتح أدوات المطوّر وتحديد عنصر ظاهر في الصفحة.
- [ ] أستطيع توضيح أن HTML للبنية وCSS للمظهر.
- [ ] كتبت ملاحظتي عن المحرر الذي اخترته ولماذا.
