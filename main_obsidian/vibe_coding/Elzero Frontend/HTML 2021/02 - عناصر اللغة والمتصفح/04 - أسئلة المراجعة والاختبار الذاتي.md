# أسئلة المراجعة والاختبار الذاتي

أجب أولًا، ثم راجع [[vibe_coding/Elzero Frontend/HTML 2021/02 - عناصر اللغة والمتصفح/02 - شرح عناصر اللغة والمتصفح]].

## الأسئلة

1. ما الهدف من الجولة التمهيدية في هذا الدرس؟
2. مم تتكون صفحة الويب بحسب الشرح؟
3. كيف تصل إلى Inspect في المتصفح، وما الذي تتيحه أداة تحديد العنصر؟
4. ما الفرق بين دور HTML ودور CSS؟
5. ما محررا الأكواد اللذان يعرضهما الفيديو؟ وما البرنامج الإضافي الذي تسرده صفحة الدرس الرسمية؟
6. هل المطلوب حفظ كل العناصر في هذا الدرس؟

## الإجابات

1. تكوين فكرة عامة عن عناصر الصفحة وكيفية استعراضها قبل البدء في تعلمها وكتابتها بالتفصيل.
2. من عناصر HTML متعددة، ولكل عنصر اسم يميّزه.
3. بالنقر بزر الفأرة الأيمن على الصفحة واختيار Inspect؛ ثم تحديد جزء مرئي لمشاهدة العنصر المقابل في أدوات المطوّر.
4. HTML توفر بنية الصفحة الأساسية، وCSS تنسق مظهرها.
5. Visual Studio Code وAtom؛ والصفحة الرسمية تسرد Brackets أيضًا.
6. لا؛ التركيز هنا على فهم الفكرة العامة، والتفاصيل تأتي في الدروس التالية.
