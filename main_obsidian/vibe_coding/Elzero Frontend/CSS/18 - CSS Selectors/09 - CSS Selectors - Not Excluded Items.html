المطلوب

الكود الكامل للحل

CSS
div:not(:first-child):not(:last-child), p:not(:first-child):not(:last-child) { color: #f00; font-weight: 700; }

الفكرة الأساسية

يستبعد :not(:first-child) أول ابن، ويستبعد :not(:last-child) آخر ابن. أدرجت نوعي div وp في السطر نفسه حتى تتلوّن العناصر الثلاثة التي تحمل كلمة Elzero في بنية HTML الأصلية.
