# CSS Selectors — Class, ID, and Type

> [!question] السؤال
> اكتب تعليقًا يوضح وظيفة كل محدد في الشيفرة التالية.
>
> ```css
> .title {
> }
>
> #nav {
> }
>
> div {
> }
>
> h2 {
> }
> ```

> [!success]- الإجابة وشرح الحل — اضغط لفتحه
>
> ### الكود الكامل للحل
>
> ```css
> /* Any Element With Class Title */
> .title {
> }
>
> /* Element with ID nav */
> #nav {
> }
>
> /* All div elements */
> div {
> }
>
> /* All h2 elements */
> h2 {
> }
> ```
>
> ### الفكرة الأساسية
>
> يختار كل عنصر يحمل قيمة الصنف التالية:
>
> > [!info]- معاني الرموز المستخدمة في الحل
> >
> > ### محددات CSS
> >
> > #### `.title`
> >
> > يستهدف العناصر التي تحمل اسم الصنف المحدد.
> >
> > #### `#nav`
> >
> > يستهدف عنصرًا يحمل المعرّف المحدد.
> >
> > #### `div`
> >
> > يحدد العنصر الذي ستطبق عليه قواعد `CSS`.
> >
> > #### `h2`
> >
> > يحدد العنصر الذي ستطبق عليه قواعد `CSS`.
> >
> > ### بنية القاعدة
> >
> > #### `{`
> >
> > يفتح مجموعة التصريحات.
> >
> > #### `}`
> >
> > يغلق مجموعة التصريحات.
> >
> > [!info]- شرح الحل سطرًا بسطر
> >
> > يبقى الكود الكامل أعلى الإجابة، ويأتي كل سطر مستقلًا مع شرحه العربي تحته.
> >
> > #### السطر 01 — `css`
> >
> > ```css
> > /* Any Element With Class Title */
> > ```
> >
> > يعرض نصًا أو قيمة في المثال.
> >
> > #### السطر 02 — `css`
> >
> > ```css
> > .title {
> > ```
> >
> > يستهدف العناصر التي تحمل اسم الصنف المحدد.
> >
> > #### السطر 03 — `css`
> >
> > ```css
> > }
> > ```
> >
> > يغلق نطاق القاعدة التي بدأها المحدد.
> >
> > #### السطر 04 — `css`

> > ```css
> > /* Element with ID nav */
> > ```
> >
> > يعرض نصًا أو قيمة في المثال.
> >
> > #### السطر 05 — `css`
> >
> > ```css
> > #nav {
> > ```

> > يستهدف عنصرًا يحمل المعرّف المحدد.

> > }
> > ```

> > ```
