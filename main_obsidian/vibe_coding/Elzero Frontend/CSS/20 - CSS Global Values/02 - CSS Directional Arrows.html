<section id="task-02">

المطلوب

أنشئ صنفًا أساسيًا اسمه arrow وأصناف اتجاه top وright وbottom وleft. لا يظهر السهم إلا عند الجمع بين arrow وصنف الاتجاه، ويظل في منتصف العنصر مهما اختلف عرضه أو ارتفاعه.

الكود الكامل للحل

HTML
<div class="arrow top"></div>

<div class="arrow left"></div>

CSS
.arrow {
  --arrow-color: #e91e63;
  position: relative;
  width: 160px;
  height: 110px;
  border: 1px solid #cbd5e1;
  background: #f8fafc;
}

.arrow.top::before,
.arrow.right::before,
.arrow.bottom::before,
.arrow.left::before {
  position: absolute;
  top: 50%;
  left: 50%;
  width: 0;
  height: 0;
  border: 14px solid transparent;
  content: "";
  transform: translate(-50%, -50%);
}

.arrow.top::before {
  border-bottom-color: var(--arrow-color);
}

.arrow.right::before {
  border-left-color: var(--arrow-color);
}

.arrow.bottom::before {
  border-top-color: var(--arrow-color);
}

.arrow.left::before {
  border-right-color: var(--arrow-color);
}

الفكرة الأساسية

تقصر المحددات على وجود arrow مع الاتجاه؛ لذلك لا يعمل top وحده. يرسم العنصر الوهمي ::before مثلثًا بالحدود الشفافة، ثم يلوّن الحد الموافق للاتجاه المطلوب. تحدد نسبتا top وleft المنتصف اعتمادًا على أبعاد الصندوق لا على رقم ثابت.

خصائص CSS

--arrow-color

تحدد قيمة الخاصية --arrow-color. مثال القيمة: #e91e63

position

تحدد طريقة التموضع. مثال القيمة: relative

width

تحدد عرض العنصر. مثال القيمة: 160px

height

تحدد ارتفاع العنصر. مثال القيمة: 110px

border

ترسم الحد وتحدد سمكه ونمطه ولونه. مثال القيمة: 1px solid #cbd5e1

background

تضبط الخلفية. مثال القيمة: #f8fafc

top

تحدد المسافة من أعلى مرجع التموضع. مثال القيمة: 50%

left

تحدد المسافة من اليسار. مثال القيمة: 50%

content

تحدد محتوى العنصر الزائف. مثال القيمة: &quot;&quot;

transform

تطبق دورانًا أو تحريكًا أو تحجيمًا. مثال القيمة: translate(-50%, -50%)

border-bottom-color

تحدد قيمة الخاصية border-bottom-color. مثال القيمة: var(--arrow-color)

border-left-color

تحدد قيمة الخاصية border-left-color. مثال القيمة: var(--arrow-color)

border-top-color

تحدد قيمة الخاصية border-top-color. مثال القيمة: var(--arrow-color)

border-right-color

تحدد قيمة الخاصية border-right-color. مثال القيمة: var(--arrow-color)
