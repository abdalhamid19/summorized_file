أصناف مساعدة للتوسيط والأشكال، ثم مثلثات اتجاهية تتوسط عناصر بأبعاد مختلفة.

التكليف 01 — Utility Classes

يحتاج العنصر الأب إلى position: relative عند توسيط عنصر باستخدام center-position.

center-flexالمحتوى في المنتصف
center-positionعنصر متمركز
100 × 100
200 × 200
.center-flex { display: flex; justify-content: center; align-items: center; }
.center-position { position: absolute; top: 50%; left: 50%; transform: translate(-50%, -50%); }
.circle-100 { width: 100px; height: 100px; border-radius: 50%; }
.circle-200 { width: 200px; height: 200px; border-radius: 50%; }

التكليف 02 — Directional Arrows

تتوسط الأسهم صناديقها، ويُطبَّق كل اتجاه مع الصنف الأساسي arrow.

arrow top
arrow right
arrow bottom
arrow left
.arrow.top::before { border-bottom-color: var(--arrow-color); }
.arrow.right::before { border-left-color: var(--arrow-color); }
.arrow.bottom::before { border-top-color: var(--arrow-color); }
.arrow.left::before { border-right-color: var(--arrow-color); }
