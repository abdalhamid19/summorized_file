# CSS Reusable Utility Classes

> [!question] السؤال
> أنشئ مجموعة أصناف قابلة لإعادة الاستخدام:
>
> - `center-flex` لتوسيط محتويات العنصر بالطول والعرض باستخدام `Flex`.
> - `center-position` لتوسيط العنصر نفسه داخل العنصر الأب بالطول والعرض.
> - `circle-100` و`circle-200` لجعل العنصر دائريًا بقياسي `100×100px` و`200×200px`.
>
> [صفحة التكليف الأصلية](https://elzero.org/css-assignments-lesson-from-86-to-88/)

> [!success]- الإجابة وشرح الحل — اضغط لفتحه
>
> ### الكود الكامل للحل
>
> ```css
> .center-flex {
>   display: flex;
>   justify-content: center;
>   align-items: center;
> }
>
> .center-position {
>   position: absolute;
>   top: 50%;
>   left: 50%;
>   transform: translate(-50%, -50%);
> }
>
> .circle-100 {
>   width: 100px;
>   height: 100px;
>   border-radius: 50%;
> }
>
> .circle-200 {
>   width: 200px;
>   height: 200px;
>   border-radius: 50%;
> }
> ```
>
> ### الفكرة الأساسية
>
> أضف `position: relative` إلى الأب الذي يحتوي العنصر ذي `center-position`؛ عندها تكون نقطة المنتصف محسوبة داخل هذا الأب. يوسّط `center-flex` العناصر الداخلية، بينما يوسّط `center-position` العنصر الذي أُضيف إليه الصنف. تجعل النسبة `50%` الحافتين دائريتين تمامًا بعد مساواة العرض والارتفاع.

> > ### خصائص CSS
> >
> > #### `display`
> >
> > تحدد طريقة عرض العنصر. مثال القيمة: `flex`
> >
> > #### `justify-content`
> >
> > توزع العناصر على المحور الرئيسي. مثال القيمة: `center`
> >
> > #### `align-items`
> >
> > تحاذي العناصر عرضيًا. مثال القيمة: `center`
> >
> > #### `position`
> >
> > تحدد طريقة التموضع. مثال القيمة: `absolute`
> >
> > #### `top`
> >
> > تحدد المسافة من أعلى مرجع التموضع. مثال القيمة: `50%`
> >
> > #### `left`
> >
> > تحدد المسافة من اليسار. مثال القيمة: `50%`
> >
> > #### `transform`
> >
> > تطبق دورانًا أو تحريكًا أو تحجيمًا. مثال القيمة: `translate(-50%, -50%)`
> >
> > #### `width`
> >
> > تحدد عرض العنصر. مثال القيمة: `100px`
> >
> > #### `height`
> >
> > تحدد ارتفاع العنصر. مثال القيمة: `100px`
> >
> > #### `border-radius`
> >
> > تدوّر زوايا العنصر. مثال القيمة: `50%`
> >
