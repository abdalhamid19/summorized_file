# CSS Nesting and Grouped Selectors

> [!question] السؤال
> حافظ على بنية HTML كما هي. لوّن كلمة `Title` بالأحمر، وجملة `Child Title` بالأزرق، وجملتي `Paragraph Content` و`Section Title` بالأخضر، ثم اجمع المحددات التي تستخدم اللون نفسه.
>
> ```html
> <div class="parent">
>   <div class="child">This Is Child <span class="title">Title</span></div>
>   <span class="title">Child Title</span>
>   <p>Paragraph Content</p>
> </div>
> <div class="title">Section Title</div>
> ```
>
> [صفحة التكليف الأصلية](https://elzero.org/css-assignments-lesson-from-13-to-16/)

> [!success]- الإجابة وشرح الحل — اضغط لفتحه
>
> ```css
> .parent {
>   .child .title {
>     color: red;
>   }
>
>   & > .title {
>     color: blue;
>   }
>
>   p,
>   & ~ .title {
>     color: green;
>   }
> }
> ```
>
> **الفكرة الأساسية**
>
> **الهدف**
>
> نحافظ على بنية HTML كما هي، ونلوّن النصوص وفق موقع كل عنصر داخلها.
>
> **طريقة الاختيار**
>
> **CSS Nesting**
>
> نستخدم هذا الأسلوب لكتابة قواعد العناصر التابعة داخل قاعدة العنصر الأب، مع التمييز بين الابن المباشر وبقية العناصر.
>
> **تجميع اللون**
>
> **Grouped Selectors**
>
> نجمع الفقرة وعنوان القسم في قاعدة واحدة لأن اللون المطلوب لهما واحد.
>
> **نطاق التطبيق**
>
> نطبّق المحددات على البنية المطلوبة كما هي، ونترك HTML دون تعديل.
>
> **معاني الرموز المستخدمة في الحل**
>
> **nesting selector**
>
> ```css
> & > .title
> ```
>
> يشير هذا الرمز إلى محدد الأب المحيط بالقاعدة الحالية. في هذا الحل يعود إلى قاعدة العنصر الأب.
>
> **child combinator**
>
> ```css
> & > .title
> ```
>
> تشترط هذه العلامة أن يكون العنصر المختار ابنًا مباشرًا للعنصر الأب.
>
> **general sibling combinator**
>
> ```css
> & ~ .title
> ```
>
> تختار هذه العلامة عنصرًا شقيقًا يأتي بعد العنصر الأب ويشاركه الحاوية نفسها؛ وهنا تطابق عنوان القسم.
>
> **grouped selectors**
>
> ```css
> p,
> & ~ .title
> ```
>
> تفصل الفاصلة المحددات التي ستأخذ القاعدة نفسها؛ هنا تجمع الفقرة مع عنوان القسم ليأخذا اللون الأخضر.
>
> **class selector**
>
> ```css
> .title
> ```
>
> تسبق النقطة اسم الصنف؛ لذلك يختار المحدد العناصر التي تحمل الصنف الموضح في السطر أعلاه.
>
> **CSS rule block**
>
> ```css
> .parent { }
> ```
>
> يحدد القوسان بداية القاعدة ونهايتها، ويبيّنان نطاق التصريحات التابعة لها.
>
> **HTML angle bracket**
>
> ```html
> <div>...</div>
> ```
>
> تستخدم علامتا الزاوية لإحاطة اسم وسم HTML، وتضاف الشرطة المائلة في وسم الإغلاق. أما علامة العلاقة في محدد CSS فوظيفتها اختيار الابن المباشر كما في المثال أعلاه.
>
> **شرح الحل سطرًا بسطر**
>
> **1. قاعدة العنصر الأب**
>
> ```css
> .parent {
> ```
>
> يفتح نطاق العنصر الأب؛ وستُكتب المحددات التابعة داخله.
>
> **2. محدد العنوان الداخلي**
>
> ```css
>   .child .title {
> ```
>
> يختار العنوان الموجود داخل العنصر الابن.
>
> **3. لون العنوان الداخلي**
>
> ```css
>     color: red;
> ```
>
> يلوّن كلمة Title الداخلية بالأحمر.
>
> **4. إغلاق قاعدة العنوان الداخلي**
>
> ```css
>   }
> ```
>
> يغلق قاعدة العنوان الداخلي.
>
> **5. محدد الابن المباشر**
>
> **nesting selector**
>
> ```css
>   & > .title {
> ```
>
> يشير محدد التداخل إلى العنصر الأب، ويشترط أن يكون العنوان ابنًا مباشرًا له؛ لذلك يطابق جملة Child Title.
>
> **6. لون الابن المباشر**
>
> ```css
>     color: blue;
> ```
>
> يلوّن الابن المباشر بالأزرق.
>
> **7. إغلاق قاعدة الابن المباشر**
>
> ```css
>   }
> ```
>
> يغلق قاعدة الابن المباشر.
>
> **8. بداية مجموعة المحددات**
>
> ```css
>   p,
> ```
>
> يبدأ هذا السطر مجموعة المحددات، ويختار الفقرة داخل العنصر الأب.
>
> **9. محدد عنوان القسم**
>
> **general sibling combinator**
>
> ```css
>   & ~ .title {
> ```
>
> يختار عنوان القسم؛ فهذا المحدد يستهدف عنصرًا يشارك العنصر الأب الحاوية نفسها ويأتي بعده.
>
> **10. اللون المشترك**
>
> ```css
>     color: green;
> ```
>
> يلوّن الفقرة وعنوان القسم بالأخضر لأنهما ضمن مجموعة المحددات نفسها.
>
> **11. إغلاق قاعدة اللون الأخضر**
>
> ```css
>   }
> ```
>
> يغلق القاعدة التي طبقت اللون الأخضر على المحددين.
>
> **12. إغلاق قاعدة العنصر الأب**
>
> ```css
> }
> ```
>
> يغلق نطاق العنصر الأب بعد انتهاء قواعد العناصر التابعة.
>
> لم تتغير أي عقدة في HTML.
