التكليف 01

Nesting and Grouped Selectors

تلوين أجزاء البنية المعطاة مع إبقاء HTML كما هو وتجميع المحددات ذات اللون المشترك.

HTML الأصلي

<div class="parent">
  <div class="child">This Is Child
    <span class="title">Title</span>
  </div>
  <span class="title">Child Title</span>
  <p>Paragraph Content</p>
</div>
<div class="title">Section Title</div>

معاينة الناتج

This Is Child Title
Child Title

Paragraph Content

Section Title

CSS الحل — Nesting and Grouped Selectors

#task-01-preview {
  .parent {
    .child .title {
      color: red;
    }

    & > .title {
      color: blue;
    }

    p,
    & ~ .title {
      color: green;
    }
  }
}

شرح الحل سطرًا بسطر

  1. السطر #task-01-preview { يحدد لوحة المعاينة فقط، حتى يظل تأثير الألوان داخل التكليف.
  2. السطر .parent { يبدأ قاعدة العنصر الأب، وتوضع المحددات التابعة داخلها باستخدام CSS Nesting.
  3. السطر .child .title { يختار عنصر .title الموجود داخل .child داخل .parent.
  4. السطر color: red; يلوّن كلمة Title الداخلية بالأحمر.
  5. القوس } يغلق قاعدة المحدد .child .title.
  6. السطر & > .title { يجعل & تشير إلى .parent، ويعني > أن .title ابن مباشر؛ لذلك يطابق Child Title.
  7. السطر color: blue; يلوّن الابن المباشر بالأزرق.
  8. القوس } يغلق قاعدة الابن المباشر.
  9. السطر p, يبدأ تجميع محددين؛ وهذا الجزء يختار الفقرة داخل .parent.
  10. السطر & ~ .title { يختار عنصر .title الشقيق الذي يأتي بعد .parent، وهو عنوان القسم.
  11. السطر color: green; يلوّن الفقرة وعنوان القسم بالأخضر لأن المحددين مجموعان في القاعدة نفسها.
  12. القوس } يغلق قاعدة اللون الأخضر، ثم يغلق القوسان التاليان قاعدة .parent وغلاف المعاينة #task-01-preview.

يشير محدد التداخل & إلى العنصر الأب .parent؛ ويجمع المحددان p و& ~ .title لأن كليهما يحتاج اللون الأخضر.

التكليف 02

Dimensions and Overflow

نترك عناصر div على display: block، ونضع حدًا أقصى للعرض ونخفي النص الزائد.

HTML وCSS

<div class="box">Title One</div>
<div class="box">Title Two With More Words</div>
<div class="box">Title Three With Many Many Many Words</div>
<div class="box">
  Title Three With Many Many Many Words Title Three With Many Many Many Words
  Title Three With Many Many Many Words Title Three With Many Many Many Words
</div>

.box {
  box-sizing: border-box;
  width: fit-content;
  max-width: 400px;
  margin: 15px 0;
  padding: 15px;
  background-color: brown;
  color: white;
  font: 16px / 1.2 "Times New Roman", serif;
}

.box:last-child {
  height: 72px;
  overflow: hidden;
}

معاينة الناتج

Title One
Title Two With More Words
Title Three With Many Many Many Words
Title Three With Many Many Many Words Title Three With Many Many Many Words Title Three With Many Many Many Words Title Three With Many Many Many Words

ارتفاع `72px` اختيار توضيحي لأن التكليف يطلب إخفاء الجزء الخارج ولا يحدد ارتفاعًا بعينه. لا يوجد تصريح `display` في الحل.
