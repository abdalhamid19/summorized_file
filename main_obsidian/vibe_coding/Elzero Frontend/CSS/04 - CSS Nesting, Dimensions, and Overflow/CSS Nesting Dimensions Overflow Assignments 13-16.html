بنية HTML هي نفسها في الجهتين؛ الذي تغيّر هو تطبيق محددات CSS على العناصر المطلوبة.

CSS الحل — Nesting and Grouped Selectors

الكود الكامل

#task-01-preview {
  .parent {
    .child .title {
      color: red;
    }

    & > .title {
      color: blue;
    }

    p,
    & ~ .title {
      color: green;
    }
  }
}

الفكرة الأساسية

  1. الهدف: نحافظ على بنية HTML كما هي، ونلوّن النصوص وفق موقع كل عنصر داخلها.
  2. طريقة الاختيار: نكتب المحددات التابعة داخل قاعدة العنصر الأب.

    CSS Nesting

    هذا هو أسلوب التداخل داخل قاعدة الأب، مع التمييز بين الابن المباشر وبقية العناصر.

  3. تجميع اللون:

    Grouped Selectors

    نجمع الفقرة وعنوان القسم في قاعدة واحدة لأن اللون المطلوب لهما واحد.

  4. نطاق التطبيق: نحصر القواعد في لوحة المعاينة حتى لا تؤثر في بقية الصفحة.
معاني الرموز المستخدمة في الحل
CSS Nesting
nesting selector
&

يشير هذا الرمز إلى محدد الأب المحيط بالقاعدة الحالية. في هذا الحل يعود إلى قاعدة العنصر الأب.

المحددات والعلاقات بين العناصر
class selector
.title

تسبق النقطة اسم الصنف؛ لذلك يختار المحدد العناصر التي تحمل الصنف الموضح في السطر أعلاه.

descendant combinator
.child .title

المسافة بين المحددين تعني أن العنوان يقع داخل العنصر الابن، ولا تشترط أن يكون ابنًا مباشرًا.

child combinator
& > .title

تشترط علامة العلاقة أن يكون العنصر المختار ابنًا مباشرًا للعنصر الأب.

general sibling combinator
& ~ .title

تختار علامة العلاقة عنصرًا شقيقًا يأتي بعد العنصر الأب ويشاركه الحاوية نفسها؛ وهنا تطابق عنوان القسم.

grouped selectors
p,
& ~ .title

تفصل الفاصلة المحددات التي ستأخذ القاعدة نفسها؛ هنا تجمع الفقرة مع عنوان القسم ليأخذا اللون الأخضر.

ID selector
#task-01-preview

تختار علامة الهاش عنصرًا بمعرّف محدد. استخدمها غلافًا للمعاينة حتى تظل ألوان الحل محصورة في التكليف الأول داخل الصفحة.

قواعد CSS وتصريحاتها
CSS rule block
.parent { }

يحدد القوسان بداية القاعدة ونهايتها، ويبيّنان نطاق التصريحات التابعة لها.

CSS declaration
color: red;

تفصل النقطتان خاصية اللون عن قيمتها، وتنهي الفاصلة المنقوطة هذا التصريح.

علامات HTML
HTML angle brackets
<div>...</div>

تحيط علامتا الزاوية باسم وسم HTML، وتظهر الشرطة المائلة في وسم الإغلاق. أما علامة العلاقة في محدد CSS فوظيفتها اختيار الابن المباشر.

شرح الحل سطرًا بسطر 
  1. #task-01-preview {

    يحدد لوحة المعاينة فقط، حتى يظل تأثير الألوان داخل التكليف.

  2.   .parent {

    يبدأ قاعدة العنصر الأب، وتُكتب المحددات التابعة داخل هذه القاعدة.

  3.     .child .title {

    يختار عنصر العنوان الموجود داخل العنصر الابن.

  4.       color: red;

    يلوّن كلمة Title الداخلية بالأحمر.

  5.     }

    يغلق قاعدة العنوان الداخلي.

  6. nesting selector

        & > .title {

    يشير محدد التداخل إلى العنصر الأب، ويشترط أن يكون العنوان ابنًا مباشرًا له؛ لذلك يطابق هذا السطر Child Title.

  7.       color: blue;

    يلوّن الابن المباشر بالأزرق.

  8.     }

    يغلق قاعدة الابن المباشر.

  9.     p,

    يبدأ مجموعة المحددات، ويختار الفقرة داخل العنصر الأب.

  10. general sibling combinator

        & ~ .title {

    يختار عنوان القسم؛ فهذا المحدد يستهدف عنصرًا يشارك العنصر الأب الحاوية نفسها ويأتي بعده.

  11.       color: green;

    يلوّن الفقرة وعنوان القسم بالأخضر لأنهما ضمن مجموعة المحددات نفسها.

  12.     }

    يغلق قاعدة اللون الأخضر.

  13.   }

    يغلق قاعدة العنصر الأب.

  14. }

    يغلق نطاق لوحة المعاينة.
