المطلوب

أنشئ الصناديق بالنصوص والألوان الظاهرة في المثال. اترك display على قيمته الأصلية block، واجعل عرض العنصر لا يتجاوز 400px، ثم أخفِ أي جزء من النص يخرج من الصندوق الأخير.

رابط صورة التكليف هو المصدر الرسمي المتاح. تعذّر حفظ الصورة محليًا لأن الموقع حجب طلب التنزيل؛ أبقيت رابطها بدل ادعاء مطابقة بصرية غير متحققة.

المقارنة تعرض تأثير قاعدة الحل على عناصر المثال. شكل الحالة السابقة للتوضيح عندما لم يحدد المصدر شكلًا سابقًا دقيقًا.

الكود الكامل للحل

CSS
.box {
  box-sizing: border-box;
  width: fit-content;
  max-width: 400px;
  margin: 15px 0;
  padding: 15px;
  background-color: brown;
  color: white;
  font: 16px / 1.2 "Times New Roman", serif;
}

.box:last-child {
  height: 72px;
  overflow: hidden;
}

الفكرة الأساسية

العرض المناسب للمحتوى يظل محدودًا بسقف 400px. وعندما يزيد النص داخل الصندوق الأخير، تخفي overflow الجزء الخارج عن ارتفاعه. لا نكتب display لأن المطلوب إبقاء عناصر div على سلوكها الأصلي.

معاني الرموز المستخدمة في الحل

CSS dimensions

width: fit-content

يجعل عرض الصندوق مناسبًا لمحتواه، بدل فرض عرض ثابت.

max-width: 400px

يضع سقفًا للعرض؛ فلا يتجاوز الصندوق 400px.

box-sizing: border-box

يجعل padding والحد ضمن العرض الأقصى المحسوب.

height: 72px

يحدد ارتفاع الصندوق الأخير في هذا المثال المرئي؛ هذه قيمة توضيحية لأن المصدر لا يحددها.

تحديد العنصر وإخفاء الزائد

.box:last-child

يختار الصندوق ذي class box عندما يكون آخر عنصر بين إخوته.

overflow: hidden

يخفي الجزء الذي يتجاوز حدود الصندوق.

قيم التنسيق

margin / padding

الأولى تضيف مسافة خارج العنصر والثانية مساحة داخل حدوده.

font: 16px / 1.2 ...

يجمع حجم الخط وارتفاع السطر وعائلة الخط في تصريح واحد.
