> ### الكود الكامل للحل
>
> ```html
> <div class="login-card">
>   <h1 class="login-title">Login</h1>
>   <div class="login-content">
>     <form class="login-form">
>       <label for="login-email">Email</label>
>       <input id="login-email" type="email" autocomplete="off">
>       <label for="login-password">Password</label>
>       <input id="login-password" type="password" autocomplete="off">
>       <button class="login-button" type="button">Login</button>
>     </form>
>     <div class="social">
>       <h3>Connect</h3>
>       <button class="facebook" type="button">Facebook</button>
>       <button class="twitter" type="button">Twitter</button>
>       <button class="linkedin" type="button">Linkedin</button>
>     </div>
>     <span class="or">Or</span>
>   </div>
> </div>
> ```
>
> ```css
> .login-card {
>   overflow: hidden;
>   border-radius: 10px;
>   background: #fff;
> }
>

>   height: 102px;
>   margin: 0;
>   display: grid;
>   place-items: center;
>   color: #fff;
>   background: #1479ed;
>   font-size: 36px;
> }
>

>   position: relative;
>   padding: 28px 30px 30px;
>   display: grid;
>   grid-template-columns: 1fr 1fr;
>   gap: 80px;
> }
>

>   content: "";
>   position: absolute;
>   top: 35px;
>   bottom: 35px;

>

> }
>

>   width: 100%;
>   height: 57px;

>   margin: 0 0 26px;

>   font-size: 22px;

>   position: absolute;

>   left: 50%;

> ### الفكرة الأساسية
>
> يقسم `grid-template-columns` المحتوى إلى عمودين: نموذج الدخول يسارًا وأزرار الربط يمينًا. يرسم `::before` الفاصل العمودي، وتغطي كلمة `Or` وسطه بخلفية بيضاء.

> > ### خصائص CSS
> >
> > #### `overflow`
> >
> > تحدد ما يحدث للمحتوى الخارج عن العنصر. مثال القيمة: `hidden`
> >
> > #### `border-radius`
> >
> > تدوّر زوايا العنصر. مثال القيمة: `10px`
> >
> > #### `background`
> >
> > تضبط الخلفية. مثال القيمة: `#fff`
> >
> > #### `height`
> >
> > تحدد ارتفاع العنصر. مثال القيمة: `102px`
> >
> > #### `margin`
> >
> > تضيف مسافة خارجية. مثال القيمة: 0
> >
> > #### `display`
> >
> > تحدد طريقة عرض العنصر. مثال القيمة: `grid`
> >
> > #### `place-items`
> >
> > تختصر محاذاة `Grid`. مثال القيمة: `center`
> >
> > #### `color`
> >
> > تحدد لون النص. مثال القيمة: `#fff`
> >
> > #### `font-size`
> >
> > تحدد حجم النص. مثال القيمة: `36px`
> >
> > #### `position`
> >
> > تحدد طريقة التموضع. مثال القيمة: `relative`
> >
> > #### `padding`
> >
> > تضيف مساحة داخلية. مثال القيمة: `28px` `30px` `30px`
> >
> > #### `grid-template-columns`
> >
> > تحدد أعمدة `Grid`. مثال القيمة: `1fr` `1fr`
> >
> > #### `gap`
> >
> > تحدد المسافة بين عناصر التخطيط. مثال القيمة: `80px`
> >
> > #### `content`
> >
> > تحدد محتوى العنصر الزائف. مثال القيمة: ""
> >
> > #### `top`
> >
> > تحدد المسافة من أعلى مرجع التموضع. مثال القيمة: `35px`
> >
> > #### `bottom`
> >
> > تحدد المسافة من الأسفل. مثال القيمة: `35px`
