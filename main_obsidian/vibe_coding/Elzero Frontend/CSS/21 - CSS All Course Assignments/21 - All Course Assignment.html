المطلوب

السؤال الرسمي اختصر خصائص كل selector (محدد CSS) في سطر واحد. المثال الأول يوضح طريقة الاختصار.

لا توجد صورة مرجعية لهذا السؤال في الصفحة الرسمية؛ الكود هو مادة السؤال.

.example {
  margin-top: 10px;
  margin-right: 20px;
  margin-bottom: 15px;
  margin-left: 20px;
  /* Shorten Code in One Line */
}

.one {
  background-color: black;
  background-image: url("../imgs/one.jpg");
  background-repeat: no-repeat;
  background-position: left top;
  background-size: cover;
  /* Shorten Code in One Line */
}

.two {
  border-top-width: 1px;
  border-top-style: solid;
  border-top-color: #000;
  /* Shorten Code in One Line */
}

.three {
  top: 10px;
  right: 20px;
  bottom: 10px;
  left: 20px;
  /* Shorten Code in One Line */
}

.four {
  flex-grow: 3;
  flex-shrink: 3;
  flex-basis: 10%;
  /* Shorten Code in One Line */
}

.five {
  flex-direction: column;
  flex-wrap: wrap;
  /* Shorten Code in One Line */
}

.example { margin: 10px 20px 15px 20px; }

الفكرة الأساسية

ترتيب قيم margin هو أعلى، يمين، أسفل، يسار؛ لذلك حافظ السطر الأول على القيم الأربع نفسها.

معاني الرموز المستخدمة في الحل

الدوال والوحدات

url()

تطبق وظيفة CSS خاصة داخل قيمة الخاصية.

px

وحدة بكسل CSS.

بنية القاعدة

{

يفتح مجموعة التصريحات.

}

يغلق مجموعة التصريحات.

:

يفصل الخاصية عن القيمة.

;

ينهي تصريح CSS.
