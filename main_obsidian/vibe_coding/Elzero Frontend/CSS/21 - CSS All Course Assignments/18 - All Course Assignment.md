# 18 — CSS Counter and Pseudo-element

> [!question] السؤال الرسمي
> استخدم بنية HTML التالية كما هي دون تعديل، واكتب CSS لعمل الشكل في الصورة. هذا تكليف تحدٍّ، ولا تستخدم `::after`.
>
> ```html
> <ul>
>   <li>Python</li>
>   <li>PHP</li>
>   <li>JavaScript</li>
>   <li>C++</li>
>   <li>C#</li>
>   <li>Java</li>
> </ul>
> ```
>
> ![[vibe_coding/Elzero Frontend/CSS/21 - CSS All Course Assignments/assets/assignment-18-reference.png]]

> [!success]- الإجابة وشرح الحل — اضغط لفتحه
>
> ### الكود الكامل للحل
>
> ```css
> ul {
>   counter-reset: language 10;
>   list-style: none;
>   margin: 0;
>   padding: 0;
>   background: #fff;
>   font: 24px Arial, sans-serif;
> }
>
> li {
>   height: 105px;
>   padding: 0 22px;
>   display: flex;
>   align-items: center;
>   justify-content: space-between;
>   border-bottom: 1px solid #d2d2d2;
>   counter-increment: language 3;
> }
>
> li:last-child {
>   border-bottom: 0;
> }
>
> li::before {
>   order: 2;
>   content: "(" counter(language) ")";
>   width: 75px;
>   height: 75px;
>   display: grid;
>   place-items: center;
>   border-radius: 50%;
>   color: #fff;
>   background: #9c27b0;
>   font: bold 16px Arial, sans-serif;
> }
>
> li:nth-child(even)::before {
>   background: #f44336;
> }
> ```
>
> ### الفكرة الأساسية
>
> يبدأ `counter-reset` العداد من 10، ثم تزيده `counter-increment` بمقدار 3 لكل عنصر؛ لذلك تظهر الأرقام 13 و16 و19 و22 و25 و28.
>
> > [!info]- معاني الرموز المستخدمة في الحل
> >
> > ### محددات CSS
> >
> > #### `ul`
> >
> > يحدد العنصر الذي ستطبق عليه قواعد `CSS`.
> >
> > #### `li`
> >
> > يحدد العنصر الذي ستطبق عليه قواعد `CSS`.
> >
> > #### `li:last-child`
> >
> > يختار عنصرًا بحسب ترتيبه أو علاقته بإخوته.
> >
> > #### `li::before`
> >
> > ينشئ عنصرًا زائفًا لتنسيقه من دون إضافة وسم جديد إلى `HTML`.
> >
> > #### `li:nth-child(even)::before`
> >
> > ينشئ عنصرًا زائفًا لتنسيقه من دون إضافة وسم جديد إلى `HTML`.
> >
> > ### خصائص CSS
> >
> > #### `counter-reset`
> >
> > تبدأ عداد `CSS`. مثال القيمة: `language` 10
> >
> > #### `list-style`
> >
> > تحدد علامة القائمة. مثال القيمة: `none`
> >
> > #### `margin`
> >
> > تضيف مسافة خارجية. مثال القيمة: 0
> >
> > #### `padding`
> >
> > تضيف مساحة داخلية. مثال القيمة: 0
> >
> > #### `background`
> >
> > تضبط الخلفية. مثال القيمة: `#fff`
> >
> > #### `font`
> >
> > تجمع إعدادات الخط. مثال القيمة: `24px` `Arial`, `sans-serif`
> >
> > #### `height`
> >
> > تحدد ارتفاع العنصر. مثال القيمة: `105px`
> >
> > #### `display`
> >
> > تحدد طريقة عرض العنصر. مثال القيمة: `flex`
> >
> > #### `align-items`
> >
> > تحاذي العناصر عرضيًا. مثال القيمة: `center`
> >
> > #### `justify-content`
> >
> > توزع العناصر على المحور الرئيسي. مثال القيمة: `space-between`
> >
> > #### `border-bottom`
> >
> > تحدد قيمة الخاصية `border-bottom`. مثال القيمة: `1px` `solid` `#d2d2d2`
> >
> > #### `counter-increment`
> >
> > تزيد عداد `CSS`. مثال القيمة: `language` 3
> >
> > #### `li`
> >
> > تحدد قيمة الخاصية `li`. مثال القيمة: `last-child` {
> >
> > #### `order`
> >
> > تحدد ترتيب العنصر. مثال القيمة: 2
> >
> > #### `content`
> >
> > تحدد محتوى العنصر الزائف. مثال القيمة: "(" `counter(language)` ")"
> >
> > #### `width`
> >
> > تحدد عرض العنصر. مثال القيمة: `75px`
> >
> > ### الدوال والوحدات
> >
> > #### `counter()`
> >
> > تعرض القيمة الحالية لعداد `CSS`.
> >
> > #### `nth-child()`
> >
> > تختار عنصرًا بحسب ترتيبه بين إخوته، ويمكن استخدام صيغة مثل `n` + 4 لاختيار ما بعد العنصر الثالث.
> >
> > #### `px`
> >
> > وحدة بكسل `CSS`.

> > ### بنية القاعدة
