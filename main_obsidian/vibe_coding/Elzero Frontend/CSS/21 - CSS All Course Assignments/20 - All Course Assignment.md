# 20 — CSS Rounded Badge

> [!question] السؤال الرسمي
> استخدم بنية HTML التالية كما هي دون تعديل، واكتب CSS لعمل الشكل في الصورة.
>
> ```html
> <h1>Elzero</h1>
> ```
>
> ![[vibe_coding/Elzero Frontend/CSS/21 - CSS All Course Assignments/assets/assignment-20-reference.png]]

> [!success]- الإجابة وشرح الحل — اضغط لفتحه
>
> ### الكود الكامل للحل
>
> ```css
> h1 {
>   position: relative;
>   width: 320px;
>   height: 165px;
>   margin: 0;
>   display: grid;
>   place-items: center;
>   border: 5px solid #f44336;
>   border-bottom: 10px solid #111;
>   border-radius: 78px;
>   background: #fff;
>   box-shadow: 0 15px 0 -5px #f44336;
>   color: #111;
>   font: 54px/1 monospace;
> }
>
> h1::before,
> h1::after {
>   content: "";
>   position: absolute;
>   top: 50%;
>   width: 38px;
>   height: 38px;
>   border: 5px solid #f44336;
>   border-radius: 50%;
>   background: #fff;
>   transform: translateY(-50%);
> }
>
> h1::before { left: -55px; }
> h1::after { right: -55px; }
> ```
>
> ### الفكرة الأساسية
>
> تعطي `border-radius` الحواف المستديرة، ويضيف `box-shadow` الشريط الأحمر أسفل الشارة. العنصران الزائفان `::before` و`::after` يرسمان الحلقتين الجانبيتين دون إضافة عناصر إلى `HTML`.
>
> > [!info]- معاني الرموز المستخدمة في الحل
> >
> > ### محددات CSS
> >
> > #### `h1`
> >
> > يحدد العنصر الذي ستطبق عليه قواعد `CSS`.
> >
> > #### `h1::after`
> >
> > ينشئ عنصرًا زائفًا لتنسيقه من دون إضافة وسم جديد إلى `HTML`.
> >
> > ### خصائص CSS
> >
> > #### `position`
> >
> > تحدد طريقة التموضع. مثال القيمة: `relative`
> >
> > #### `width`
> >
> > تحدد عرض العنصر. مثال القيمة: `320px`
> >
> > #### `height`
> >
> > تحدد ارتفاع العنصر. مثال القيمة: `165px`
> >
> > #### `margin`
> >
> > تضيف مسافة خارجية. مثال القيمة: 0
> >
> > #### `display`
> >
> > تحدد طريقة عرض العنصر. مثال القيمة: `grid`
> >
> > #### `place-items`
> >
> > تختصر محاذاة `Grid`. مثال القيمة: `center`
> >
> > #### `border`
> >
> > ترسم الحد وتحدد سمكه ونمطه ولونه. مثال القيمة: `5px` `solid` `#f44336`
> >
> > #### `border-bottom`
> >
> > تحدد قيمة الخاصية `border-bottom`. مثال القيمة: `10px` `solid` `#111`
> >
> > #### `border-radius`
> >
> > تدوّر زوايا العنصر. مثال القيمة: `78px`
> >
> > #### `background`
> >
> > تضبط الخلفية. مثال القيمة: `#fff`
> >
> > #### `box-shadow`
> >
> > ترسم ظل الصندوق. مثال القيمة: 0 `15px` 0 -`5px` `#f44336`
> >
> > #### `color`
> >
> > تحدد لون النص. مثال القيمة: `#111`
> >
> > #### `font`
> >
> > تجمع إعدادات الخط. مثال القيمة: `54px`/1 `monospace`
> >
> > #### `h1`
> >
> > تحدد قيمة الخاصية `h1`. مثال القيمة: `:before`,
> >
> > #### `content`
> >
> > تحدد محتوى العنصر الزائف. مثال القيمة: ""
> >
> > #### `top`
> >
> > تحدد المسافة من أعلى مرجع التموضع. مثال القيمة: `50%`
> >
> > ### الدوال والوحدات
> >
> > #### `translateY()`
> >
> > تحرك العنصر رأسيًا على محور `Y`.
> >
> > #### `px`
> >
> > وحدة بكسل `CSS`.

> > ### بنية القاعدة

> >
> > ينهي تصريح `CSS`.
