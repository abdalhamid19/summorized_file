# CSS All Course Assignment 04

> [!question] المطلوب
> نسّق حقل الهاتف ليطابق الصورة، مع الإبقاء على HTML المعطى حرفيًا دون تعديل.
>
> ```html
> <div class="input-box">
>   <span class="prefix">+20</span>
>   <input type="tel" placeholder="1011001100" />
> </div>
> ```
>
> ![[vibe_coding/Elzero Frontend/CSS/21 - CSS All Course Assignments/assets/assignment-04-reference.png]]

> [!success]- الإجابة وشرح الحل — اضغط لفتحه
>
> ### الكود الكامل للحل
>
> ```css
> * {
>   box-sizing: border-box;
> }
>
> body {
>   min-height: 100vh;
>   margin: 0;
>   display: grid;
>   place-items: center;
>   background: #eee;
>   font-family: Arial, sans-serif;
> }
>
> .input-box {
>   display: flex;
>   width: min(900px, calc(100% - 32px));
>   height: 110px;
>   overflow: hidden;
>   border: 3px solid #ddd;
>   border-radius: 12px;
>   background: #fff;
> }
>
> .prefix {
>   flex: 0 0 130px;
>   display: grid;
>   place-items: center;
>   color: #fff;
>   background: #009688;
>   font-size: 42px;
> }
>
> .input-box input {
>   flex: 1;
>   min-width: 0;
>   border: 0;
>   border-left: 1px solid #009688;
>   outline: 0;
>   padding: 0 28px;
>   font-size: 40px;
> }
>
> .input-box input::placeholder {
>   color: #757575;
>   opacity: 1;
> }
> ```
>
> ### الفكرة الأساسية
>
> الحاوية `display: flex` تضع البادئة والحقل جنبًا إلى جنب، ويملأ الحقل المساحة الباقية بفضل `flex: 1`.
>

> >
> > #### `*`
> >
> > يحدد العنصر الذي ستطبق عليه قواعد `CSS`.

> > يحدد العنصر الذي ستطبق عليه قواعد `CSS`.

> > يستهدف العناصر التي تحمل اسم الصنف المحدد.
> >

> >
> > يستهدف العناصر التي تحمل اسم الصنف المحدد.

> > ### خصائص CSS
> >
> > #### `box-sizing`
> >
> > تحدد حساب أبعاد الصندوق. مثال القيمة: `border-box`
> >
> > #### `min-height`
> >
> > تحدد أقل ارتفاع. مثال القيمة: `100vh`
> >
> > #### `margin`
> >
> > تضيف مسافة خارجية. مثال القيمة: 0
> >
> > #### `display`
> >
> > تحدد طريقة عرض العنصر. مثال القيمة: `grid`
> >
> > #### `place-items`
> >
> > تختصر محاذاة `Grid`. مثال القيمة: `center`
> >
> > #### `background`
> >
> > تضبط الخلفية. مثال القيمة: `#eee`
> >
> > #### `font-family`
> >
> > تحدد عائلة الخط. مثال القيمة: `Arial`, `sans-serif`
> >
> > #### `width`
> >
> > تحدد عرض العنصر. مثال القيمة: `min(900px, calc(100% - 32px)`)
> >
> > #### `height`
> >
> > تحدد ارتفاع العنصر. مثال القيمة: `110px`
> >
> > #### `overflow`
> >
> > تحدد ما يحدث للمحتوى الخارج عن العنصر. مثال القيمة: `hidden`
> >
> > #### `border`
> >
> > ترسم الحد وتحدد سمكه ونمطه ولونه. مثال القيمة: `3px` `solid` `#ddd`
> >
> > #### `border-radius`
> >
> > تدوّر زوايا العنصر. مثال القيمة: `12px`
> >
> > #### `flex`
> >
> > تختصر نمو عنصر `Flex` وحجمه. مثال القيمة: 0 0 `130px`
> >
> > #### `color`
> >
> > تحدد لون النص. مثال القيمة: `#fff`
> >
> > #### `font-size`
> >
> > تحدد حجم النص. مثال القيمة: `42px`
> >
> > #### `min-width`
> >
> > تحدد أقل عرض. مثال القيمة: 0
> >
> > ### الدوال والوحدات
> >
> > #### `min()`
> >
> > تختار أصغر قيمة من القيم المعطاة.
> >
> > #### `calc()`
> >
> > تحسب قيمة من تعبير رياضي، ويمكنها الجمع بين وحدات `CSS` المختلفة.
> >
> > #### `vh`
> >
> > نسبة من ارتفاع نافذة العرض.
> >
> > #### `px`
> >
> > وحدة بكسل `CSS`.
> >
