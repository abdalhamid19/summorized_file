خصائص CSS

box-sizing

تحدد حساب أبعاد الصندوق. مثال القيمة: border-box

margin

تضيف مسافة خارجية. مثال القيمة: 0

background-color

تحدد لون الخلفية. مثال القيمة: #eee

font-family

تحدد عائلة الخط. مثال القيمة: Arial, sans-serif

position

تحدد طريقة التموضع. مثال القيمة: relative

width

تحدد عرض العنصر. مثال القيمة: min(100%, 600px)

height

تحدد ارتفاع العنصر. مثال القيمة: 460px

inset

تحدد المسافات من الحواف. مثال القيمة: 60px 0 0

border-radius

تدوّر زوايا العنصر. مثال القيمة: 20px

background

تضبط الخلفية. مثال القيمة: linear-gradient(to bottom, #ccc 0 25%, #607d8b 25% 75%, #ccc 75% 100%)

z-index

تحدد ترتيب الطبقة؛ الأكبر يظهر فوق الأصغر. مثال القيمة: 2

top

تحدد المسافة من أعلى مرجع التموضع. مثال القيمة: 0

left

تحدد المسافة من اليسار. مثال القيمة: calc(50% - 97px)

clip-path

تحدد قيمة الخاصية clip-path. مثال القيمة: polygon(14% 0, 86% 0, 100% 100%, 0 100%)

display

تحدد طريقة عرض العنصر. مثال القيمة: grid

place-items

تختصر محاذاة Grid. مثال القيمة: center

الدوال والوحدات

min()

تختار أصغر قيمة من القيم المعطاة.

linear-gradient()

تنشئ تدرجًا لونيًا يسير في اتجاه خطي.

calc()

تحسب قيمة من تعبير رياضي، ويمكنها الجمع بين وحدات CSS المختلفة.

polygon()

ترسم شكلًا متعدد الأضلاع من نقاط إحداثية، غالبًا مع clip-path.

translateX()

تحرك العنصر أفقيًا على محور X.

px

وحدة بكسل CSS.
