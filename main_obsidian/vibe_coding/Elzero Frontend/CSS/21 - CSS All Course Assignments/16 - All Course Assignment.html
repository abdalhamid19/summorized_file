الفكرة الأساسية

تضع caption-side: bottom عنوان الجدول أسفله. يلون المحدد tfoot td:first-child خانة Total بالأصفر، وتلون tfoot td:not(:first-child) قيم الإجمالي بالأزرق. يحافظ table-layout: fixed على توزيع الأعمدة.

خصائص CSS

width

تحدد عرض العنصر. مثال القيمة: 100%

max-width

تحدد أقصى عرض. مثال القيمة: 1000px

margin

تضيف مسافة خارجية. مثال القيمة: 0 auto

border-collapse

تحدد قيمة الخاصية border-collapse. مثال القيمة: collapse

table-layout

تحدد قيمة الخاصية table-layout. مثال القيمة: fixed

background-color

تحدد لون الخلفية. مثال القيمة: #fff

font

تجمع إعدادات الخط. مثال القيمة: 16px Arial, sans-serif

th

تحدد قيمة الخاصية th. مثال القيمة: first-child,

td

تحدد قيمة الخاصية td. مثال القيمة: first-child {

padding

تضيف مساحة داخلية. مثال القيمة: 14px 8px

border

ترسم الحد وتحدد سمكه ونمطه ولونه. مثال القيمة: 2px solid #eee

text-align

تحاذي النص. مثال القيمة: center

font-weight

تحدد سُمك الخط. مثال القيمة: 700

color

تحدد لون النص. مثال القيمة: #fff

caption-side

تحدد قيمة الخاصية caption-side. مثال القيمة: bottom

font-size

تحدد حجم النص. مثال القيمة: 22px
