> ### الكود الكامل للحل
>
> ```css
> * {
>   box-sizing: border-box;
> }
>
> body {
>   margin: 0;
>   padding: 13px 18px 18px;
>   background: #eee;
>   color: #000;
>   font: 28px/1.2 Arial, sans-serif;
> }
>
> body > ul {
>   margin: 0;
>   padding: 0;
>   list-style: none;
>   counter-reset: main-item;
> }
>
> body > ul > li {
>   min-height: 80px;
>   margin-bottom: 10px;
>   padding: 10px;
>   background: #fff;
>   line-height: 60px;
>   counter-increment: main-item;
> }
>
> body > ul > li::before {
>   content: counter(main-item);
>   display: inline-flex;
>   align-items: center;
>   justify-content: center;
>   width: 60px;
>   height: 60px;
>   margin-right: 20px;
>   background: #ddd;
>   font-weight: 700;
>   vertical-align: top;
>   line-height: 1;
> }
>
> body > ul > li:nth-child(4) {
>   padding-bottom: 40px;
>   background: #ddd;
> }
>
> body > ul > li:nth-child(4)::before {
>   background: #fff;
> }
>
> body > ul > li > ul {
>   margin: 30px 0 0 30px;
>   padding: 0;
>   list-style: none;
>   counter-reset: sub-item;
> }
>
> body > ul > li > ul > li {
>   height: 80px;
>   margin: 10px 0;
>   padding: 10px;
>   background: #fff;
>   line-height: 60px;
>   counter-increment: sub-item;
> }
>
> body > ul > li > ul > li::before {
>   content: counter(main-item) "." counter(sub-item);
>   display: inline-flex;
>   align-items: center;
>   justify-content: center;
>   width: 60px;
>   height: 60px;
>   margin-right: 20px;
>   color: #fff;
>   background: #009688;
>   font-weight: 700;
>   vertical-align: top;
>   line-height: 1;
> }
> ```
>
> ### الفكرة الأساسية
>
> خاصية `counter-reset` تبدأ العدّاد، و`counter-increment` تزيده لكل عنصر. وتضيف `::before` (عنصرًا وهميًا) رقمًا قبل النص من دون إدخال أرقام أو تغيير بنية `HTML`. العدّاد `main-item` يعطي رقم العنصر الأب، و`sub-item` يكوّن الأرقام مثل `4.1` و`4.2` و`4.3`.

> > ### خصائص CSS
> >
> > #### `box-sizing`
> >
> > تحدد حساب أبعاد الصندوق. مثال القيمة: `border-box`

> >
> > تضيف مسافة خارجية. مثال القيمة: 0

> >
> > تحدد علامة القائمة. مثال القيمة: `none`

> > #### `counter-reset`
> >
> > تبدأ عداد `CSS`. مثال القيمة: `main-item`
> >
> > #### `min-height`
> >
> > تحدد أقل ارتفاع. مثال القيمة: `80px`
> >
> > #### `margin-bottom`
> >
> > تحدد قيمة الخاصية `margin-bottom`. مثال القيمة: `10px`
> >
> > #### `line-height`
> >
> > تحدد المسافة بين الأسطر. مثال القيمة: `60px`
> >
> > #### `counter-increment`
> >
> > تزيد عداد `CSS`. مثال القيمة: `main-item`
> >
> > #### `content`
> >
> > تحدد محتوى العنصر الزائف. مثال القيمة: `counter(main-item)`
> >
> > #### `display`
> >
> > تحدد طريقة عرض العنصر. مثال القيمة: `inline-flex`
> >
> > #### `align-items`
> >
> > تحاذي العناصر عرضيًا. مثال القيمة: `center`
