خصائص CSS

overflow

تحدد ما يحدث للمحتوى الخارج عن العنصر. مثال القيمة: hidden

border-radius

تدوّر زوايا العنصر. مثال القيمة: 10px

background

تضبط الخلفية. مثال القيمة: #fff

height

تحدد ارتفاع العنصر. مثال القيمة: 102px

margin

تضيف مسافة خارجية. مثال القيمة: 0

display

تحدد طريقة عرض العنصر. مثال القيمة: grid

place-items

تختصر محاذاة Grid. مثال القيمة: center

color

تحدد لون النص. مثال القيمة: #fff

font-size

تحدد حجم النص. مثال القيمة: 36px

position

تحدد طريقة التموضع. مثال القيمة: relative

padding

تضيف مساحة داخلية. مثال القيمة: 28px 30px 30px

grid-template-columns

تحدد أعمدة Grid. مثال القيمة: 1fr 1fr

gap

تحدد المسافة بين عناصر التخطيط. مثال القيمة: 80px

content

تحدد محتوى العنصر الزائف. مثال القيمة: &quot;&quot;

top

تحدد المسافة من أعلى مرجع التموضع. مثال القيمة: 35px

bottom

تحدد المسافة من الأسفل. مثال القيمة: 35px

الدوال والوحدات

px

وحدة بكسل CSS.

fr

جزء من مساحة Grid.
