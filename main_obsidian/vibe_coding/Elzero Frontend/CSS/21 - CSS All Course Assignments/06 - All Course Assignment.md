# CSS All Course Assignment 06

> [!question] المطلوب
> لوّن الرابط الذي لا يحمل `class`، حتى لو تغيّر ترتيبه بين الروابط. لا تستخدم محددات المواقع مثل `:last-child` ولا تستعمل أسماء `class` في محدد CSS.

> <a href="https://www.elzero.courses/">Elzero Courses</a>
> ```

> [!success]- الإجابة وشرح الحل — اضغط لفتحه
>
> ### الكود الكامل للحل
>
> ```css
> body {
>   min-height: 100vh;
>   margin: 0;
>   padding: 0 20px;
>   display: flex;
>   align-items: center;
>   gap: 10px;
>   background: #eee;
>   font: 42px/1.2 "Times New Roman", serif;
> }
>
> a {
>   color: #000;
>   text-decoration: none;
> }
>
> a:not([class]) {
>   color: #ff3b30;
>   font-weight: 700;
> }
> ```
>
> ### الفكرة الأساسية
>
> المحدد `:not([class])` يختار رابطًا لا يحمل خاصية `class`، لذلك يبقى الاختيار صحيحًا حتى عند نقل الرابط. لا نعتمد على ترتيبه ولا نكتب أسماء `class` مثل `.url` أو `.link`.
>

> > ### محددات CSS
> >
> > #### `body`
> >
> > يحدد العنصر الذي ستطبق عليه قواعد `CSS`.
> >
> > #### `a`
> >
> > يحدد العنصر الذي ستطبق عليه قواعد `CSS`.
> >
> > #### `a:not([class])`
> >
> > يختار العناصر بحسب خاصية `HTML` أو قيمتها.

> > ### خصائص CSS
> >
> > #### `min-height`
> >
> > تحدد أقل ارتفاع. مثال القيمة: `100vh`
> >
> > #### `margin`
> >
> > تضيف مسافة خارجية. مثال القيمة: 0
> >
> > #### `padding`
> >
> > تضيف مساحة داخلية. مثال القيمة: 0 `20px`
> >
> > #### `display`
> >
> > تحدد طريقة عرض العنصر. مثال القيمة: `flex`
> >
> > #### `align-items`
> >
> > تحاذي العناصر عرضيًا. مثال القيمة: `center`
> >
> > #### `gap`
> >
> > تحدد المسافة بين عناصر التخطيط. مثال القيمة: `10px`
> >
> > #### `background`
> >
> > تضبط الخلفية. مثال القيمة: `#eee`
> >
> > #### `font`
> >
> > تجمع إعدادات الخط. مثال القيمة: `42px`/1.2 "`Times` `New` `Roman`", `serif`
> >
> > #### `color`
> >
> > تحدد لون النص. مثال القيمة: `#000`
> >
> > #### `text-decoration`
> >
> > تضيف أو تزيل خطًا زخرفيًا. مثال القيمة: `none`
> >
> > #### `a`
> >
> > تحدد قيمة الخاصية `a`. مثال القيمة: `not([class])` {
> >
> > #### `font-weight`
> >
> > تحدد سُمك الخط. مثال القيمة: 700
> >
> > ### الدوال والوحدات
> >
> > #### `not()`
> >
> > تستبعد العناصر التي يطابقها المحدد الموجود بين القوسين.

> > #### `vh`
> >
> > نسبة من ارتفاع نافذة العرض.
> >
> > #### `px`
> >
> > وحدة بكسل `CSS`.

> > ### بنية القاعدة
