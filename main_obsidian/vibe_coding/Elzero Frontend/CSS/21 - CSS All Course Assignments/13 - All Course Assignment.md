> > ### خصائص CSS
> >
> > #### `box-sizing`
> >
> > تحدد حساب أبعاد الصندوق. مثال القيمة: `border-box`
> >
> > #### `display`
> >
> > تحدد طريقة عرض العنصر. مثال القيمة: `grid`
> >
> > #### `grid-template-columns`
> >
> > تحدد أعمدة `Grid`. مثال القيمة: `repeat(3, minmax(0, 1fr)`)
> >
> > #### `gap`
> >
> > تحدد المسافة بين عناصر التخطيط. مثال القيمة: `28px`
> >
> > #### `max-width`
> >
> > تحدد أقصى عرض. مثال القيمة: `860px`
> >
> > #### `margin`
> >
> > تضيف مسافة خارجية. مثال القيمة: `25px` `auto`
> >
> > #### `font-family`
> >
> > تحدد عائلة الخط. مثال القيمة: `Arial`, `sans-serif`
> >
> > #### `position`
> >
> > تحدد طريقة التموضع. مثال القيمة: `relative`
> >
> > #### `min-height`
> >
> > تحدد أقل ارتفاع. مثال القيمة: `170px`
> >
> > #### `padding`
> >
> > تضيف مساحة داخلية. مثال القيمة: `20px`
> >
> > #### `border`
> >
> > ترسم الحد وتحدد سمكه ونمطه ولونه. مثال القيمة: `2px` `solid` `transparent`
> >
> > #### `border-radius`
> >
> > تدوّر زوايا العنصر. مثال القيمة: `12px`
> >
> > #### `background-color`
> >
> > تحدد لون الخلفية. مثال القيمة: `#fff`
> >
> > #### `box-shadow`
> >
> > ترسم ظل الصندوق. مثال القيمة: 0 `7px` `17px` `#0003`
> >
> > #### `color`
> >
> > تحدد لون النص. مثال القيمة: `#555`
> >
> > #### `border-color`
> >
> > تحدد قيمة الخاصية `border-color`. مثال القيمة: `#3171ff`
