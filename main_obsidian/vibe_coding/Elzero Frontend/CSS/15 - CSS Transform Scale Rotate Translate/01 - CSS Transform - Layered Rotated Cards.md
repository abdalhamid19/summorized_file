# CSS Transform - Layered Rotated Cards

> [!question] السؤال
> استخدم بنية HTML كما هي. اجعل العنصر 300×200px، ووسّطه أفقيًا، ونسّق الشكل والألوان كما في الصورة.
>
> صورة السؤال:
>
> ![[vibe_coding/Elzero Frontend/CSS/15 - CSS Transform Scale Rotate Translate/assets/reference-task-01.png|650]]

> [!success]- الإجابة وشرح الحل — اضغط لفتحه
>
> ### الكود الكامل للحل
>
> ```css
> .card {
>   position: relative;
>   width: 300px;
>   height: 200px;
>   margin-inline: auto;
>   display: grid;
>   place-items: center;
>   color: #03a9f4;
>   background: #eee;
>   font: bold 34px Georgia, serif;
> }
>
> .card::before,
> .card::after {
>   content: "";
>   position: absolute;
>   inset: 0;
>   z-index: -1;
> }
>
> .card::before { background: #e91e63; transform: rotate(6deg); }
> .card::after { background: #03a9f4; transform: rotate(-6deg); }
> ```
>
> ### الفكرة الأساسية
>
> تُدير `::before` و`::after` الشكلين الملونين خلف البطاقة الأصلية باتجاهين متعاكسين. تبقى الخلفية الرمادية والنص في المقدمة كما في معاينة الصفحة.

> > ### خصائص CSS
> >
> > #### `position`
> >
> > تحدد طريقة التموضع. مثال القيمة: `relative`
> >
> > #### `width`
> >
> > تحدد عرض العنصر. مثال القيمة: `300px`
> >
> > #### `height`
> >
> > تحدد ارتفاع العنصر. مثال القيمة: `200px`
> >
> > #### `margin-inline`
> >
> > تضيف مسافة على جانبي العنصر. مثال القيمة: `auto`
> >
> > #### `display`
> >
> > تحدد طريقة عرض العنصر. مثال القيمة: `grid`
> >
> > #### `place-items`
> >
> > تختصر محاذاة `Grid`. مثال القيمة: `center`
> >
> > #### `color`
> >
> > تحدد لون النص. مثال القيمة: `#03a9f4`
> >
> > #### `background`
> >
> > تضبط الخلفية. مثال القيمة: `#eee`
> >
> > #### `font`
> >
> > تجمع إعدادات الخط. مثال القيمة: `bold` `34px` `Georgia`, `serif`
> >
> > #### `content`
> >
> > تحدد محتوى العنصر الزائف. مثال القيمة: ""
> >
> > #### `inset`
> >
> > تحدد المسافات من الحواف. مثال القيمة: 0
> >
> > #### `z-index`
> >
> > تحدد ترتيب الطبقة؛ الأكبر يظهر فوق الأصغر. مثال القيمة: -1
