# تكليف 01: محددات الصنف والمعرّف واسم الوسم

> [!question] السؤال
> اكتب تعليقًا يوضح ما الذي يختاره كل **CSS Selector** (محدد CSS: نمط يختار عناصر الصفحة المطلوب تنسيقها). أكمل التعليقات الناقصة:
>
> ```css
> /* Any Element With Class Title */
> .title {
> }
>
> /* ? */
> #nav {
> }
>
> /* ? */
> div {
> }
>
> /* ? */
> h2 {
> }
> ```

> [!success]- الإجابة وشرح الحل — اضغط لفتحهما
>
> ```css
> /* أي عنصر يحمل الصنف title */
> .title {
> }
>
> /* العنصر الذي يحمل المعرّف nav */
> #nav {
> }
>
> /* جميع عناصر div */
> div {
> }
>
> /* جميع عناصر h2 */
> h2 {
> }
> ```
>
> - **`.title` — `class selector` (محدد الصنف):** النقطة `.` تعني اختيار أي عنصر يحمل `class="title"`؛ ويمكن لعناصر متعددة أن تحمل الصنف نفسه.
> - **`#nav` — `ID selector` (محدد المعرّف):** علامة `#` تعني اختيار العنصر الذي يحمل `id="nav"`.
> - **`div` و`h2` — `type selector` (محدد نوع الوسم):** كتابة اسم الوسم وحده تختار كل عناصر HTML (وسوم بناء الصفحة) التي تحمل هذا الاسم.
>
> **قاعدة سريعة:** النقطة للصنف، وعلامة `#` للمعرّف، واسم الوسم وحده لاختيار كل العناصر من نوعه.
