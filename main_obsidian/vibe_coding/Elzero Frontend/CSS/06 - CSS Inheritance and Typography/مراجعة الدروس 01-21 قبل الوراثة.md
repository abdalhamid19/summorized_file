# مراجعة دروس CSS 01–21 قبل الدرس 22: Inheritance

الرابط الذي أرسلته هو الدرس **22 — Inheritance (الوراثة)**. هذه مراجعة لموضوعات الدروس 1–21 حسب ترتيب خطة الدورة، مع ربطها بملاحظات CSS الموجودة في المشروع.

> [!tip] الفكرة المحورية
> <span dir="rtl" style="color:#0D9488">ابدأ بتحديد العنصر، ثم افهم صندوقه وطريقة عرضه، وبعدها نسّق النص وما يخرج عن حدود الصندوق.</span>

## 01–04 — أساسيات CSS واختيار العناصر

1. **Introduction and What I Need To Learn?** — تعرّف إلى CSS (**Cascading Style Sheets**؛ قواعد تنسيق شكل صفحة الويب).
2. **Your First Project And Syntax** — قاعدة CSS تتكون من محدد `selector` (يختار العناصر) ثم تصريحات داخل أقواس: خاصية `property` (ما نغيّره) وقيمة `value` (الشكل المطلوب).
3. **Element Styling** — يمكن كتابة التنسيق المضمن `Inline` (على العنصر نفسه)، أو الداخلي `Internal` (داخل صفحة HTML)، أو الخارجي `External` (في ملف CSS مستقل). الملف الخارجي يسهل إعادة استخدام التنسيق وصيانته.
4. **Name Conventions And Rules** — ميّز بين اسم صالح نحويًا واسم مفضّل للقراءة. يستخدم المشروع الاسم `.user-name` كنمط واضح بأحرف صغيرة تفصلها شرطة، ولا تخلط بين `class` (صنف يمكن تكراره) و`id` (معرّف يفترض أن يميز عنصرًا واحدًا).

## 05–08 — الخلفيات والمسافات

5. **Background – Color, Image, Repeat** — اختر لون الخلفية أو صورتها، ثم حدد تكرار الصورة مثل `repeat-x` أفقيًا أو `no-repeat` لإيقاف التكرار. تسمح `rgba()` بتحديد شفافية لون الخلفية دون جعل النص شفافًا.
6. **Background – Attachment, Position, Size** — حدّد هل تتحرك الخلفية مع الصفحة (`scroll`) أو تبقى ثابتة (`fixed`)، وأين تظهر، وكيف تُقاس. `cover` يملأ المساحة وقد يقص جزءًا من الصورة؛ `contain` يعرض الصورة كاملة وقد يترك فراغًا.
7. **Padding** (الحشو) — مساحة داخلية بين المحتوى وحد العنصر.
8. **Margin** (الهامش) — مساحة خارجية تفصل العنصر عمّا حوله. مثال `margin: 20px auto` يوسّط عنصرًا أفقيًا عندما يكون له عرض محدد.

## 09–12 — الحدود وطريقة العرض والظهور

9. **Border** (الحد) — يرسم إطارًا حول صندوق العنصر، ويُضبط بالسمك والنمط واللون.
10. **Outline** (الإطار الخارجي) — يرسم حول العنصر خارج الحد، ولا يحجز مساحة جديدة في ترتيب العناصر.
11. **Display – Block, Inline-Block, Inline** — `block` يبدأ عادةً سطرًا جديدًا ويقبل أبعادًا؛ `inline` يبقى ضمن السطر؛ و`inline-block` يبقى ضمن السطر مع إمكان ضبط أبعاده.
12. **Element Visibility And Use Cases** — `visibility: hidden` يخفي العنصر ويُبقي مكانه، بينما `display: none` يزيله من التخطيط ويزيل الفراغ الذي كان يشغله.

## 13–16 — المحددات والأبعاد والمحتوى الزائد

13. **Grouping Multiple Selectors** — تفصل الفاصلة بين محددات تتشارك قاعدة تنسيق. في تكليف المشروع، تجمع `p` و`& ~ .title` كي يأخذا اللون نفسه.
14. **Nesting** (التداخل) — المسافة في `.child .title` تختار عنوانًا داخل عنصر `.child` ولا تشترط أن يكون ابنًا مباشرًا. وفي تكليف المشروع، يرمز `&` إلى المحدد الأب، بينما `>` يشترط أن يكون `.title` ابنًا مباشرًا. يستخدم الملف صيغة CSS Nesting الحديثة؛ لا أنسب الصيغة الحديثة نفسها تلقائيًا لفيديو 2021.
15. **Dimensions – Width And Height** — `width` و`height` يضبطان العرض والارتفاع، و`min-*` و`max-*` يضعان حدودًا دنيا أو عليا.
16. **Overflow – Overflow-X And Overflow-Y** — تحدد `overflow` ما يحدث للمحتوى الذي يخرج من الصندوق: `visible` يظهره، `hidden` يقصه، و`scroll` أو `auto` يوفّران التمرير. يتحكم `overflow-x` و`overflow-y` بكل محور على حدة.

## 17–21 — تنسيق النص وقصّه

17. **Text – Color And Shadow** — `color` يغيّر لون النص، و`text-shadow` يضيف ظلًا بإزاحة أفقية ورأسية، مع تمويه ولون عند الحاجة.
18. **Text – Alignment** — `text-align` يحاذي النص أفقيًا داخل العنصر؛ لا يوسّط صندوق العنصر نفسه.
19. **Text – Decoration And Transform** — `text-decoration` يضيف خطوطًا مثل التسطير أو يزيلها، و`text-transform` يغيّر شكل الحروف المعروض دون تعديل النص الأصلي في HTML.
20. **Text – Spacing** — `letter-spacing` للمسافة بين الحروف، و`word-spacing` بين الكلمات، و`line-height` لارتفاع السطر، و`text-indent` لإزاحة بداية الفقرة.
21. **Text – Overflow And Use Cases** — لإظهار علامة حذف آلية في سطر واحد، اجمع عرضًا محدودًا مع `white-space: nowrap` و`overflow: hidden` و`text-overflow: ellipsis`. علامة الحذف يضيفها المتصفح، ولا تُكتب يدويًا.

### مثال من ملفات المشروع

في ملاحظة التكليف [[vibe_coding/Elzero Frontend/CSS/05 - CSS Text Formatting/03 - CSS Text Formatting - Text Overflow Ellipsis|Text Overflow Ellipsis]]، يحدد الصندوق بعرض `400px` ثم يستخدم:

```css
#task-03 .ellipsis {
  overflow: hidden;
  white-space: nowrap;
  text-overflow: ellipsis;
}
```

وهذا يجمع درسي الأبعاد والمحتوى الزائد (15–16) مع درس قص النص (21).

## جسر إلى الدرس 22

انتبه إلى الفرق بين الخصائص التي تنتقل من العنصر الأب تلقائيًا، وتلك التي لا تنتقل. في ملاحظة التكليف [[vibe_coding/Elzero Frontend/CSS/06 - CSS Inheritance and Typography/01 - CSS Inheritance of Padding and Border|Inheritance of Padding and Border]]، يطلب الكود من الفقرة `p` أن تأخذ قيم الأب صراحةً:

```css
.parent > p {
  padding: inherit;
  border: inherit;
}
```

هنا تعني `inherit` أن الخاصية تأخذ القيمة المحسوبة من العنصر الأب؛ أما `padding` و`border` فلا تُورثان تلقائيًا.
