المقارنة تعرض تأثير قاعدة الحل على عناصر المثال. شكل الحالة السابقة للتوضيح عندما لم يحدد المصدر شكلًا سابقًا دقيقًا.

الكود الكامل للحل

CSS
.open-sans {
  font-family: "Open Sans", sans-serif;
  font-size: 24px;
  font-weight: 300;
  font-style: italic;
}
.cairo {
  font-family: "Cairo", sans-serif;
  font-size: 24px;
  font-weight: 700;
}
.jomhuria {
  font-family: "Jomhuria", cursive;
  font-size: 32px;
  font-weight: 400;
}

الفكرة الأساسية

font-family يختار شكل الخط، وfont-weight يحدد سماكته، وfont-style يجعل الخط مائلًا عند طلب ذلك. أسماء العائلات وأوزانها الثلاثة مطلوبة؛ أما الأحجام والفئات البديلة فلدعم المعاينة.

معاني الرموز المستخدمة في الحل

Typography

font-family

يحدد عائلة الخط؛ وتأتي بعدها عائلة عامة احتياطية.

font-weight

يحدد وزن الخط الرقمي مثل 300 أو 700.

font-style: italic

يعرض الخط بميلان.

sans-serif / cursive

عائلات عامة يستخدمها المتصفح إذا لم يتوفر الخط المحدد.
