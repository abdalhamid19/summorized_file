CSS Inheritance — Padding and Border

صفحة مستقلة لهذا التكليف: المطلوب، HTML، الحل، الفكرة، الرموز، وشرح CSS سطرًا بسطر.

المطلوب وHTML الأصلي

HTML تمثيلي للشرح؛ صفحة التكليف تشير إلى بنية سابقة ولا تعرضها كنص

<div class="parent">
  <p>الابن يرث padding وborder من الأب</p>
</div>
افتح صورة السؤال من الموقع الرسمي

المطلوب

استخدم البنية السابقة دون تعديلها. اجعل أي تغيير في padding أو border للعنصر الأب div ينتقل إلى العنصر الابن p من دون إعادة ضبط الابن يدويًا.

لم تعرض صفحة التكليف البنية السابقة كاملة، لذلك وُسِمت بنية HTML في الصفحة بأنها تمثيلية. صورة الحل المحلية توضح سلوك الوراثة، أما صورة السؤال الأصلية فتعذّر حفظها من الموقع.

معاينة قبل وبعد

قبل — حالة توضيحية

الفقرة داخل الأب

بعد — تطبيق الحل

الفقرة داخل الأب

المقارنة تعرض تأثير قاعدة الحل على عناصر المثال. شكل الحالة السابقة للتوضيح عندما لم يحدد المصدر شكلًا سابقًا دقيقًا.

الكود الكامل للحل

CSS
.parent {
  padding: 20px;
  border: 3px solid #147d73;
}
.parent > p {
  padding: inherit;
  border: inherit;
}

الفكرة الأساسية

خاصيتا padding وborder لا تُورثان تلقائيًا في CSS. نطلب الوراثة صراحةً بقيمة inherit على p، فيأخذ القيم المحسوبة من div الأب عند تغييرها.

معاني الرموز المستخدمة في الحل

Inheritance

inherit

يجعل الخاصية تأخذ القيمة المحسوبة من العنصر الأب.

padding

مساحة داخلية بين المحتوى وحد العنصر.

border

الحد المرئي حول العنصر.

علاقة HTML وCSS

.parent

يختار العنصر الأب الذي يحمل الصنف parent.

>

يشترط أن يكون p ابنًا مباشرًا للأب.

p

محدد نوع يختار الفقرة.

شرح الحل سطرًا بسطر 
.parent {
  padding: 20px;
  border: 3px solid #147d73;
}
.parent > p {
  padding: inherit;
  border: inherit;
}
