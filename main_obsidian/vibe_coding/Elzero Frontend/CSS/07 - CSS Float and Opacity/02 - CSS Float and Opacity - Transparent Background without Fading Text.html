المطلوب

استخدم البنية المحددة. اجعل خلفية العناصر الثلاثة واحدة، وخلفية العنصرين الأخيرين بشفافية 0.1، مع بقاء النص واضحًا.

لم أتمكن من التحقق من قيمة لون الخلفية في صورة المرجع. أبقيت لون الحل المحلي #009688 مع الإشارة إلى أن المطابقة اللونية غير مؤكدة.

المقارنة تعرض تأثير قاعدة الحل على عناصر المثال. شكل الحالة السابقة للتوضيح عندما لم يحدد المصدر شكلًا سابقًا دقيقًا.

الكود الكامل للحل

CSS
#task-02 .stage > div {
  box-sizing: border-box;
  width: 300px;
  margin: 20px auto;
  padding: 20px;
  color: black;
  font-weight: bold;
  font-size: 1rem;
  background-color: #009688;
}
#task-02 .stage > .one,
#task-02 .stage > .two {
  background-color: rgba(0, 150, 136, 0.1);
}

الفكرة الأساسية

نستخدم rgba() لتغيير شفافية لون الخلفية وحدها. أما opacity فتؤثر في العنصر كله بما فيه النص، لذلك تبقى الكتابة معتمة وواضحة عند ضبط alpha داخل لون الخلفية.

معاني الرموز المستخدمة في الحل

RGBA background

rgba(red, green, blue, alpha)

تحدد قنوات اللون الثلاث ثم قيمة الشفافية من 0 إلى 1.

0.1

يعني أن الخلفية تحتفظ بعُشر عتامتها تقريبًا.

opacity

تؤثر في العنصر ومحتواه كله؛ لهذا لا نستخدمها هنا.

Selectors and grouping

.stage > div

.one, .two

الفاصلة تجمع محددين لتطبيق قاعدة الخلفية الشفافة على الاثنين.
