CSS Float and Opacity — Dynamic Float Grid with calc()

صفحة مستقلة لهذا التكليف: المطلوب، HTML، الحل، الفكرة، الرموز، وشرح CSS سطرًا بسطر.

المطلوب وHTML الأصلي

المطلوب

اجعل عرض العنصر الأب 800px بلا padding، والفواصل الأفقية والرأسية 15px. اجعل عرض العناصر ديناميكيًا، ثم غيّر عرض الأب إلى 1000px وتأكد أن التخطيط يبقى سليمًا.

عدد الأعمدة والعناصر في المعاينة تقدير محفوظ من الحل السابق وليس موضحًا في النص الرسمي. صورة التكليف الأصلية محجوبة عند تنزيلها؛ لذلك لا أؤكد أن هذا الجزء يطابق شكلها.

المقارنة تعرض تأثير قاعدة الحل على عناصر المثال. شكل الحالة السابقة للتوضيح عندما لم يحدد المصدر شكلًا سابقًا دقيقًا.

الكود الكامل للحل

CSS
#task-01 .parent {
  width: 800px;
  margin: 0 auto;
  --gap: 15px;
}
#task-01 .parent::after {
  content: "";
  display: block;
  clear: both;
}
#task-01 .item {
  float: left;
  box-sizing: border-box;
  width: calc((100% - 3 * var(--gap)) / 4);
  min-height: 100px;
  margin: 0 var(--gap) var(--gap) 0;
}
#task-01 .item:nth-child(4n) { margin-right: 0; }
@media (min-width: 900px) {
  #task-01 .parent { width: 1000px; }
}

الفكرة الأساسية

تحسب calc() عرض الأعمدة اعتمادًا على عرض الأب، بعد طرح الفواصل الأفقية، فيظل التخطيط قابلًا للتغيير. يزيل nth-child الفاصل عن آخر عنصر في كل صف، ويجعل clear الأب يحتوي العناصر العائمة.

معاني الرموز المستخدمة في الحل

CSS custom property and calc()

--gap: 15px

يخزن قياس الفاصل في متغير CSS لإعادة استخدامه.

calc((100% - 3 * var(--gap)) / 4)

يطرح ثلاثة فواصل من عرض الأب ثم يقسم المساحة على أربعة أعمدة.

var(--gap)

يستدعي قيمة المتغير --gap.

Float and clearing

float: left

يرتب العنصر العائم إلى اليسار ويسمح بتجاور العناصر.

clear: both

يمنع العنصر التالي من الالتفاف حول أي عناصر عائمة سابقة.

::after

ينشئ عنصرًا زائفًا بعد محتوى الأب.

Grid-like placement

:nth-child(4n)

يختار كل عنصر رابع، أي نهاية كل صف من أربعة أعمدة.

@media (min-width: 900px)

يطبق تغيير عرض الأب عندما يبلغ viewport هذا العرض.
