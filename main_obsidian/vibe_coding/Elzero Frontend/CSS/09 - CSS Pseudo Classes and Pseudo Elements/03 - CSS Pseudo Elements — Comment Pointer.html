03 - CSS Pseudo Elements — Comment Pointer

المطلوب بجوار HTML المعاينة، ثم مقارنة النتيجة قبل قواعد CSS وبعدها. الشرح العربي من اليمين إلى اليسار، وكل HTML وCSS إنجليزي من اليسار إلى اليمين.

المطلوب وHTML المستخدم في المعاينة

المطلوب في التكليف

نسّق ثلاثة تعليقات، وأضف لسانًا مثلثًا على الحافة اليسرى لكل تعليق باستخدام pseudo-element.

HTML المعروض في صفحة المعاينة

صفحة التكليف تعرض المعايير والصورة المرجعية، ولا تتضمن بنية HTML السابقة المشار إليها؛ لذلك يستخدم ملف المعاينة عناصر بديلة لإعادة بناء الشكل.

المعاينة البصرية قبل الحل وبعده

Before CSS

البنية المحلية نفسها قبل إضافة قواعد حل هذا التكليف.

After CSS

البنية المحلية نفسها بعد تطبيق تنسيق المعاينة.

الكود الكامل للحل

CSS الكامل لهذا التكليف، مستقل وباتجاه القراءة من اليسار إلى اليمين.

.comment {
  position: relative;
  border-left: 5px solid #e91e63;
  background: #eee;
  padding: 20px 24px;
}

.comment::before {
  content: "";
  position: absolute;
  left: -30px;
  top: 50%;
  transform: translateY(-50%);
  border: 15px solid transparent;
  border-right-color: #e91e63;
}

الفكرة الأساسية

نرسم لسان التعليق من حدود ::before الشفافة. تلوين حد واحد فقط يجعل الجزء الملون مثلثًا، ثم تنقله transform إلى منتصف ارتفاع التعليق.

المحددات في CSS

  • .comment

    يستهدف العناصر التي تحمل اسم الفئة في المحدد.

  • .comment::before

    يختار عنصرًا زائفًا ينشأ قبل المحتوى لإضافة علامة أو نص. يستهدف العناصر التي تحمل اسم الفئة في المحدد.

Pseudo-classes and Pseudo-elements

CSS Positioning

position: relative
تختار طريقة التموضع؛ تستخدم هنا لإخراج العنصر من التدفق أو جعله مرجعًا للعناصر داخله.
left: -30px
تحدد المسافة من الحافة اليسرى.
top: 50%
تحدد المسافة من أعلى مرجع التموضع.

Borders and Shadows

border-left: 5px solid #e91e63
ترسم الحد الأيسر.
border: 15px solid transparent
ترسم حدًا وتحدد سمكه ونمطه ولونه.

Color and Typography

background: #eee
تحدد خلفية العنصر، ومنها اللون أو التدرج.

Dimensions and Spacing

padding: 20px 24px
تحدد المساحة الداخلية بين المحتوى والحد.

Pseudo-elements and Counters

content: ""
ينشئ محتوى فارغًا حتى يمكن رسم الشكل الزخرفي بالحدود.

Transitions and Transforms

transform: translateY(-50%)
تحرك العنصر دون تعديل تدفق الصفحة.

Other

border-right-color: #e91e63
تضبط هذه الخاصية القيمة #e91e63.

علامات صياغة CSS

  • {}

    تجمع الأقواس قواعد المحدد وتحدد بداية القاعدة ونهايتها.

  • :

    تفصل النقطتان بين اسم الخاصية وقيمتها.

  • ;

    تنهي الفاصلة المنقوطة تصريح CSS.

  • ::

    تشير إلى عنصر زائف تنشئه CSS مثل before.

  • px

    وحدات للمقاس أو النسبة أو الزمن؛ مثل px للبكسل وfr لجزء من المساحة المتاحة.
