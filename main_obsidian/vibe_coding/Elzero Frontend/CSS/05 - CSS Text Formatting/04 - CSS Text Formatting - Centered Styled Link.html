المطلوب

استخدم الرابط الأصلي دون تعديل HTML. ضعه في منتصف الصفحة تمامًا ونسّق ألوانه وشكله كما في الصورة المرجعية.

ألوان المعاينة وأبعاد الزر هي القيم الموجودة في الحل السابق. صورة المصدر الرسمية غير محفوظة محليًا ولا أؤكد تطابق هذه القيم معها.

معاينة قبل وبعد

قبل — حالة توضيحية
elzero
بعد — تطبيق الحل
elzero

المقارنة تعرض تأثير قاعدة الحل على عناصر المثال. شكل الحالة السابقة للتوضيح عندما لم يحدد المصدر شكلًا سابقًا دقيقًا.

الكود الكامل للحل

CSS
#task-04 {
  min-height: 260px;
  display: grid;
  place-items: center;
}
#task-04 a {
  padding: 18px 30px;
  border-radius: 8px;
  background: #009688;
  color: #fff;
  font: 700 24px Arial, sans-serif;
  text-decoration: none;
}

الفكرة الأساسية

نحوّل الحاوية إلى Grid ونستخدم place-items لتوسيط الرابط أفقيًا ورأسيًا. بعد ذلك نضيف مساحة داخلية وخلفية ولونًا للرابط، ونزيل خطه السفلي.

معاني الرموز المستخدمة في الحل

Grid alignment

display: grid

ينشئ حاوية Grid لعنصر الرابط.

place-items: center

يوسّط العنصر داخل مساحة الحاوية أفقيًا ورأسيًا.

min-height

يوفر ارتفاعًا كافيًا لتظهر عملية التوسيط في المعاينة.

تنسيق الرابط

a

محدد نوع يختار عنصر الرابط.

padding: 18px 30px

القيمة الأولى للحشو الرأسي والثانية للأفقي.

border-radius

يليّن زوايا الخلفية.
