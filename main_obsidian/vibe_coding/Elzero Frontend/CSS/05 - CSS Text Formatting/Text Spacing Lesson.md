# <bdi dir="ltr">CSS</bdi> — <bdi dir="ltr">Text Spacing</bdi>

في مثال الدرس، تغيّر <bdi dir="ltr">word-spacing</bdi> المسافة بين الكلمات في العبارة المتكررة. حرّك الأشرطة في المعاينة لتقارنها بالمسافة بين الحروف وارتفاع السطر وإزاحة بداية الفقرة.

## كود الدرس

```css
div {
  background-color: #f9f9f9;
  word-spacing: 5px;
}
```

## معنى الخصائص

- <bdi dir="ltr">word-spacing</bdi>: تغيّر المسافة بين الكلمات. في كود الدرس قيمتها <bdi dir="ltr">5px</bdi>.
- <bdi dir="ltr">letter-spacing</bdi>: تغيّر المسافة بين الحروف.
- <bdi dir="ltr">line-height</bdi>: تحدد ارتفاع السطر، فتزيد أو تقل المسافة الرأسية بين أسطر النص.
- <bdi dir="ltr">text-indent</bdi>: تزحزح بداية السطر الأول من الفقرة إلى الداخل.

الخصائص الثلاث الأخيرة ظاهرة في التجربة لتوضيح مصطلحات المسافات التي وردت في تعليق الدرس؛ كود الدرس المعروض هنا يستخدم <bdi dir="ltr">word-spacing</bdi> فقط.
