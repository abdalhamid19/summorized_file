افتح صورة السؤال من الموقع الرسمي

المطلوب

أنشئ الشكل الظاهر في صورة التكليف، مع استخدام الألوان نفسها. تلميح المصدر: يمكن إضافة أكثر من ظل داخل خاصية واحدة.

الصورة الرسمية لا تتوفر ضمن الملفات المحلية، والموقع حجب طلب تنزيلها. لذلك تعرض الصفحة مثال الظلال بالقيم المحفوظة سابقًا، ولا تزعم مطابقة اللون المرجعي.

معاينة قبل وبعد

قبل — حالة توضيحية

Elzero

بعد — تطبيق الحل

Elzero

المقارنة تعرض تأثير قاعدة الحل على عناصر المثال. شكل الحالة السابقة للتوضيح عندما لم يحدد المصدر شكلًا سابقًا دقيقًا.

الكود الكامل للحل

CSS
#task-01 .text-shadow {
  color: #222;
  text-shadow:
    2px 2px 0 #e91e63,
    -2px -2px 0 #2196f3,
    4px 4px 0 #ff9800;
}

الفكرة الأساسية

تقبل text-shadow عدة ظلال في تصريح واحد. لكل ظل إزاحة أفقية ورأسية ولون، وتسمح الفواصل بتراكب الألوان حول النص. قيم الألوان هنا هي القيم الموجودة في الحل المحلي، لكن لا يمكن تأكيد مطابقتها للصورة الرسمية المحجوبة.

معاني الرموز المستخدمة في الحل

Text formatting

text-shadow

تضيف ظلًا للنص من دون إنشاء عناصر إضافية.

2px 2px 0 color

يمثل الإزاحة الأفقية ثم الرأسية ثم التمويه ثم اللون.

الفاصلة ,

تفصل ظلًا عن الظل الذي يليه داخل القيمة نفسها.
