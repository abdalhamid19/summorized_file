# مراجعة دورة CSS — الدروس 01–26

اختبار سريع يغطي درسًا واحدًا لكل سؤال، بالترتيب من 1 إلى 26. افتح صندوق الإجابة المطوي بعد محاولة الحل؛ يحتوي الإجابة ومثالًا توضيحيًا.

المصدر: [صفحة دورة CSS في أكاديمية الزيرو](https://elzero.org/category/courses/css-course/). عناوين الدروس بالإنجليزية لتطابق أسماء موضوعاتها في المصدر، والشرح بالعربية.

## 01–06 — الأساسيات والخلفيات

**1 — `Introduction And What I Need To Learn?` — المقدمة:** ما وظيفة `CSS` في صفحة الويب؟

> [!faq]- الإجابة مع مثال
> تتحكم `CSS` في مظهر عناصر الصفحة وتنسيقها، مثل الألوان والخطوط والمسافات.
>
> ```css
> p {
>   color: blue;
> }
> ```
>
> يجعل هذا لون نص الفقرة أزرق.
>

**2 — `Your First Project And Syntax` — المشروع الأول والصيغة:** ممَّ تتكوّن قاعدة `CSS` الأساسية؟

> [!faq]- الإجابة مع مثال
> تتكوّن من محدِّد `selector` يختار العنصر، ثم أقواس معقوفة تضم الخاصية والقيمة.
>
> ```css
> h1 {
>   color: green;
> }
> ```
>
> يختار `h1` العناوين بهذا الوسم ويغيّر لونها.
>

**3 — `Elements Styling` — تنسيق العناصر:** كيف تختار كل عناصر الفقرة `p` لتنسيقها؟

> [!faq]- الإجابة مع مثال
> اكتب اسم الوسم كمحدِّد:
>
> ```css
> p {
>   color: navy;
> }
> ```
>
> هذا يطبّق اللون على عناصر الفقرة.
>

**4 — `Name Conventions And Rules` — قواعد التسمية:** كيف تختار عنصرًا يحمل `class="card"`؟

> [!faq]- الإجابة مع مثال
> استخدم نقطة قبل اسم الفئة:
>
> ```css
> .card {
>   border: 1px solid black;
> }
> ```
>
> يختار `.card` كل عنصر يحمل `class="card"`.
>

**5 — `Background – Color, Image, Repeat` — الخلفية: اللون والصورة والتكرار:** ما الخاصية التي تغيّر لون خلفية العنصر؟

> [!faq]- الإجابة مع مثال
> الخاصية هي `background-color`.
>
> ```css
> .card {
>   background-color: lightblue;
> }
> ```
>
> يجعل خلفية العنصر زرقاء فاتحة.
>

**6 — `Background – Attachment, Position, Size` — تثبيت الخلفية وموضعها وحجمها:** ما الخاصية التي تحدد موضع صورة الخلفية داخل العنصر؟

> [!faq]- الإجابة مع مثال
> الخاصية هي `background-position`.
>
> ```css
> .hero {
>   background-position: center;
> }
> ```
>
> يجعل موضع صورة الخلفية في وسط العنصر.
>

## 07–12 — المسافات والحدود وطريقة العرض

**7 — `Padding` — الحشو الداخلي:** أين توجد المسافة التي تضيفها `padding`؟

> [!faq]- الإجابة مع مثال
> توجد بين محتوى العنصر وحدوده، أي داخل العنصر.
>
> ```css
> .card {
>   padding: 16px;
> }
> ```
>
> يضيف مسافة داخلية حول محتوى البطاقة.
>

**8 — `Margin` — الهامش الخارجي:** ماذا تفعل خاصية `margin`؟

> [!faq]- الإجابة مع مثال
> تضيف مسافة خارج حدود العنصر، فتفصله عن العناصر المحيطة.
>
> ```css
> .card {
>   margin: 20px;
> }
> ```
>
> يضيف مسافة خارجية مقدارها `20px` حول البطاقة.
>

**9 — `Border` — الحدود:** كيف تضيف حدًا أسود متصلًا بسمك بكسل واحد؟

> [!faq]- الإجابة مع مثال
> استخدم خاصية `border` المختصرة:
>
> ```css
> .box {
>   border: 1px solid black;
> }
> ```
>
> القيم تحدد السمك والنمط واللون بالترتيب.
>

**10 — `Outline` — الإطار الخارجي:** ما الخاصية التي تضيف إطارًا خارج حدود العنصر؟

> [!faq]- الإجابة مع مثال
> الخاصية هي `outline`.
>
> ```css
> button {
>   outline: 2px solid blue;
> }
> ```
>
> يرسم إطارًا أزرق حول الزر.
>

**11 — `Display – Block, Inline-Block, Inline` — طريقة عرض العناصر:** ما الفرق الأساسي بين `block` و`inline`؟

> [!faq]- الإجابة مع مثال
> عنصر `block` يبدأ عادةً بسطر جديد ويشغل العرض المتاح، أما `inline` فيبقى ضمن السطر ويأخذ مساحة محتواه.
>
> ```css
> span {
>   display: block;
> }
> ```
>
> يجعل عنصر `span` يبدأ في سطر جديد ويتصرف كعنصر كتلي.
>

**12 — `Element Visibility And Use Case` — إظهار العناصر وإخفاؤها:** ما الفرق بين `display: none` و`visibility: hidden`؟

> [!faq]- الإجابة مع مثال
> `display: none` يخفي العنصر ويزيل مساحته من التخطيط، أما `visibility: hidden` فيخفيه مع إبقاء مساحته.
>
> ```css
> .hidden {
>   visibility: hidden;
> }
> ```
>
> العنصر لا يظهر، لكن مكانه يظل محجوزًا.
>

## 13–16 — المحددات والأبعاد والتجاوز

**13 — `Grouping Multiple Selectors` — تجميع المحددات:** كيف تطبّق التنسيق نفسه على `h1` و`p`؟

> [!faq]- الإجابة مع مثال
> اكتب المحددين وافصل بينهما بفاصلة:
>
> ```css
> h1,
> p {
>   color: purple;
> }
> ```
>
> يطبّق اللون نفسه على العناوين والفقرات.
>

**14 — `Nesting` — التداخل:** كيف تختار الفقرات الموجودة داخل عنصر فئته `box`؟

> [!faq]- الإجابة مع مثال
> استخدم محددًا مركبًا: `.box p`.
>
> ```css
> .box p {
>   color: gray;
> }
> ```
>
> يستهدف الفقرات داخل عنصر `box`.
>

**15 — `Dimensions – Width And Height` — الأبعاد: العرض والارتفاع:** ما الخاصيتان الأساسيتان لتحديد عرض العنصر وارتفاعه؟

> [!faq]- الإجابة مع مثال
> `width` تحدد العرض، و`height` تحدد الارتفاع.
>
> ```css
> .box {
>   width: 200px;
>   height: 100px;
> }
> ```
>
> يجعل أبعاد العنصر 200 بكسل عرضًا و100 بكسل ارتفاعًا.
>

**16 — `Overflow – Overflow-X And Overflow-Y` — تجاوز المحتوى أفقيًا ورأسيًا:** ماذا تفعل `overflow: hidden` إذا زاد المحتوى على مساحة العنصر؟

> [!faq]- الإجابة مع مثال
> تخفي الجزء الزائد عن حدود العنصر.
>
> ```css
> .box {
>   width: 100px;
>   height: 50px;
>   overflow: hidden;
> }
> ```
>
> أي محتوى يتجاوز مساحة الصندوق لن يظهر خارجه.
>

## 17–22 — تنسيق النص والتوريث

**17 — `Text – Color And Shadow` — النص: اللون والظل:** ما الخاصية التي تضيف ظلًا إلى النص؟

> [!faq]- الإجابة مع مثال
> الخاصية هي `text-shadow`.
>
> ```css
> h1 {
>   text-shadow: 2px 2px 4px gray;
> }
> ```
>
> يضيف ظلًا رماديًا للنص.
>

**18 — `Text – Alignment` — محاذاة النص:** ما الخاصية التي تُستخدم لمحاذاة النص إلى الوسط؟

> [!faq]- الإجابة مع مثال
> استخدم `text-align: center`.
>
> ```css
> p {
>   text-align: center;
> }
> ```
>
> يضع نص الفقرة في وسط المساحة المتاحة.
>

**19 — `Text – Decoration And Transform` — زخرفة النص وتحويله:** كيف تزيل الخط الذي يظهر أسفل الرابط؟

> [!faq]- الإجابة مع مثال
> استخدم `text-decoration: none`.
>
> ```css
> a {
>   text-decoration: none;
> }
> ```
>
> يزيل الخط الافتراضي أسفل الرابط.
>

**20 — `Text – Spacing` — المسافات في النص:** ما الخاصية التي تتحكم في المسافة بين الحروف؟

> [!faq]- الإجابة مع مثال
> الخاصية هي `letter-spacing`.
>
> ```css
> h2 {
>   letter-spacing: 2px;
> }
> ```
>
> يزيد المسافة بين حروف العنوان بمقدار بكسلين.
>

**21 — `Text – Overflow And Use Cases` — تجاوز النص واستخداماته:** كيف تعرض نقاط الحذف عندما يكون النص أطول من المساحة المتاحة؟

> [!faq]- الإجابة مع مثال
> استخدم `text-overflow: ellipsis` مع منع التفاف النص وإخفاء الجزء الزائد.
>
> ```css
> .title {
>   width: 120px;
>   white-space: nowrap;
>   overflow: hidden;
>   text-overflow: ellipsis;
> }
> ```
>
> إذا زاد النص على عرض العنصر، تظهر نقاط الحذف بدلًا من بقيته.
>

**22 — `Inheritance` — التوريث:** ماذا يعني أن خاصية `CSS` موروثة؟

> [!faq]- الإجابة مع مثال
> يعني أن العنصر الابن يأخذ قيمة الخاصية من العنصر الأب تلقائيًا، إذا كانت الخاصية تقبل التوريث ولم تُحدَّد قيمة مختلفة للابن.
>
> ```css
> .parent {
>   color: blue;
> }
> ```
>
> النص داخل العناصر الأبناء يرث اللون الأزرق عادةً.
>

## 23–26 — الخط ومؤشر الفأرة

**23 — `Typography – Font Family` — تنسيق الخط: عائلة الخط:** ما الخاصية التي تحدد عائلة الخط؟

> [!faq]- الإجابة مع مثال
> الخاصية هي `font-family`.
>
> ```css
> p {
>   font-family: Arial, sans-serif;
> }
> ```
>
> يطلب من المتصفح استخدام `Arial` أو خط بديل من عائلة `sans-serif`.
>

**24 — `Typography – Font Size And CSS Units` — حجم الخط ووحدات CSS:** ما الفرق بين `em` و`px` عند تحديد حجم الخط؟

> [!faq]- الإجابة مع مثال
> `em` وحدة نسبية تتأثر بحجم خط العنصر الأب، بينما `px` تحدد الحجم بالبكسل.
>
> ```css
> .parent {
>   font-size: 20px;
> }
>
> .child {
>   font-size: 1.5em;
> }
> ```
>
> حجم خط الابن هنا يساوي `1.5` من حجم الأب، أي `30px` في هذا المثال.
>

**25 — `Typography – Font Style, Variant, Weight` — نمط الخط وشكله ووزنه:** ما الخاصية التي تتحكم في وزن الخط، مثل جعله عريضًا؟

> [!faq]- الإجابة مع مثال
> الخاصية هي `font-weight`.
>
> ```css
> p {
>   font-weight: bold;
> }
> ```
>
> يجعل نص الفقرة عريضًا.
>

**26 — `Mouse Cursor` — مؤشر الفأرة:** كيف تجعل المؤشر يظهر كيد عند المرور فوق زر؟

> [!faq]- الإجابة مع مثال
> استخدم `cursor: pointer`.
>
> ```css
> button {
>   cursor: pointer;
> }
> ```
>
> يظهر المؤشر على شكل يد عند المرور فوق الزر.
>
