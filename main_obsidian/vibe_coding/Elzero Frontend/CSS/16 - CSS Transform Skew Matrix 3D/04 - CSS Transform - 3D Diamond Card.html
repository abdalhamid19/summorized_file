المطلوب

اجعل العنصر 200×200px، ووسّطه رأسيًا وأفقيًا، ثم كوّن الشكل والألوان في الصورة المرجعية.

بعد تطبيق الحل

تستخدم المقارنة البنية الواردة في السؤال أو معاينة المجموعة المحفوظة. راجع نص المطلوب للتحقق من القيم المحددة.

الكود الكامل للحل

CSS
.card {
  position: relative;
  width: 200px;
  height: 200px;
  margin: auto;
  display: flex;
  align-items: flex-end;
  padding: 8px;
  color: white;
  background: #607d8b;
  perspective: 600px;
}

.card::before {
  content: "";
  position: absolute;
  width: 200px;
  height: 200px;
  left: 0;
  top: -100px;
  z-index: 1;
  background: #000;
  border: 2px solid white;
  transform: rotate(45deg);
}

الفكرة الأساسية

يحوّل rotate(45deg) المربع الأسود إلى شكل ماسي. يتموضع فوق البطاقة الزرقاء الرمادية مع حد أبيض، ويظل النص أسفل البطاقة. استخدم حاوية display: grid; place-items: center; min-height: 100vh لتوسيط العنصرين في الشاشة.

معاني الرموز المستخدمة في الحل

محددات CSS

.card

يستهدف العناصر التي تحمل اسم الصنف المحدد.

.card::before

ينشئ عنصرًا زائفًا لتنسيقه من دون إضافة وسم جديد إلى HTML.

خصائص CSS

position

تحدد طريقة التموضع. مثال القيمة: relative

width

تحدد عرض العنصر. مثال القيمة: 200px

height

تحدد ارتفاع العنصر. مثال القيمة: 200px

margin

تضيف مسافة خارجية. مثال القيمة: auto

display

تحدد طريقة عرض العنصر. مثال القيمة: flex

align-items

تحاذي العناصر عرضيًا. مثال القيمة: flex-end

padding

تضيف مساحة داخلية. مثال القيمة: 8px

color

تحدد لون النص. مثال القيمة: white

background

تضبط الخلفية. مثال القيمة: #607d8b

perspective

تحدد قيمة الخاصية perspective. مثال القيمة: 600px

content

تحدد محتوى العنصر الزائف. مثال القيمة: &quot;&quot;

left

تحدد المسافة من اليسار. مثال القيمة: 0

top

تحدد المسافة من أعلى مرجع التموضع. مثال القيمة: -100px

z-index

تحدد ترتيب الطبقة؛ الأكبر يظهر فوق الأصغر. مثال القيمة: 1

border

ترسم الحد وتحدد سمكه ونمطه ولونه. مثال القيمة: 2px solid white

transform

تطبق دورانًا أو تحريكًا أو تحجيمًا. مثال القيمة: rotate(45deg)

الدوال والوحدات

rotate()

تدير العنصر بالزاوية المحددة.

px

وحدة بكسل CSS.

deg

درجة زاوية.
