# CSS Transform - Variable Color Skew Shape

> [!question] السؤال
> استخدم البنية السابقة، واجعل عرض العنصر 150px، ووسّطه أفقيًا، وعرّف اللون الأساسي بمتغير CSS. طابق الشكل والألوان المرجعية.
>
> صورة السؤال:
>
> ![[vibe_coding/Elzero Frontend/CSS/16 - CSS Transform Skew Matrix 3D/assets/reference-task-01.png|650]]

> [!success]- الإجابة وشرح الحل — اضغط لفتحه
>
> ### الكود الكامل للحل
>
> ```css
> .shape {
>   --main-color: #ff5722;
>   width: 150px;
>   height: 140px;
>   margin-inline: auto;
>   display: grid;
>   place-items: center;
>   color: white;
>   background: var(--main-color);
>   clip-path: polygon(0 0, 50% 13%, 100% 0, 91% 50%, 100% 100%, 50% 87%, 0 100%, 9% 50%);
> }
> ```
>
> ### الفكرة الأساسية
>
> يقص `clip-path` الزوايا للداخل والخارج لتكوين شكل الساعة الرملية الظاهر. المتغير `--main-color` يحقق شرط تحديد اللون الأساسي من قيمة واحدة. العرض في الصورة المرجعية يقارب `210px`؛ صفحة التكليف النصية تذكر `150px`، لذا اعتمدت `150px` في ملاحظة السؤال وأبقيت قيمة المثال توضيحية.
>
> > [!info]- معاني الرموز المستخدمة في الحل
> >
> > ### محددات CSS
> >
> > #### `.shape`
> >
> > يستهدف العناصر التي تحمل اسم الصنف المحدد.
> >
> > ### خصائص CSS
> >
> > #### `--main-color`
> >
> > تحدد قيمة الخاصية `--main-color`. مثال القيمة: `#ff5722`
> >
> > #### `width`
> >
> > تحدد عرض العنصر. مثال القيمة: `150px`
> >
> > #### `height`
> >
> > تحدد ارتفاع العنصر. مثال القيمة: `140px`
> >
> > #### `margin-inline`
> >
> > تضيف مسافة على جانبي العنصر. مثال القيمة: `auto`
> >
> > #### `display`
> >
> > تحدد طريقة عرض العنصر. مثال القيمة: `grid`
> >
> > #### `place-items`
> >
> > تختصر محاذاة `Grid`. مثال القيمة: `center`
> >
> > #### `color`
> >
> > تحدد لون النص. مثال القيمة: `white`
> >
> > #### `background`
> >
> > تضبط الخلفية. مثال القيمة: `var(--main-color)`
> >
> > #### `clip-path`
> >
> > تحدد قيمة الخاصية `clip-path`. مثال القيمة: `polygon(0 0, 50% 13%, 100% 0, 91% 50%, 100% 100%, 50% 87%, 0 100%, 9% 50%)`
> >
> > ### الدوال والوحدات
> >
> > #### `var()`
> >
> > تستدعي قيمة متغير `CSS` مثل `--main-color`.
> >
> > #### `polygon()`
> >
> > ترسم شكلًا متعدد الأضلاع من نقاط إحداثية، غالبًا مع `clip-path`.
> >
> > #### `px`
> >
> > وحدة بكسل `CSS`.
> >
> > ### بنية القاعدة
> >
> > #### `{`
> >
> > يفتح مجموعة التصريحات.
> >
> > #### `}`
> >
> > يغلق مجموعة التصريحات.
> >
> > #### `:`
> >
> > يفصل الخاصية عن القيمة.
> >
> > #### `;`
> >
> > ينهي تصريح `CSS`.
> >
> > #### `,`
> >
> > يفصل بين محددات أو قيم.
> >
