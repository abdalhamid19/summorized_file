# CSS Transform - Full Transform Declarations

> [!question] السؤال
> داخل تعليق CSS، اكتب قيم `transform` كاملة المستخدمة في حل التكليف السابق.
>
> صورة السؤال:
>
> ![[vibe_coding/Elzero Frontend/CSS/16 - CSS Transform Skew Matrix 3D/assets/reference-task-02.png|650]]

> [!success]- الإجابة وشرح الحل — اضغط لفتحه
>
> ### الكود الكامل للحل
>
> ```css
> /*
> transform: skewX(20deg);
> transform: skewX(-20deg);
> */
> ```
>
> ### الفكرة الأساسية
>
> التعليق يسجل قيم التحويل كاملة كما طلب التكليف. السطر الأول يميل اللافتة، والثاني يعيد نصها إلى الاتجاه الطبيعي.
>
> > [!info]- معاني الرموز المستخدمة في الحل
> >
> > ### خصائص CSS
> >
> > #### `transform`
> >
> > تطبق دورانًا أو تحريكًا أو تحجيمًا. مثال القيمة: `skewX(20deg)`
> >
> > ### الدوال والوحدات
> >
> > #### `skewX()`
> >
> > تميل العنصر على محور `X` بالزاوية المحددة.
> >
> > #### `skewX()`
> >
> > تميل العنصر على محور `X` بالزاوية المحددة.
> >
> > #### `deg`
> >
> > درجة زاوية.
> >
> > ### بنية القاعدة
> >
> > #### `:`
> >
> > يفصل الخاصية عن القيمة.
> >
> > #### `;`
> >
> > ينهي تصريح `CSS`.
> >
> > [!info]- شرح الحل سطرًا بسطر
> >
> > يبقى الكود الكامل أعلى الإجابة، ويأتي كل سطر مستقلًا مع شرحه العربي تحته.
> >
> > #### السطر 01 — `css`
> >
> > ```css
> > /*
> > ```
> >
> > يعرض نصًا أو قيمة في المثال.
> >
> > #### السطر 02 — `css`
> >
> > ```css
> > transform: skewX(20deg);
> > ```
> >
> > تطبق دورانًا أو تحريكًا أو تحجيمًا. والقيمة هنا `skewX(20deg)`.
> >
> > #### السطر 03 — `css`
> >
> > ```css
> > transform: skewX(-20deg);
> > ```
> >
> > تطبق دورانًا أو تحريكًا أو تحجيمًا. والقيمة هنا `skewX(-20deg)`.
> >
> > #### السطر 04 — `css`
> >
> > ```css
> > */
> > ```
> >
> > يعرض نصًا أو قيمة في المثال.
> >
