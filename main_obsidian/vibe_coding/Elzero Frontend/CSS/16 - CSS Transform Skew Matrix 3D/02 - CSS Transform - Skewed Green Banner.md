# CSS Transform - Skewed Green Banner

> [!question] السؤال
> استخدم البنية السابقة، ووسّط العنصر أفقيًا، واستخدم متغيرًا للون الأساسي. أنشئ لافتة متوازية الأضلاع وشريطًا أبيض مائلًا كما في الصورة.
>
> صورة السؤال:
>
> ![[vibe_coding/Elzero Frontend/CSS/16 - CSS Transform Skew Matrix 3D/assets/reference-task-02.png|650]]

> [!success]- الإجابة وشرح الحل — اضغط لفتحه
>
> ### الكود الكامل للحل
>
> ```css
> .banner {
>   --main-color: #009688;
>   position: relative;
>   width: 300px;
>   height: 140px;
>   margin-inline: auto;
>   display: grid;
>   place-items: center;
>   color: white;
>   background: var(--main-color);
>   transform: skewX(20deg);
> }
>
> .banner::before {
>   content: "";
>   position: absolute;
>   inset-block: 0;
>   left: 22px;
>   width: 12px;
>   background: white;
> }
>
> .banner span { display: block; margin-left: 50px; transform: skewX(-20deg); }
> ```
>
> ### الفكرة الأساسية
>
> يميل `skewX` جسم اللافتة. تعكس الكلمة الميل حتى تظهر مستقيمة، بينما يبقى الشريط الأبيض في زاويته المائلة. اللون الأساسي متغير ليكون تغييره من مكان واحد.
>
> > [!info]- معاني الرموز المستخدمة في الحل
> >
> > ### محددات CSS
> >
> > #### `.banner`
> >
> > يستهدف العناصر التي تحمل اسم الصنف المحدد.
> >
> > #### `.banner::before`
> >
> > ينشئ عنصرًا زائفًا لتنسيقه من دون إضافة وسم جديد إلى `HTML`.
> >
> > ### خصائص CSS
> >
> > #### `--main-color`
> >
> > تحدد قيمة الخاصية `--main-color`. مثال القيمة: `#009688`
> >
> > #### `position`
> >
> > تحدد طريقة التموضع. مثال القيمة: `relative`
> >
> > #### `width`
> >
> > تحدد عرض العنصر. مثال القيمة: `300px`
> >
> > #### `height`
> >
> > تحدد ارتفاع العنصر. مثال القيمة: `140px`
> >
> > #### `margin-inline`
> >
> > تضيف مسافة على جانبي العنصر. مثال القيمة: `auto`
> >
> > #### `display`
> >
> > تحدد طريقة عرض العنصر. مثال القيمة: `grid`
> >
> > #### `place-items`
> >
> > تختصر محاذاة `Grid`. مثال القيمة: `center`
> >
> > #### `color`
> >
> > تحدد لون النص. مثال القيمة: `white`
> >
> > #### `background`
> >
> > تضبط الخلفية. مثال القيمة: `var(--main-color)`
> >
> > #### `transform`
> >
> > تطبق دورانًا أو تحريكًا أو تحجيمًا. مثال القيمة: `skewX(20deg)`
> >
> > #### `content`
> >
> > تحدد محتوى العنصر الزائف. مثال القيمة: ""
> >
> > #### `inset-block`
> >
> > تحدد قيمة الخاصية `inset-block`. مثال القيمة: 0
> >
> > #### `left`
> >
> > تحدد المسافة من اليسار. مثال القيمة: `22px`
> >
> > ### الدوال والوحدات
> >
> > #### `var()`
> >
> > تستدعي قيمة متغير `CSS` مثل `--main-color`.
> >
> > #### `skewX()`
> >
> > تميل العنصر على محور `X` بالزاوية المحددة.
> >
> > #### `skewX()`
> >
> > تميل العنصر على محور `X` بالزاوية المحددة.
> >
> > #### `px`
> >
> > وحدة بكسل `CSS`.
> >
> > #### `deg`
> >
> > درجة زاوية.
> >
> > ### بنية القاعدة
