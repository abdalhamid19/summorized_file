> ### الكود الكامل للحل
>
> ```css
> .products {
>   display: grid;
>   grid-template-columns: repeat(2, minmax(0, 1fr));
>   grid-template-areas:
>     "one one"
>     "two three"
>     "four four";
>   gap: 30px;
>   width: calc(100% - 60px);
>   max-width: 1050px;
>   margin: 45px auto;
> }
>
> .product {
>   min-height: 92px;
>   display: grid;
>   align-content: center;
>   gap: 8px;
>   border: 1px solid #ddd;
>   background: #eee;
>   text-align: center;
> }
>
> .product h2 {
>   margin: 0;
>   color: #009688;
>   font-size: 20px;
> }
>
> .product p {
>   margin: 0;
>   color: #333;
>   font-size: 16px;
> }
>
> .product-one { grid-area: one; }
> .product-two { grid-area: two; }
> .product-three { grid-area: three; }
> .product-four { grid-area: four; }
>
> @media (max-width: 1099px) and (min-width: 900px) {
>   .products {
>     grid-template-columns: repeat(3, minmax(0, 1fr));
>     grid-template-areas:
>       "one one one"
>       "two three four";
>   }
>
>   .product h2 {
>     color: #f00;
>   }
> }
>
> @media (max-width: 899px) {
>   .products {
>     grid-template-columns: 1fr;
>     grid-template-areas:
>       "one"
>       "two"
>       "three"
>       "four";
>   }
>
>   .product h2 {
>     color: #000;
>   }
> }
> ```
>
> ### الفكرة الأساسية
>
> في العرض الواسع يشغل العنصر الأول صفًا كاملًا، ويأتي العنصران الثاني والثالث بجانبهما في الصف التالي، ثم يشغل الرابع صفًا كاملًا. في المقاس المتوسط يظهر الأول بعرض كامل ثم تأتي العناصر الثلاثة في صف واحد. على الهاتف يتحول التخطيط إلى عمود واحد. اخترت نقطتي التحول `1099px` و`899px` لأنها غير محددة في نص التكليف.

> > ### خصائص CSS
> >
> > #### `display`
> >
> > تحدد طريقة عرض العنصر. مثال القيمة: `grid`
> >
> > #### `grid-template-columns`
> >
> > تحدد أعمدة `Grid`. مثال القيمة: `repeat(2, minmax(0, 1fr)`)
> >
> > #### `grid-template-areas`
> >
> > تسمي مناطق `Grid`. مثال القيمة:
> >
> > #### `gap`
> >
> > تحدد المسافة بين عناصر التخطيط. مثال القيمة: `30px`
> >
> > #### `width`
> >
> > تحدد عرض العنصر. مثال القيمة: `calc(100% - 60px)`
> >
> > #### `max-width`
> >
> > تحدد أقصى عرض. مثال القيمة: `1050px`
> >
> > #### `margin`
> >
> > تضيف مسافة خارجية. مثال القيمة: `45px` `auto`
> >
> > #### `min-height`
> >
> > تحدد أقل ارتفاع. مثال القيمة: `92px`
> >
> > #### `align-content`
> >
> > تحاذي صفوف أو أعمدة التخطيط. مثال القيمة: `center`
> >
> > #### `border`
> >
> > ترسم الحد وتحدد سمكه ونمطه ولونه. مثال القيمة: `1px` `solid` `#ddd`
> >
> > #### `background`
> >
> > تضبط الخلفية. مثال القيمة: `#eee`
> >
> > #### `text-align`
> >
> > تحاذي النص. مثال القيمة: `center`
> >
> > #### `color`
> >
> > تحدد لون النص. مثال القيمة: `#009688`
> >
> > #### `font-size`
> >
> > تحدد حجم النص. مثال القيمة: `20px`
> >
> > ### الدوال والوحدات
> >
> > #### `repeat()`
> >

> >
> > #### `minmax()`
> >
> > تحدد حدًا أدنى وحدًا أقصى لحجم مسار في `Grid`.
> >
> > #### `calc()`
> >
> > تحسب قيمة من تعبير رياضي، ويمكنها الجمع بين وحدات `CSS` المختلفة.

> > #### `repeat()`
