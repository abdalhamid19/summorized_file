# CSS Media Queries - Print Font Size

> [!question] السؤال
> اجعل حجم الخط `40px` عند الطباعة فقط.
>
> صورة السؤال:
>
> التكليف لا يرفق صورة مرجعية؛ المطلوب محدد نصيًا.

> [!success]- الإجابة وشرح الحل — اضغط لفتحه
>
> ### الكود الكامل للحل
>
> ```css
> @media print {
>   h1 {
>     font-size: 40px;
>   }
> }
> ```
>
> ### الفكرة الأساسية
>
> يطبّق `@media print` القاعدة عند تجهيز الصفحة للطباعة فقط؛ في العرض العادي يظل عنوان الصفحة على حجمه الأصلي.
>
> > [!info]- معاني الرموز المستخدمة في الحل
> >
> > ### محددات CSS
> >
> > #### `h1`
> >
> > يحدد العنصر الذي ستطبق عليه قواعد `CSS`.
> >
> > ### خصائص CSS
> >
> > #### `font-size`
> >
> > تحدد حجم النص. مثال القيمة: `40px`
> >
> > ### الدوال والوحدات
> >
> > #### `px`
> >
> > وحدة بكسل `CSS`.
> >
> > ### بنية القاعدة
> >
> > #### `{`
> >
> > يفتح مجموعة التصريحات.
> >
> > #### `}`
> >
> > يغلق مجموعة التصريحات.
> >
> > #### `:`
> >
> > يفصل الخاصية عن القيمة.
> >
> > #### `;`
> >
> > ينهي تصريح `CSS`.
> >
> > [!info]- شرح الحل سطرًا بسطر
> >
> > يبقى الكود الكامل أعلى الإجابة، ويأتي كل سطر مستقلًا مع شرحه العربي تحته.
> >
> > #### السطر 01 — `css`
> >
> > ```css
> > @media print {
> > ```
> >
> > يبدأ شرطًا يطبق القواعد عند تحقق حجم الشاشة أو نوع الوسيط.
> >
> > #### السطر 02 — `css`
> >
> > ```css
> >   h1 {
> > ```
> >
> > يحدد العنصر الذي ستطبق عليه قواعد `CSS`.
> >
> > #### السطر 03 — `css`
> >
> > ```css
> >     font-size: 40px;
> > ```
> >
> > تحدد حجم النص. والقيمة هنا `40px`.
> >
> > #### السطر 04 — `css`
> >
> > ```css
> >   }
> > ```
> >
> > يغلق نطاق القاعدة التي بدأها المحدد.
> >
> > #### السطر 05 — `css`
> >
> > ```css
> > }
> > ```
> >
> > يغلق نطاق القاعدة التي بدأها المحدد.
> >
