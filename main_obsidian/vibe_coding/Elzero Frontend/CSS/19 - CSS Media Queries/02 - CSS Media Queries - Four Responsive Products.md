> ### الكود الكامل للحل
>
> ```css
> .products {
>   display: grid;
>   grid-template-columns: repeat(4, minmax(0, 1fr));
>   gap: 30px;
>   width: 93%;
>   max-width: 1200px;
>   margin: 50px auto;
> }
>
> .product {
>   min-height: 92px;
>   display: grid;
>   align-content: center;
>   gap: 8px;
>   border: 1px solid #ddd;
>   background: #eee;
>   text-align: center;
> }
>
> .product h2 {
>   margin: 0;
>   color: #009688;
>   font-size: 20px;
> }
>
> .product p {
>   margin: 0;
>   color: #333;
>   font-size: 16px;
> }
>
> @media (max-width: 1099px) {
>   .products {
>     grid-template-columns: repeat(2, minmax(0, 1fr));
>   }
>
>   .product h2 {
>     color: #f00;
>   }
> }
>
> @media (max-width: 899px) {
>   .products {
>     grid-template-columns: 1fr;
>   }
>
>   .product h2 {
>     color: #000;
>   }
> }
> ```
>
> ### الفكرة الأساسية
>
> تعرض الشبكة أربعة أعمدة في العرض الواسع، وعمودين في العرض المتوسط، وعمودًا واحدًا في الهاتف. يتبدل لون العنوان من الأخضر المزرق إلى الأحمر ثم الأسود كما في الصور. اخترت نقطتي التحول `1099px` و`899px` لتقسيم المقاسات؛ التكليف يعرض حالات مرئية ولا يحدد أرقامًا إلزامية لنقاط التحول.

> > ### خصائص CSS
> >
> > #### `display`
> >
> > تحدد طريقة عرض العنصر. مثال القيمة: `grid`
> >
> > #### `grid-template-columns`
> >
> > تحدد أعمدة `Grid`. مثال القيمة: `repeat(4, minmax(0, 1fr)`)
> >
> > #### `gap`
> >
> > تحدد المسافة بين عناصر التخطيط. مثال القيمة: `30px`
> >
> > #### `width`
> >
> > تحدد عرض العنصر. مثال القيمة: `93%`
> >
> > #### `max-width`
> >
> > تحدد أقصى عرض. مثال القيمة: `1200px`
> >
> > #### `margin`
> >
> > تضيف مسافة خارجية. مثال القيمة: `50px` `auto`
> >
> > #### `min-height`
> >
> > تحدد أقل ارتفاع. مثال القيمة: `92px`
> >
> > #### `align-content`
> >
> > تحاذي صفوف أو أعمدة التخطيط. مثال القيمة: `center`
> >
> > #### `border`
> >
> > ترسم الحد وتحدد سمكه ونمطه ولونه. مثال القيمة: `1px` `solid` `#ddd`
> >
> > #### `background`
> >
> > تضبط الخلفية. مثال القيمة: `#eee`
> >
> > #### `text-align`
> >
> > تحاذي النص. مثال القيمة: `center`
> >
> > #### `color`
> >
> > تحدد لون النص. مثال القيمة: `#009688`
> >
> > #### `font-size`
> >
> > تحدد حجم النص. مثال القيمة: `20px`
> >
> > ### الدوال والوحدات
> >
> > #### `repeat()`
> >
> > تكرر مسارًا أو مجموعة مسارات بعدد محدد في تخطيط `Grid`.
> >
> > #### `minmax()`
> >
> > تحدد حدًا أدنى وحدًا أقصى لحجم مسار في `Grid`.
> >
> > #### `repeat()`
