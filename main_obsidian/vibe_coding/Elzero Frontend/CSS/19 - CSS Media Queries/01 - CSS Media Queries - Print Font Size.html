CSS Media Queries - Print Font Size

المطلوب والحل والفكرة ومعاني الرموز وشرح الأسطر في صفحة مستقلة.

المطلوب وHTML الأصلي

HTML مأخوذ من المعاينة المحلية

<section class="task" data-task="01">
      <p class="task-label">CSS Media Queries — Print</p>
      <h1 class="print-sample">Print Title</h1>
    </section>

المطلوب

اجعل حجم الخط 40px عند الطباعة فقط.

صورة السؤال:

التكليف لا يرفق صورة مرجعية؛ المطلوب محدد نصيًا.

معاينة قبل وبعد

قبل تطبيق CSS
بعد تطبيق الحل

تستخدم المقارنة البنية الواردة في السؤال أو معاينة المجموعة المحفوظة. راجع نص المطلوب للتحقق من القيم المحددة.

الكود الكامل للحل

CSS
@media print {
  h1 {
    font-size: 40px;
  }
}

الفكرة الأساسية

يطبّق @media print القاعدة عند تجهيز الصفحة للطباعة فقط؛ في العرض العادي يظل عنوان الصفحة على حجمه الأصلي.

معاني الرموز المستخدمة في الحل

خصائص CSS

تحدد حجم النص. مثال القيمة: 40px
