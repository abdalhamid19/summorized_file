# التكليف 01: محددات CSS

## المطلوب

اكتب تعليقًا فوق كل **CSS Selector** (محدد CSS: نمط يختار عناصر الصفحة التي نريد تنسيقها) يشرح ما الذي يحدده.

## الحل

```css
/* أي عنصر يحمل class باسم title (الصنف: تصنيف يمكن أن تشترك فيه عناصر متعددة) */
.title {
}

/* العنصر الذي يحمل id باسم nav (المعرّف: اسم يحدد عنصرًا واحدًا) */
#nav {
}

/* جميع عناصر div */
div {
}

/* جميع عناصر h2 */
h2 {
}
```

## طريقة التمييز بينها

- النقطة `.` قبل الاسم تعني أن المحدد يبحث عن عنصر يحمل ذلك الـ **class** (الصنف).
- علامة `#` قبل الاسم تعني أن المحدد يبحث عن العنصر ذي ذلك الـ **id** (المعرّف).
- كتابة اسم العنصر وحده، مثل `div` أو `h2`، تعني اختيار كل العناصر التي تحمل هذا الاسم.

`h2` هنا محدد يختار عناصر العنوان `h2` المكتوبة في HTML (لغة بناء هيكل صفحة الويب).
