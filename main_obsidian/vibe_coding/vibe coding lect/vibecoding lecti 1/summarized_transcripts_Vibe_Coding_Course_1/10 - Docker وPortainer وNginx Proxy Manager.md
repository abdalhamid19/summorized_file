# 10 - Docker وPortainer وNginx Proxy Manager

## الخلاصة العلمية المنظمة

لوحة تحكم Docker: <span style="color:#0D9488; font-weight:bold;">[[Portainer]]</span> (`portainer.io`). المطوّرون يعملون Docker من Terminal؛ Vibe Coder يريد واجهة. يبدو مدفوعًا وهو **مجاني 100%**.

### تثبيت Portainer عبر الذكاء الاصطناعي

أي ذكاء اصطناعي: أوامر تثبيت Portainer على Ubuntu 24. مع التكرار يعمل الشخص documentًا خاصًا للأوامر التي مشت. الأوامر تحت الفيديو أيضًا. النمط: copy من الذكاء → right-click في PuTTY للصق. أول أمر: تحديث Server ثم تثبيت Docker ثم Portainer؛ أي سؤال `Y`.

الدخول: `https://IP:9443` (ذكر أيضًا 933 في موضع). **على Vultr فقط:** فتح الـ Ports بـ UFW لأن الـ Default مغلق (Hetzner يفتح الكل). يمكن فتح Port 9443 فقط أو تمكين الكل. أول دخول: إنشاء user وPassword (يشيل الـ checkbox) → Create user.

ارتباك الواجهة: Home → Environment → Local → Stacks. من Stacks تُثبَّت البرامج.

### مصادر الستاتكات

- `hub.docker.com` للبرامج.
- قناة/شركة **elestio** (استضافة؛ يختار «أنظف برامج»؛ Servers من Amazon وVultr وSetup automatic؛ الملفات مفتوحة المصدر): Mautic لـ Email Marketing، WordPress، Vibe Coder، Redis، Flowise لـ AI agent، Odoo المجاني، وغيرها.
- أو البرامج الـ Verified المشهورة على Docker.
- أي إيج: انسخ الDocument للذكاء الاصطناعي: «ساعدني أثبّته على Portainer» فيعطيك الخطوة بخطوة.

أول ما يُثبَّت: **[[Nginx Proxy Manager]]** (الأوامر تحت الفيديو) لأجل ربط Domain/Subdomain بالـ IP. Add stack → الصق ملف الStack من الذكاء الاصطناعي (لا يحتاج قاعدة بيانات إضافية إن لم تُرَد) → Deploy. بديل Nginx التقليدي بخطوة واحدة؛ يوفّر مشاكل Nginx الكثيرة عند المطوّرين.

دخول NPM: `http://IP:81`. الافتراضي: user `admin@example.com` وPassword `changeme` ثم تغيير الـ Email.

### مثال n8n (الهدف تعليم الربط لا تعليم n8n)

1. جهّز Subdomain على Cloudflare: A record من `n8n.vibe-code.com` (مثال) إلى IP Server.
2. في Portainer: أنشئ **Volume** اسمه مثل `n8n_data` **قبل** التثبيت.
3. n8n على Port **5678**.
4. في NPM: Add Proxy Host → IP Server (نفس Server) + Port + الSubdomain. أولًا HTTP ثم Edit → SSL → Request certificate → Agree → Save. SSL بعد ربط Cloudflare.
5. Deploy للStack في Portainer.
6. أول فتح: شاشة تنصيب (أحيانًا متصفح آخر إن لم تظهر).
7. فعّل **WebSocket** في إعدادات Proxy لـ n8n (وللأدوات التي تحتاج Data instant). بعض المواقع لا تُفعَّل فيها.

نفس النمط لـ Activepieces (قال إنها نفس فكرة n8n): Stack → Volume → Email/Password/Frontend URL → Deploy → Port 8080 → Proxy بلا HTTPS أولًا ثم Subdomain.

> [!tip] الزمن
> بTerminal/Nginx العادي: ساعتان أو ثلاث ويلزم معرفة كل خطوة. هنا: دقائق.

> [!info] الفترة المرجعية
> الأسطر 142–173.

### خطوات النمط العام (أي تطبيق Docker)

1. خذ Document الصورة/الStack.
2. اطلب من الذكاء الاصطناعي خطوات Portainer.
3. أنشئ Volume إن لزم قبل التثبيت.
4. Deploy Stack.
5. اربط Port في Nginx Proxy Manager + Subdomain Cloudflare.
6. اطلب SSL.
7. فعّل WebSocket إن كانت Data instant.
