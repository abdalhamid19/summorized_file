# 02 - الست مهارات وصورة Vibe Coder

## الخلاصة العلمية المنظمة

- الهدف: ركوب Vibe Coding وتحقيق الفكرة، **لا تعلم البرمجة ولا تعليمها**. المتحدث نفسه ليس مبرمجًا ولا يعرف أن يبرمج؛ عمل أدوات وE-commerce لشركات وChrome Extension **بدون كتابة سطر واحد**، ولم يتعلم كتابة الـ Code كي يبقى محافظًا على فكر Business.
- حتى المطوّر الذي يعرف البرمجة إن نقصته هذه المهارات **لن يعرف أن يعمل Vibe Coder**.

الكورس هنا على **Web Application** لا Mobile Application.

### 1. الرؤية

لازم فكرة حاضرة كاملة: أداة أو Chrome Extension أو موقع يُحوَّل إلى Application. كثير عنده الفكرة ويقف عند تكلفة المبرمجين والتعاقد مع الشركات. في عصر الذكاء الاصطناعي الفكرة تُنفَّذ بسهولة؛ الكورس يعلّم كيف. الشرط: فكرة قوية مدروسة حاضرة في البال.

### 2. عقلية Business

الاشتغال بـ Code يُخرج من فكر Business: العقل يُستنزف في شكل الكتابة واللغة والمكتبة وعدد الملفات. المطوّر لا يتحرك إلا حين يقول صاحب المشروع «عاوز أعمل كذا». صاحب الـ Business لا يهمه كيف يُكتب الـ Code ما دامت فكرة الـ Business حاضرة؛ لغة البرمجة لا تفرّق معه.

### 3. اكتشاف الـ Bug (Bug explanation)

لا برمجة بلا مشاكل. المطوّرون يُستنزف عقلهم ووقتهم في فهم Bug وعلاقته بالمكتبة والسؤال في Stack Overflow وGitHub. Vibe Coder ينسخ Bug Copy-بيست للذكاء الاصطناعي وهو يحله. المطلوب تعلم **كيف تجد Bug وتعطيها للذكاء الاصطناعي**. بعد التحديثات (Sonnet 4.5 وChatGPT 5): مجرد Copy-بيست بلا «اعمل لي» ولا Prompt؛ وهو يعمل كل شيء.

### المهارات اليمنى (قشور تُشرح في هذا الفيديو)

1. **VS Code وGitHub:** أساسيات لأي مبرمج؛ يكفي الربط بينهما. Deployment لاحقًا من GitHub automatic للServer؛ ما طلع على GitHub حصل له Deployment والأداة اشتغلت.
2. **Docker:** عالم واسع؛ يُؤخذ الأساسي فقط. يوفّر أوامر كثيرة. Vibe Coder يأخذ ملف Docker ويضعه على Server أو Serverless فيعمل Web Application كامل بأمر واحد أو stroke واحدة. يُنسَخ الطلب للذكاء الاصطناعي: «هات ملف الـ Docker الذي يعمل Setup للحاجة الفلانية».
3. **Server administration:** وظيفة قائمة بذاتها؛ تُؤخذ القشور التي تساعد على عمل الـ Application.

الثلاث اليمنى تُغطى قشورها في هذا الفيديو؛ الثلاث الشمال في الفيديو القادم.
