# 13 - أسئلة المراجعة والاختبار الذاتي

> [!warning] تنبيه
> الأسئلة مستخرجة من محتوى التفريغ فقط.

## أولًا: اختيار من متعدد

1. ما الترجمة الحرفية التي ذكرها المصدر للـ Vibe Coding؟
   - أ. البرمجة الكائنية
   - ب. البرمجة الحدثية
   - ج. البرمجة الوظيفية
   - د. البرمجة المتوازية

2. كم مهارة قال المصدر إنها لازمة للـ Vibe Coder؟
   - أ. أربع
   - ب. خمس
   - ج. ست
   - د. ثمان

3. ما تعريف Headless كما ورد؟
   - أ. Frontend و Backend في Core واحد
   - ب. Frontend في ناحية وBackend في ناحية يرتبطان بـ API أو GraphQL
   - ج. قاعدة بيانات فقط
   - د. CDN فقط

4. أي طريقة Rendering قال إنها ليست SEO-optimized؟
   - أ. SSR
   - ب. SSG
   - ج. CSR
   - د. ISR

5. أي منصة Static ذكر أنها حتى 500 زائر يوميًا مجانًا ثم 5 دولار/شهر؟
   - أ. Railway
   - ب. Cloudflare Pages
   - ج. Fly.io
   - د. PlanetScale

6. ما لغة الـ API التي ركّز عليها مع الذكاء الاصطناعي؟
   - أ. PHP
   - ب. Ruby
   - ج. Python
   - د. .NET

7. أي قاعدة بيانات وصفها بأنها الأعلى قيمة ومفتوحة المصدر؟
   - أ. MySQL
   - ب. MongoDB
   - ج. PostgreSQL
   - د. SQLite

8. ما واجهة Docker التي اختارها بدل Terminal؟
   - أ. Kubernetes Dashboard
   - ب. Portainer
   - ج. Docker Desktop فقط
   - د. cPanel

## ثانيًا: صح أم خطأ

1. الكورس على YouTube مجاني والأدوات المجانية كافية للعمل بحسب المصدر. — خطأ.
2. حتى المطوّر إن نقصته المهارات الست قد لا يعمل Vibe Coder. — صح.
3. Vue بحسب المصدر تعمل CSR خالص. — خطأ (قال إنها لا تعمل CSR؛ كلها Server سايد).
4. صفحة الدفع/الـ checkout تصلح CSR أو SSG. — خطأ.
5. Vercel يحاول البعد عنها لأنها «بدأت تدعم الكيان». — صح.
6. Typesense مصدر مفتوح ومجاني للبحث. — صح.
7. Hetzner by Default يقفل كل الـ Ports. — خطأ (يفتحها؛ Vultr يقفل).
8. Portainer مدفوع 100%. — خطأ (قال إنه مجاني 100%).

## ثالثًا: أسئلة قصيرة

1. اذكر الثلاث مهارات «الشمال» والثلاث «اليمين».
2. ما مكوّنات أي موقع إنترنت التي ذكرها المصدر؟
3. لماذا يُختار Serverless من جهة Security بحسب المصدر؟
4. ما المكتبة على بايثون التي قال إنها تضبط Prompt داخل Backend؟
5. ما الفرق الذي ذكره بين تفعيل حساب Hetzner وحساب Vultr؟
6. ما Port الافتراضي لـ Nginx Proxy Manager؟ وما user/Password أول دخول؟
7. ما اسم الملف الذي قال إن Railway تفرضه داخل المشروع؟

## رابعًا: تطبيق عملي (من المصدر فقط)

1. رتّب ما يحدث عند طلب صفحة: Routing / Authentication / جلب بيانات / Rendering.
2. اختر Framework لMarketplace يحتاج SEO، وعلّل بما قاله المصدر عن React مقابل Next/Astro.
3. صف مسار تثبيت تطبيق Docker على Portainer ثم ربط Subdomain عبر NPM كما في مثال n8n.

## مفتاح الإجابات

> [!faq]- إجابات الاختيار من متعدد
> 1. ب — البرمجة الحدثية
> 2. ج — ست
> 3. ب — Frontend و Backend منفصلان عبر API أو GraphQL
> 4. ج — CSR
> 5. ب — Cloudflare Pages
> 6. ج — Python
> 7. ج — PostgreSQL
> 8. ب — Portainer

> [!faq]- إجابات الأسئلة القصيرة
> 1. شمال: رؤية، عقلية Business، اكتشاف الـ Bug. يمين: VS Code+GitHub، Docker، قشور الـ Server.
> 2. HTML + CSS + JavaScript.
> 3. لا بيانات Server حتى عند صاحب الحاجة؛ من يحاول الاختراق لا يجد بيانات على Server تقليدي.
> 4. DSPy.
> 5. Hetzner يحتاج تفعيل (PayPal أو Visa+جواز) وLimit Server أول شهر؛ Vultr بلا Verification.
> 6. Port 81؛ `admin@example.com` / `changeme`.
> 7. `railway.toml`.
