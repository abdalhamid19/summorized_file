# 08 - VS Code وCursor وربط GitHub

## الخلاصة العلمية المنظمة

بعد المفاهيم: تعلم ربط [[VS Code]] و[[GitHub]]. الرؤية وعقلية Business تُؤجَّل حتى عمل الأداة.

### محررات مبنية على VS Code

VS Code برنامج مفتوح المصدر من مايكروسوفت؛ يمكن أخذ الـ Code الخاص به وبناء برنامج باسم آخر:

| البرنامج | علاقته بـ VS Code في المصدر |
|---|---|
| [[Cursor]] | قائم على كود VS Code مع مميزات الذكاء الاصطناعي؛ أشهر من VS Code حاليًا |
| Windsurf | ذُكر |
| Trae الصيني | ذُكر «الطالع أخير» |
| VS Code | العمود الفقري؛ أشهرهم في الوقت الحالي مع Cursor |

يفضّل تثبيت VS Code أولًا لا Cursor مباشرة؛ Extension VS Code يتثبّت على Cursor أيضًا.

### التثبيت قبل الربط

1. **Node.js** من جوجل (على Windows اختيار automatic؛ Mac/Linux أمر واحد من Terminal).
2. **Python:** وقت التسجيل النسخة 3.13؛ في أكتوبر 2025 الذكاء الاصطناعي آخره 3.12 و3.11 ولم يصل 3.13. يحاول أخذ نسخة أقدم قليلًا؛ دعم 3.12 حتى 2028 تقريبًا. مثال عملي: 3.11.
3. حساب GitHub (لا يحتاج شرح إنشاء الحساب).
4. برنامج **Git for Windows**.

التحقق: افتح فولدر مشروع → Terminal → New Terminal → `npm -v` (أو اسأل الذكاء الاصطناعي). اختبر بايثون بطلب Code في ملف.

### ربط GitHub

Extension **GitHub Pull Requests** أهم Extension للربط. أول مرة: يفتح رابطًا وcode تُنسخ إلى حساب GitHub. المشروع يُنشَر Private أو Public. أي تعديل في الفولدر: Commit ثم Push فيظهر على GitHub.

ملف **`.gitignore`** يُنشأ automatic ويمنع صعود `node_modules` و`.next`؛ تصعد الملفات الـ public.

### Extensions العمل

الأهم اثنان وعليهما علامة Anthropic وOpenAI: **Claude Code** (الأهم لأنه سيعمل عليه) و**Codex** الخاص بـ ChatGPT (مهم في بعض الأحوال). الفرق لاحقًا.

### عرض عملي: مشروع Next.js ثم Push

- فولدر test project → يسأل DeepSeek مثالًا (للبداية لا للعمل): `create new next.js project`.
- ينسخ الأمر للTerminal؛ اختيارات: TypeScript yes، Tailwind yes، ESLint yes، App Router / SSR yes، Turbo pack no، حسب ما قال DeepSeek.
- `cd` إلى مجلد المشروع ثم `npm run dev` → Port 3000 والمشروع يفتح.
- Push: يسأل Private/Public؛ `.gitignore` automatic.
- تعديل تجريبي: DeepSeek يعطي محتوى لـ `app/page`؛ استبدال الـ Code؛ الألوان تتبّع التعديلات؛ Commit باسم مثل «Home Page» ثم يظهر على GitHub.

> [!tip] ماذا يكفي من GitHub؟
> GitHub تفاصيل كثيرة جدًا. الذي لُقِّن هنا: **ربط GitHub بـ VS Code** — هذا وحده يمشي في Vibe Coding. الباقي يُسأل أي ذكاء اصطناعي.
