# 09 - لوحة التقنيات والـ Servers (Hetzner / Vultr)

## الخلاصة العلمية المنظمة

نقطة كور ثانية بعد GitHub: [[Server Administration]] مع [[Docker]]. قبلها لوحة «Tech Stack» المشهورة:

| المحور | الأعلى بحسب ما عرضه |
|---|---|
| HTML | لا يهمنا |
| قواعد البيانات | Postgres الأعلى؛ MySQL مرتفع بسبب WordPress — «من غير WordPress MySQL ما يُعتبرش حاجة» → البقاء على Postgres (Supabase وNeon وما شابه) |
| Cloud | Amazon ثم Microsoft ثم Google ثم Cloudflare |
| ويب Framework | Node.js وReact الأعلى؛ Next يعرف الفترة دي؛ Vue؛ Astro لم تكمل ثلاث سنين و«طالعة جامدة»؛ Remix جديد |
| Docker | أعلى وأهم شيء يجب العمل به |

رابط اللوحة تحت الفيديو. Docker يُنزَّل من docker.com لـ Windows/Mac للتجربة المحلية؛ **المهم تشغيله على الـ Server**.

### اختيار نوع الاستضافة مجددًا قبل شراء Server

- أدوات Dynamic → [[Railway]] (أفضل سعر وتعامل من وجهة نظره).
- موقع شركة Static → Cloudflare Pages (500 زائر/يوم ثم 5 دولار/شهر).
- Self-host → Server خاص.

### مزوّدا الـ Server الخاص

| | [[Hetzner]] | [[Vultr]] |
|---|---|---|
| السعر | أرخص بكثير | أغلى؛ تعوّض بقوة الـ Servers (تشابه قوة أمازون) |
| متى تختار | الميزانية | شغل ثقيل/موقع ثقيل يتحمل كثيرًا |
| حد أدنى ذكره | 4 CPU + 16GB بـ 25 يورو ≈ 30 دولار | لا أقل من 40 دولار؛ Dedicated CPU؛ 2 CPU + 8GB أقل شيء؛ أو 60 دولار |
| الموقع | Locations أقل؛ أمريكي، أو ألماني إن كان الموقع عربيًا (أقرب للدول العربية) | يفضّل مدينة أمريكية؛ نيويورك من الأفضل |
| نظام التشغيل | Ubuntu؛ Dedicated CPU | Ubuntu 24 (25 ليست stable بعد؛ من يسمع لاحقًا قد يختار 25) |
| تفعيل الحساب | يحتاج تفعيل أول مرة: PayPal auto-approve أو Visa ثم جواز/بطاقة. Limit أول شهر: Server واحد حتى دفع الفاتورة. Link الفيديو: 20 دولار Credit؛ من الموقع مباشرة بلا رصيد | لا تحتاج Verification. Link الفيديو: 300 دولار أول شهر؛ من دونه تسجيل مجاني بلا شيء |
| الـ Ports | باي Default **يفتح كل الـ Ports** (مريح للـ Development؛ عيب Security → تُقفَل يدويًا من Firewall) | باي Default **يقفل** الـ Ports |
| الدخول | يرسل IP على اللوحة وPassword على الـ Email؛ يطالب بتغيير Password أول دخول | IP وUsername وPassword root من اللوحة (copy-paste)؛ لا يطالب بتغيير Password (يفضّل المشي بـ Password Vultr كما هو) |
| النسخ الاحتياطي | — | يمكن إلغاء خيار Backup إن لم يُرَد |

الدخول عبر برنامج **PuTTY** (`putty download`): IP → Open → `root` → right-click للصق Password (لا Ctrl+V). على Hetzner: الصق Password القديم ثم الجديد مرتين (لا تظهر الكتابة) ثم `clear`. على Vultr: `passwd` إن أردت التغيير.

Public IPv4 مجاني على Vultr. نقطة SSH أمنية ذكرها ولم يحب تنفيذها في العرض؛ ترك Server بPassword.
