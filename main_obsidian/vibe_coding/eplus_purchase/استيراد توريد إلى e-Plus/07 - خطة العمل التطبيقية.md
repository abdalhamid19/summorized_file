# 07 - خطة العمل التطبيقية

> [!abstract] الغرض
> قائمة لمراجعة طلب Tawreed قبل إدخال فاتورة شراء معلقة في e-Plus. الخطوات مستخلصة من تسلسل الواجهة والكود، وليست اقتباسًا من محاضرة.

## المصطلحات

| المصطلح | المقصود |
|---|---|
| <code>Tawreed</code> | مصدر الطلب والكمية والسعر |
| <code>e-Plus</code> | نظام الموردين وكتالوج الأصناف وفاتورة الشراء |
| <code>product_id</code> | المنتج العام في Tawreed |
| <code>store_product_id</code> | إدراج المنتج لدى المورد |
| <code>itm_code</code> | كود الصنف في e-Plus |
| <code>ven_id</code> | معرّف المورد في e-Plus |
| Dry-run | فحص الطلب دون إنشاء فاتورة في e-Plus |
| Apply | إدخال الفاتورة المعلقة إلى e-Plus بعد التأكيد |

## المرحلة 1: تحميل الطلب ومراجعته

- [ ] افتح **Confirmed Bills** وحمّل الطلبات المؤكدة.
- [ ] تحقق من رقم الطلب والمورد والتاريخ والإجمالي.
- [ ] اختر طلبًا واحدًا، وافتح Preview أو Dry-run.

## المرحلة 2: مراجعة هوية المورد والصنف

- [ ] راجع مطابقة اسم المتجر إلى <code>ven_id</code>؛ فهي مستقلة عن مطابقة المنتج.
- [ ] قارن اسم Tawreed العربي والإنجليزي واسم السلعة لدى المورد، ولا تعامل اسم المورد بوصفه ترجمة رسمية.
- [ ] راجع <code>itm_code</code> واسمي الصنف في e-Plus.
- [ ] إذا بقي صنف غير محسوم، افتح **Item Mapping**. اقرأ [[مطابقة الأصناف/02 - ترتيب حل الصنف والمطابقات المنسقة]] و[[مطابقة الأصناف/03 - بوابة التوافق والدرجة والقبول]].
- [ ] ميّز المرشح المقترح من قرار المراجعة المحفوظ، ولا تعتبر التشابه وحده قبولًا.

## المرحلة 3: مراجعة الأسعار والحسابات

- [ ] راجع الكمية وسعر الوحدة قبل الخصم وسعر الشراء الصافي ونسبة الخصم.
- [ ] قارن إجمالي السطر الوارد من Tawreed بحساب الكمية مضروبة في سعر الشراء الصافي.
- [ ] راجع مجاميع البنود وإجمالي الطلب وأي فرق أو صنف غير مربوط في [[03 - بناء فاتورة الشراء والتحقق من الأسعار]].

## المرحلة 4: فهم الآثار المحلية وقرار Apply

- [ ] تذكر أن Dry-run لا يكتب فاتورة في ERP. تختلف آثار SQLite المحلية: معاينة CLI والواجهة تستخدم سياسة بلا حفظ مطابقة، بينما bootstrap في Item Mapping قد يحفظ الربط المؤهل ويضيف غير المحلول إلى طابور المراجعة.
- [ ] إذا كانت الحالة PARTIAL، حل البنود الناقصة قبل Apply؛ خيار فرض الفاتورة الجزئية قرار منفصل.
- [ ] لا تضغط Apply إلا بعد مراجعة الطلب والمورد والأصناف والحسابات والتأكيد.
- [ ] راجع [[مطابقة الأصناف/04 - المراجعة اليدوية والحفظ وآثار التشغيل]] لفصل التخزين المحلي عن الكتابة في ERP.
