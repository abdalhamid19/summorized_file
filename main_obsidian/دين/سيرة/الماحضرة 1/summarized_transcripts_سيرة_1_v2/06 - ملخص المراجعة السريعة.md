# 06 - ملخص المراجعة السريعة

> [!abstract] المجلس 1 — الأرجوزة المئية

---

## 🔑 في بطاقة واحدة

| الموضوع | الخلاصة |
|:--------|:--------|
| لماذا الأرجوزة؟ | متن 100 بيت = خريطة السيرة بسرعة |
| مراحل العلم | مختصر → توسع → تخصص |
| الناظم | ابن أبي العز الحنفي — تلميذ ابن كثير — شارح الطحاوية |
| الفصول | إشارة محتملة لكتاب ابن كثير |
| الشرح | عبد الرزاق البدر |
| الحفظ | من حفظ المتون حاز الفنون |
| افتتاح النظم | الحمد + الصلاة؛ الكلام بلا ذكر أبتر |
| القديم | بمعنى الأول؛ التعبير الشرعي: هو الأول والآخر |
| السيرة اصطلاحًا | من الولادة إلى الرفيق الأعلى |
| المولد | عام الفيل + الاثنين قطعًا؛ يوم الشهر خلاف (المشهور 12) |
| ليلة المولد | لا حكم شرعي تعبّدي مربوط بتاريخ اليوم |
| اليتم | وفاة الأب **قبل** الولادة |
| الرضاع | حليمة؛ الفطام بعد عامين ثم العودة للأم |

---

## 🧠 احفظ الفروق

1. **نظم ≠ نثر** — كلاهما طريق تدوين العلم.
2. **سيرة ≠ تاريخ عام** — السيرة مرحلة النبوة من الولادة للوفاة.
3. **شروط البيع ≠** (لا علاقة هنا) — **عام الفيل قطعي / يوم الشهر ظني مشهور**.
4. **صوم الاثنين** معلّل بالولادة والبعثة **دون** تعيين تاريخ ربيع.
5. **مدرسة السيرة** متوقفة مؤقتًا لصالح الأرجوزة ثم العودة للتربية على المائدة.
