# ا <span style="color:#D97706">06 - ملخص المراجعة السريعة</span>

## ا <span style="color:#0D9488">بطاقة الجزء</span>
- **المصدر**: تلخيص شامل من المحاضرة 9 من شرح أخصر المختصرات (باب البيع - عقود التوثيقات: الرهن والضمان والكفالة).
- **الغرض**: بطاقة مكثفة للمراجعة السريعة قبل الاختبارات أو لإعادة ترتيب المعلومات بعد الانتهاء من دراسة الأجزاء التفصيلية.

---

## ا <span style="color:#D97706">أولاً: ملخص عقد الرهن</span>

| المسألة | الحكم |
|:--------|:------|
| ضابط ما يصح رهنه | كل ما جاز بيعه جاز رهنه |
| رهن الثمار قبل بدو الصلاح | يصح رهنها (وإن حرم بيعها)، لأن الدين لا يسقط بهلاكها |
| رهن القِن دون ولده | يصح لأنه حبس لا تفريق |
| لزوم الرهن | يلزم الراهن بالقبض، وللمرتهن فسخه متى شاء |
| التصرف بلا إذن | باطل من الطرفين |
| عتق الراهن للعبد | ينفذ وتؤخذ قيمته رهناً |
| يد المرتهن | يد أمانة، لا ضمان إلا بتعد أو تفريط |
| تعدد الرهن | ينفك في نصيب من وُفِّي دينه |
| بيع الرهن عند الحلول | إذن الراهن ← القاضي ← الحبس ← البيع الجبري |
| الغائب | كالممتنع، يبيع القاضي |
| شرط عدم البيع | باطل (مناقض لمقتضى العقد) |
| غلق الرهن | باطل ومحرم (لا يغلق الرهن) |
| انتفاع المرتهن | يحرم إلا ركوب ما يُركب وحلب ما يُحلب بقدر النفقة |
| النفقة بلا إذن مع إمكانه | تبرع لا رجوع فيه |
| النفقة بلا إذن مع تعذره | يرجع بالأقل (ما أنفقه أو نفقة المثل) إن نوى الرجوع |
| عمارة ما خرب | يرجع بالأعيان فقط (لا الأجرة) |

## ا <span style="color:#D97706">ثانياً: ملخص عقد الضمان</span>

| المسألة | الحكم |
|:--------|:------|
| شرط الضامن | جائز التصرف (بالغ عاقل رشيد) |
| ضمان ما وجب | صحيح (الدين الحال) |
| ضمان ما سيجب | صحيح (الدين المستقبلي) |
| ضمان الأمانات | لا يصح (لأنها غير مضمونة أصلاً) |
| ضمان التعدي على الأمانة | يصح (لأنه فعل مضمون) |
| ضمان الجزية | لا يصح |
| شرط الرضا | رضا الضامن فقط (لا يُشترط رضا المدين ولا الدائن) |
| مطالبة الدائن | له مطالبة من شاء: الأصيل أو الضامن |
| هروب الأصيل | لا يُعفي الضامن؛ عليه السداد |

---

## ا <span style="color:#D97706">ثالثاً: ملخص عقد الكفالة</span>

| المسألة | الحكم |
|:--------|:------|
| محل الكفالة | إحضار البدن أو العين (لا ضمان المال) |
| الكفالة ببدن | تصح ببدن من عليه حق مالي |
| الكفالة بعين | تصح بكل عين يصح ضمانها |
| شرط الرضا | رضا الكفيل فقط |
| موت الكفيل قبل الطلب | يبرأ وتسقط الكفالة |
| تلف العين بآفة سماوية قبل الطلب | يبرأ الكفيل |
| بعد المطالبة مع عجز الإحضار | يستقر الدين في ذمة الكفيل |
| الدين بعد موت الكفيل (إذا طُولب) | يُؤخذ من التركة لا من أموال الورثة |
| تلف العين بتعدٍ بشري | الكفيل يطالب المتعدي بالتعويض |

## ا <span style="color:#D97706">رابعاً: الفروق الجوهرية بين العقود الثلاثة</span>

| وجه المقارنة | **الرهن** | **الضمان** | **الكفالة** |
|:-------------|:---------|:----------|:-----------|
| نوع التوثيق | بعين مادية | بذمة ومال | ببدن أو إحضار عين |
| ما يلزم صاحبه | حبس العين حتى السداد | دفع الدين عند عجز الأصيل | إحضار الغريم أو العين |
| شرط الصحة | قبض العين | أهلية الضامن ورضاه | رضا الكفيل |
| الملكية | تبقى للراهن | لا تتعلق بملكية | لا تتعلق بملكية |
| عند هلاك المحل | لا يسقط الدين | لا يتأثر (الذمة باقية) | يبرأ الكفيل (قبل الطلب) |

## ا <span style="color:#D97706">خامساً: القواعد الفقهية المستخلصة</span>

1. **كل ما جاز بيعه جاز رهنه** — ضابط عام للرهن.
2. **الأمين لا يضمن إلا بتعد أو تفريط** — يد المرتهن يد أمانة.
3. **لا يغلق الرهن** — النهي النبوي عن جعل الرهن بديلاً عن الدين تلقائياً.
4. **الظهر يُركب بنفقته، ولبن الدُّرّ يُشرب بنفقته** — ضابط انتفاع المرتهن.
5. **العائد في هبته كالكلب يعود في قيئه** — المتبرع لا يرجع.
6. **الخراج بالضمان** — الربح والخسارة على من يتحمل المخاطر.
7. **الغارم ضامن** — من التزم بدين غيره غرم.
8. **كل شرط ليس في كتاب الله فهو باطل** — إبطال الشروط الفاسدة.
