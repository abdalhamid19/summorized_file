# 08 - ملخص المراجعة السريعة

> [!abstract] للمحاضرة 3 — باب البيع

---

## 🔑 في بطاقة واحدة

| الموضوع | الحكم المختصر |
|:--------|:--------------|
| بيع على بيع الأخ | حرام + لا يصح (حنابلة) |
| شراء على شراء الأخ | حرام + لا يصح |
| سوم على سوم الأخ | حرام السوم؛ البيع إن تم صحيح |
| المزاد | جائز (فعله النبي ﷺ) |
| بعد مفارقة المجلس | البيع لازم |
| شروط البيع vs في البيع | شرع vs متعاقدان |
| صحيح الشروط | مقتضى / مصلحة / نفع معلوم |
| شرطان (حنابلة) | يفسدان العقد |
| فاسد يُبطل/يمنع | خلاف المقتضى؛ عقد آخر؛ تعليق |
| شرط لا خسارة | شرط باطل + عقد صحيح |
| بريرة | الولاء لمن أعتق — شرط فاسد لم يُعتبر |
| براءة من عيب مجهول | لم يبرأ (مع تفصيل العلم) |
| خيار المجلس | ما لم يتفرقا بأبدانهما عرفًا |
| خيار الشرط | مدة معلومة بلا حيلة ربوية |

---

## 🧠 احفظ الفروق

1. **حرام ≠ باطل دائمًا** — السوم حرام والبيع قد يصح؛ شرط لا خسارة باطل والعقد يصح.
2. **المزاد ≠ شراء على شراء** — لا عقد سابق؛ البائع يطلب الزيادة.
3. **ضمان الجودة ≠ شرط عدم النفاق**.
4. **خيار مجلس ≠ خيار عيب**.
5. **تعليق البيع = لم ينعقد** — ليس بيعًا فاسد الآثار بل معدوم حتى إيجاب وقبول جديدين.

---

## 📚 أدلة مركزية

- «البيعان بالخيار ما لم يتفرقا»
- «لا يحل سلف وبيع ولا شرطين في بيع ولا بيع ما ليس عندك»
- «الولاء لمن أعتق»
- «الخراج بالضمان»
- «من عمل عملاً ليس عليه أمرنا فهو رد»
- النهي يقتضي الفساد (أصل حنابلة)
