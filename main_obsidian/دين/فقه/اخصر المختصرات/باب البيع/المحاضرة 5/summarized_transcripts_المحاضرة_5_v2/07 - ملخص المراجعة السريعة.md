# 07 - ملخص المراجعة السريعة

> [!abstract] بطاقة المراجعة المركزة للمحاضرة الخامسة — باب البيع
> تشمل هذه البطاقة أهم الضوابط والأحكام المستفادة من المحاضرة، مرتبة لسرعة الاستحضار والمذاكرة.

---

## في بطاقة واحدة

| الموضوع | الحكم والضابط الفقهي المختصر |
|:--------|:----------------------------|
| **شروط الصلاة والشروط فيها** | لا فرق بينهما في الصلاة لأن الشروط تستصحب وجوباً طوال الصلاة، والافتراق محله باب البيوع. |
| **شروط الوجوب vs شروط الصحة** | شروط الوجوب تقتضي لزوم الفعل وتكليفه (إسلام، بلوغ، عقل)، وشروط الصحة لا يُجزئ الفعل إلا بها (طهارة، سترة...). |
| **الحكم التكليفي والوضعي** | الشيء قد يزدوج فيه الوصفان؛ فالإسلام تكليفي ابتداءً، ووضعي من حيث كونه سبباً وعلامة على وجوب الصلاة. |
| **لزوم عقد المكيل ونحوه** | يلزم بالعقد ويثبت حق المشتري في ذمة البائع ويحق له إجباره قضاءً على التسليم. |
| **التصرف قبل القبض** | <span style="color:#E11D48; font-weight:bold;">يحرم ولا يصح</span> بيع أو هبة المكيل والموزون والمذروع قبل قبضه الشرعي. |
| **قبض المكيل والموزون والمذروع** | بالكيل أو الوزن أو الذرع بحضور المشتري أو وكيله، أو وضعه في كيده ووعائه. |
| **قبض الصُّبرة (الكومة)** | بنقلها إلى وعاء المشتري أو سيارته. |
| **قبض ما يُتناول** | بالتناول الحسي باليد؛ والذهب وإن قُوِّم بالوزن فقبضه بالتناول. |
| **قبض العقار والمخازن والسيارات** | بالتخلية وتسليم المفاتيح دون عائق. |
| **حكم الإقالة** | <span style="color:#0D9488; font-weight:bold;">سُنَّة مستحبة</span> في حق البائع لحديث: «من أقال مسلماً أقال الله عثرته». |
| **طبيعة الإقالة** | <span style="color:#0D9488; font-weight:bold;">فسخٌ</span> يرد عين الثمن؛ فإن نقص منه أو زاد خرج عن الإقالة وصار بيعاً جديداً. |
| **تصحيح بيع المعارض من مخازن الغير** | إما بالوكالة عن صاحب المخزن، أو بأن يقبض صبيّ/وكيل المعرض البضاعة في المخزن أولاً قبل تسليمها للمشتري. |
| **أقسام الربا** | ربا ديون (القروض المشروطة بنفع)، وربا بيوع (ربا فضل، وربا نسيئة). |
| **علة الربا عند الحنابلة** | <span style="color:#0D9488; font-weight:bold;">الكيل والوزن مع اتحاد الجنس</span>. |
| **الأصناف الستة** | الذهب، الفضة، البر، الشعير، التمر، الملح. |
| **بيع الربوي بجنسه** | يشترط: **المماثلة التامة** (مثلاً بمثل) و**التقابض والحلول** (يداً بيد / هاء وهاء)، وتهدر الجودة. |
| **بيع الربوي بغير جنسه مع اتحاد العلة** | كقمح بشعير: **يجوز التفاضل** و**يحرم النسيئة** (يشترط التقابض بالمجلس). |
| **بيع المعدودات والمذروعات ببعضها** | كأبواب أو ثياب: **يجوز التفاضل والنسيئة مطلقاً** لانتفاء الكيل والوزن. |
| **بيع التمر بالتمر** | مكيل؛ فلا يباع وزناً لاحتمال تفاوت أحجام الحبات وثقلها. |
| **حيلة تبديل الرديء بالجيد مع دفع الفارق** | <span style="color:#E11D48; font-weight:bold;">ممنوعة عند الجمهور (مد عجوة)</span>؛ والحل: بيع الرديء بالنقد أولاً ثم شراء الجيد به. |
| **بيع السلع بالأثمان (النقود)** | <span style="color:#0D9488; font-weight:bold;">يجوز التفاضل والتأجيل مطلقاً</span> بغير قيد. |
| **بيع مكيل بموزون من غير جنسه** | كبر بملح: <span style="color:#0D9488; font-weight:bold;">يجوز التفاضل والنسيئة مطلقاً</span> لاختلاف الجنس والعلة. |
| **صرف الذهب بالفضة** | يجوز التفاضل، و**يشترط التقابض قبل التفرق**؛ فإن افترقا بطل فيما لم يقبض. |

---

## احفظ الفروق الجوهرية

1. **لزوم العقد ≠ جواز التصرف:** لزوم العقد يثبت الحق في الذمة، بينما جواز البيع والهبة معلّق على تحقق القبض الشرعي.
2. **قبض التناول ≠ قبض الوزن:** الذهب يوزن لتقدير مقداره، لكن قبضه الشرعي لا يتم إلا بالتناول باليد.
3. **الإقالة (فسخ) ≠ البيع الجديد:** الإقالة استرداد لنفس الثمن دون ربح، أما إن نقص المردود ليربح البائع فهو بيع جديد مستأنف.
4. **ربا الفضل ≠ ربا النسيئة:** الفضل زيادة كمية في البدلين المتحدين، والنسيئة تأخير وقبض مؤجل في متحدي العلة.
5. **اتحاد العلة مع اختلاف الجنس ≠ اختلاف العلة والجنس:** قمح بشعير (متحد العلة) يحرم فيه النسيئة، بينما بر بملح (مختلف العلة) يجوز فيه النسيئة والتفاضل.

## أدلة وقواعد مركزية

- <span style="color:#D97706; font-weight:bold;">«من ابتاع طعاماً فلا يبعه حتى يستوفيه»</span> (قاعدة حظر التصرف قبل القبض).
- <span style="color:#D97706; font-weight:bold;">«من أقال مسلماً أقال الله عثرته يوم القيامة»</span> (فضل الإقالة والمسامحة).
- <span style="color:#D97706; font-weight:bold;">«لا تبع ما ليس عندك»</span> (ضابط صحة بيوع المعارض والمخازن).
- <span style="color:#D97706; font-weight:bold;">«مثلاً بمثل، يداً بيد، هاء وهاء»</span> (ضابط بيع الأموال الربوية المتحدة).
- <span style="color:#D97706; font-weight:bold;">«الجهل بالتساوي كالعلم بالتفاضل»</span> (قاعدة المنع من بيع التمر وزناً).
