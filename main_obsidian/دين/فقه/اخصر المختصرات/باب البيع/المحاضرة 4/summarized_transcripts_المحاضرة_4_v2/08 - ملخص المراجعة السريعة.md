# 08 - ملخص المراجعة السريعة

> [!abstract] للمحاضرة 4 — فصل الخيار

---

## في بطاقة واحدة

| الموضوع | الحكم المختصر |
|:--------|:--------------|
| أقسام الخيار | سبعة أسباب |
| خيار الشرط | مدة معلومة لأحدهما أو كليهما |
| حيلة ربوية بصورة الشرط | حرام + لا يصح البيع |
| الملك مدة الخيار | للمشتري؛ الخراج بالضمان |
| التصرف الناقل للملك مدة الخيار | يحرم ولا يصح إلا عتقًا أو والخيار له |
| خيار الغبن | زيادة خارجة عن العادة بخداع (نجش/غش/استعجال) |
| حد الربح | لا حد معيّن مع مشترٍ خبير بلا غش |
| خيار التدليس | بما يزيد الثمن (تصرية، تسويد شعر، تجميل خادع) |
| غبن وعيب وتدليس | على التراخي ما لم يوجد دليل رضا |
| التصرية | ثلاثة أيام بنص النبي ﷺ |
| خيار العيب | إمساك مع أرش أو رد مع الثمن |
| تلف/عتق بعد ثبوت العيب | تعيّن الأرش |
| عيبان (بائع + مشترٍ) | أرش الأصلي أو رد مع دفع أرش الحادث |
| الاختلاف في حدوث العيب | قول المشتري بيمينه |
| تخبير الثمن | خيار المشتري إن بان خلاف الإخبار |
| اختلاف الثمن ولا بينة | تحالف ثم فسخ إن لم يرضَ أحد بقول الآخر |
| تلف ثم تحالف | غرم المشتري بقيمة وقت الشراء |
| اختلاف أجل/شرط | قول النافي (الأصل العدم) |
| اختلاف العين/القدر | قول البائع |
| خلاف الأوصاف عند التسليم | يثبت الخيار |
| مطابقة الصفة | ثبت البيع بلا خيار |
| رد بعد اللزوم بخصم | عقد جديد / إقالة مندوبة |

---

## احفظ الفروق

1. **انتفاع ≠ تصرف ناقل للملك** — الانتفاع مدة الخيار جائز؛ البيع/الهبة لا.
2. **ربح كثير ≠ غبن** — الغبن خداع خارج العادة؛ الخبير لا خيار له لمجرد غلاء الربح.
3. **تراخي ≠ رضا** — التراخي مباح حتى يظهر دليل الرضا (استعمال، هبة، بيع، تأخير فاحش).
4. **خيار عيب ≠ خيار شرط** — العيب سبب مستقل بلا اشتراط مدة.
5. **مجلس ≠ قبض** — ارتفاع المجلس لا يلغي أن التسليم قبض لاحق.
6. **بينة مقدمة على يمين** — إن تعادلت البينات أو عُدمت → التحالف.
7. **إقالة ≠ فسخ بخيار** — بعد اللزوم الرد برضا = عقد جديد أو إقالة.

## أدلة وقواعد مركزية

- الخراج بالضمان / الغنم بالغرم
- أمر النبي ﷺ في المصرّاة بثلاثة أيام
- «من أقال عثرة مسلم أقال الله عثرته يوم القيامة»
- «تهادوا تحابوا»
- قبول النبي ﷺ الهدية دون أكل الصدقة
- «وأما السائل فلا تنهر»
