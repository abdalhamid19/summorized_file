## الأحكام الفقهية في المحاضرة

| الحكم | التفصيل |
|:------|:--------|
| <span style="color:#0D9488; font-weight:bold;">جائز</span> | خيار الشرط بمدة معلومة لأحدهما أو كليهما |
| <span style="color:#E11D48; font-weight:bold;">حرام + لا يصح البيع</span> | الحيلة بخيار الشرط لأكل الربا |
| <span style="color:#0D9488; font-weight:bold;">ينتقل الملك للمشتري</span> | في مدة الخيار؛ الربح له والضمان عليه |
| <span style="color:#E11D48; font-weight:bold;">يحرم ولا يصح</span> | التصرف الناقل للملك في المبيع وعوضه مدة الخيار (إلا العتق / إلا إذا كان الخيار له) |
| <span style="color:#0D9488; font-weight:bold;">على التراخي</span> | خيار الغبن والعيب والتدليس ما لم يوجد دليل الرضا |
| <span style="color:#D97706; font-weight:bold;">ثلاثة أيام</span> | استثناء التصرية |
| <span style="color:#0D9488; font-weight:bold;">تخيير</span> | عند العلم بالعيب: إمساك مع أرش أو رد مع أخذ الثمن |
| <span style="color:#0D9488; font-weight:bold;">قول المشتري بيمينه</span> | عند الاختلاف في حدوث العيب |
| <span style="color:#0D9488; font-weight:bold;">قول النافي</span> | عند الاختلاف في الأجل أو الشرط لأن الأصل عدمه |
| <span style="color:#0D9488; font-weight:bold;">قول البائع</span> | عند الاختلاف في عين المبيع أو قدره |
| <span style="color:#0D9488; font-weight:bold;">عقد جديد</span> | رد السلعة بعد لزوم البيع برضا الطرفين (إقالة أو بيع جديد) |
