### **الجزء الأول: إعداد الاتصال واستخراج البروكسي**

**الفترة الزمنية:** (00:00 - 03:00)

#### **الملخص العلمي المنظم**

شرح المتحدث كيفية تحويل اتصال الـ VPN إلى بروكسي (IP وبورت) لاستخدامه في الشبكات الداخلية أو الخارجية. بدأت العملية باستخدام برنامج **Comet VPN** واختيار نوع اتصال **Residential IP** لدولة معينة (مثل ألمانيا). لاستخراج هذا الاتصال كبروكسي، يتم استخدام برنامج وسيط يسمى **Clash for Windows**.

#### **الخطوات أو المراحل**

1. **تشغيل Comet VPN:** اختيار الدولة ونوع الاتصال (Residential) والانتظار حتى الربط.
2. **إعداد Clash for Windows:**
    - تفعيل خيار **Allow LAN** للسماح بالاتصال عبر الشبكة.
    - تفعيل خيار **System Proxy**.
    - تحديد **البورت (Port)** المطلوب استخدامه (الافتراضي 7890).
3. **إعداد جدار الحماية (Firewall):** إضافة قاعدة جديدة (New Rule) للسماح بمرور البيانات عبر البورت المحدد (مثلاً 7890) ليعمل الاتصال بشكل "Global".

#### **التصنيفات أو التقسيمات**

|القسم|التفاصيل|
|:--|:--|
|**أنواع الاتصال المتاحة**|VPN عادي، Dedicated، Residential (تخفي).|
|**خيارات البرنامج الوسيط**|Allow LAN، System Proxy، Start with Windows.|

> ⚠️ **تنبيه** يجب التأكد من إضافة البورت في الفاير وول (Firewall) والسماح له بالاتصال (Allow the connection) لضمان عمل البروكسي خارج الجهاز أو الـ VPS.

### **الجزء الثاني: التجربة والتطبيق العملي**

**الفترة الزمنية:** (03:00 - 08:00)

#### **الملخص العلمي المنظم**

بعد إعداد البروكسي، يتم اختباره على متصفحات متعددة الحسابات (Multi-browsers). القاعدة الأساسية هي استخدام **الـ IP العام (Public IP)** الخاص بالجهاز أو الـ VPS الذي يعمل عليه البرنامج، مع **البورت** الذي تم ضبطه في برنامج Clash. عند تغيير الـ IP داخل برنامج الـ VPN، يتحدث الـ IP الخاص بالبروكسي تلقائياً دون الحاجة لتغيير الإعدادات في البرامج الأخرى.

#### **الأمثلة والتطبيقات**

- **التطبيق الداخلي:** استخدام متصفح **IX Browser** على نفس الجهاز، وإدخال IP الـ VPS وبورت 7890.
- **التطبيق الخارجي:** استخدام متصفح **Dolphin Anty** على جهاز شخصي مختلف تماماً، وإدخال نفس بيانات IP الـ VPS والبورت، مما يؤدي لظهور IP الـ VPN الألماني على الجهاز الشخصي.

#### **الفوائد أو النتائج**

- إمكانية تشغيل البروكسي على أي جهاز خارج شبكة الـ VPS.
- ثبات الإعدادات (IP الماكينة والبورت) حتى مع تغير IP الـ VPN المستخدم.
- سهولة التنقل بين الدول وأنواع الـ IP (Residential/Dedicated) بمجرد تغييرها في البرنامج الأصلي.
