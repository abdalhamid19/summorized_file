# 1️⃣ التفريغ والتلخيص العلمي المنظم

### 1. المقدمة والهدف الأساسي من الشرح (`00:00 - 00:43`)
يقدم الشرح طريقة احترافية لتحويل أي اتصال شبكة خاصة افتراضية **VPN** إلى بروتوكول **Proxy** (سواء كان **SOCKS5** أو **HTTP**) واستخراج **Public IP** و **Port** خاص به، مما يتيح استخدامه وتوزيع الاتصال على أي برنامج أو متصفح داخل الشبكة المحلية (LAN) أو عبر الأجهزة الخارجية البعيدة على شبكة الإنترنت.

### 2. إعداد برنامج VPN واختيار IP السكني (`00:43 - 02:16`)
- فتح برنامج **Comnet VPN** واختيار نوع الاتصال المطلوب (سواء كان اتصال VPN عادي، أو Dedicated، أو <span style="color:#0D9488; font-weight:bold;">Residential IP</span>، أو وضع التخفي Stealth).
- تحديد دولة الاتصال (مثل ألمانيا Germany).
- بدء عملية الاتصال والانتظار حتى الربط، ثم عمل Refresh للتحقق من الحصول على عنوان IP السكني الجديد (مثل IP ينتهي بـ `128`).

### 3. تثبيت وتهيئة برنامج Clash for Windows (`02:16 - 03:08`)
- تثبيت برنامج <span style="color:#0D9488; font-weight:bold;">Clash for Windows</span> بخطوات تثبيت اعتيادية سلسة (`Next -> Next -> Finish`).
- تفعيل الخيارات التشغيلية في واجهة البرنامج:
  1. تفعيل خيار <span style="color:#0D9488; font-weight:bold;">Allow LAN</span> لتميل السماح للشبكة المحلية والأجهزة الخارجية بالاتصال بالمنفذ.
  2. تفعيل خيار <span style="color:#0D9488; font-weight:bold;">System Proxy</span>.
  3. (اختياري) تفعيل البدء التلقائي مع الويندوز (Start with Windows).
- تحديد رقم المنفذ (<span style="color:#0D9488; font-weight:bold;">Port</span>): المنفذ الافتراضي المعتمد هو `7890` ويدعم كلاً من بروتوكول HTTP و SOCKS5 مع إمكانية تعديله.

### 4. ضبط قواعد جدار الحماية Windows Firewall (`03:08 - 04:43`)
- الدخول إلى إعدادات جدار الحماية (Windows Firewall Advanced Settings) وتحديد قواعد الاتصال الوارد (**Inbound Rules**).
- إنشاء قاعدة جديدة (**New Rule**) وتخصيصها لنوع **Port**.
- تحديد رقم المنفذ **`7890`** (أو المنفذ المخصص في Clash).
- اختيار **Allow the connection** لتمرير الاتصالات كافة بدون حجب عبر الشبكة الداخلية والخارجية.
- إعطاء اسم معبر للقاعدة (مثل `7890`) وإنهاء الإعداد (**Finish**).

### 5. تطبيق واختبار البروكسي على المتصفحات المتعددة محلياً (`04:43 - 08:38`)
- فتح متصفح إدارة الحسابات المتعددة (**IxBrowser**).
- إنشاء ملف شخصي جديد (**Create Profile**) والانتقال لإعدادات البروكسي.
- اختيار نوع البروكسي **SOCKS5** أو **HTTP**.
- <span style="color:#E11D48; font-weight:bold;">ملاحظة هامة:</span> لا يتم وضع IP الـ VPN الداخلي، بل يتم وضع الـ **Public IP** الخارجي للجهاز أو سيرفر الـ VPS المضيف (مثال: `89.167.1.81`) مع المنفذ `7890`.
- عند فحص واختبار الاتصال، يخرج الاتصال بالـ **Residential IP** المنبثق من برنامج الـ VPN (مثل IP ينتهي بـ `15`).

### 6. تشغيل البروكسي على جهاز بعيد خارج شبكة الـ VPS (`08:38 - 10:37`)
- فتح متصفح **Dolphin Anty** على جهاز كمبيوتر شخصي آخر بعيد كلياً عن سيرفر الـ VPS.
- إضافة البروكسي بنوع **SOCKS5** وإدخال Public IP الخاص بسيرفر الـ VPS والمنفذ `7890`.
- عند الضغط على **Check Proxy** والبدء، يتصل الجهاز البعيد بنجاح ويظهر نفس الـ IP السكني الظاهر على الـ VPS.

### 7. المرونة وتغيير IP تلقائياً بدون تعديل الإعدادات (`10:37 - 12:38`)
- عند تغيير سيرفر أو IP الـ VPN داخل برنامج Comnet VPN (مثال: الحصول على IP جديد ينتهي بـ `99`):
  - لا تتطلب العملية أي تعديل على إعدادات البروكسي في المتصفحات أو الأجهزة البعيدة.
  - بمجرد تحديث الصفحة (Refresh) في IxBrowser أو Dolphin Anty، يتم سحب الـ IP الجديد فوراً وتلقائياً عبر طبقة الوساطة (Clash Layer).

# 2️⃣ استخراج المعلومات العلمية والتقنية

### 📖 التعريفات والمصطلحات العلمية

| المصطلح | التعريف العلمي والتقني |
| :--- | :--- |
| <span style="color:#0D9488; font-weight:bold;">VPN (Virtual Private Network)</span> | شبكة افتراضية خاصة تقوم بتشفير حركة البيانات وتوجيهها عبر سيرفر وسيط لتغيير موقع المستخدم وعنوان IP الخاص به. |
| <span style="color:#0D9488; font-weight:bold;">Proxy (البروكسي)</span> | خادم وسيط يعمل كبوابة بين المستخدم وإنترنت، يتلقى الطلبات من البرامج ويقوم بتمريرها وإعادة توجيهها بعنوان IP خاص به. |
| <span style="color:#0D9488; font-weight:bold;">SOCKS5 / HTTP Proxy</span> | بروتوكولات توجيه البروكسي؛ حيث يعمل HTTP على مستوى تصفح الويب، بينما يعمل SOCKS5 على مستوى أدنى لنقل جميع أنواع الترافيك والبيانات. |
| <span style="color:#0D9488; font-weight:bold;">Residential IP</span> | عنوان IP صادر من مزودي خدمة الإنترنت المنزليين الحقيقيين (ISPs)، ويمتاز بدرجة موثوقية عالية جداً وقدرة على تجنب الحظر. |
| <span style="color:#0D9488; font-weight:bold;">Clash for Windows</span> | برنامج وسيط (GUI Client) لإدارة وتوجيه حركة المرور وتجميع الاتصالات وتحويلها إلى خوادم بروكسي محلية أو شبكية. |
| <span style="color:#0D9488; font-weight:bold;">Allow LAN</span> | خيار تشغيلي داخل برنامج Clash يسمح للأجهزة الأخرى على الشبكة المحلية أو الخارجية بالوصول إلى خادم البروكسي عبر المنفذ المفتوح. |
| <span style="color:#0D9488; font-weight:bold;">Public IP</span> | عنوان بروتوكول الإنترنت الظاهر المباشر الخاص بالسيرفر أو الجهاز على شبكة الإنترنت العالمية، وهو العنوان المستخدم للربط الخارجي. |
| <span style="color:#0D9488; font-weight:bold;">Inbound Rule (Windows Firewall)</span> | قاعدة اتصال واردة في جدار حماية الويندوز تسمح بمرور حركة البيانات القادمة من الخارج نحو منفذ (Port) محدد على الجهاز. |

### 🔢 الخطوات والمراحل العملية

1. **إعداد اتصال VPN:**
   - فتح برنامج **Comnet VPN**.
   - اختيار **Residential IP** واختيار الدولة (مثل ألمانيا).
   - الضغط على اتصال والتحقق من تغير الـ IP السكني عبر موقع الفحص.

2. **تهيئة برنامج Clash for Windows:**
   - تثبيت البرنامج وبدء التشغيل.
   - مفتاح تفعيل **Allow LAN** وتفعيل **System Proxy**.
   - التأكد من رقم المنفذ الافتراضي **`7890`**.

3. **تكوين جدار الحماية (Windows Firewall):**
   - فتح `Windows Defender Firewall with Advanced Security`.
   - الانتقال إلى **Inbound Rules** ثم **New Rule**.
   - اختيار **Port** -> تخصيص الرقم **`7890`** -> اختيار **Allow the connection**.
   - تطبيق القاعدة على جميع نطاقات الشبكة وتسميتها باسم المنفذ (`7890`).

4. **تطبيق البروكسي واختباره:**
   - إدخال **Public IP** للجهاز المضيف + **Port `7890`** في برنامج الإدارة (مثل IxBrowser أو Dolphin Anty).
   - إجراء اختبار البروكسي (Check Proxy) والتأكد من مطابقة الـ IP السكني الظاهر.

### 🎯 الفوائد والنتائج العلمية

- <span style="color:#0D9488; font-weight:bold;">تحويل اشتراك VPN واحد إلى مصدر بروكسيات غير محدود:</span> إمكانية تحويل أي اتصال VPN سكني أو عادي إلى بروكسي SOCKS5/HTTP جاهز للاستخدام.
- <span style="color:#0D9488; font-weight:bold;">التحديث الديناميكي التلقائي (Dynamic IP Auto-Sync):</span> عند تغيير الـ IP داخل برنامج الـ VPN، يتحدث البروكسي تلقائياً في جميع المتصفحات والأجهزة المربوطة دون الحاجة لتعديل البيانات.
- <span style="color:#0D9488; font-weight:bold;">الربط الخارجي العابر للشبكات (Global Proxy Sharing):</span> إمكانية ربط أجهزة منزلية شخصية بسيرفر VPS بعيد واستخدام البروكسي كأنه بروكسي سكني مدفوع مخصص.

### ⚠️ التنبيهات والأخطاء الشائعة

> <span style="color:#E11D48; font-weight:bold;">⚠️ تنبيه 1: عدم استخدام IP الـ VPN الداخلي أو اللوكال</span>
> عند إعداد البروكسي في المتصفحات أو الأجهزة الأخرى، **لا تضع** IP الـ VPN الناتج، بل يجب وضع **Public IP** الخاص بجهازك أو سيرفر الـ VPS المضيف؛ وإلا فلن ينجح الاتصال.

> <span style="color:#E11D48; font-weight:bold;">⚠️ تنبيه 2: عدم تفعيل Allow LAN أو اغلاق جدار الحماية</span>
> إذا نسيت تفعيل خيار **Allow LAN** في برنامج Clash أو لم تقم بإضافة منفذ `7890` في قواعد **Inbound Rules** بـ Windows Firewall، فلن تتمكن الأجهزة الخارجية من الاتصال بالبروكسي.

> <span style="color:#E11D48; font-weight:bold;">⚠️ تنبيه 3: معالجة توقف استجابة البروكسي الفجائية</span>
> في حال حدوث عدم استجابة للبروكسي أثناء الفحص، قم بإيقاف خيار **Allow LAN** في برنامج Clash ثم إعادة تفعيله فوراً للنعاش القواعد وتحديث الارتباط.
