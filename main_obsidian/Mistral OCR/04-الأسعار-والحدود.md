# الأسعار والحدود

## الأسعار

> [!warning] تغيّر السعر بين الإصدارات
> الأسعار تختلف بين النموذج الأصلي (المهجور) و OCR 4 الحالي.

| النموذج | السعر | ملاحظة | المصدر |
|---|---|---|---|
| OCR 2503 (عند الإطلاق، مارس 2025) | **$1 / 1000 صفحة** | ~2x مع batch **[ادعاء تسويقي]** | [news/mistral-ocr](https://mistral.ai/news/mistral-ocr) |
| **OCR 4 — OCR عادي** | **$4 / 1000 صفحة** | الحالي | [pricing/api](https://mistral.ai/pricing/api/) |
| **OCR 4 — Document AI (مُعلَّق)** | **$5 / 1000 صفحة** | مع annotations | [pricing/api](https://mistral.ai/pricing/api/) |
| مكتبات (Libraries tool) | $3 / 1000 صفحة | — | [ocr-4 model card](https://docs.mistral.ai/models/model-cards/ocr-4-0) |
| Batch processing | **−50%** | خصم الدُفعات | [ocr-4 model card](https://docs.mistral.ai/models/model-cards/ocr-4-0) |

> [!info] السعر الحالي للنموذج المهجور 2503: غير مؤكد (صفحة الأسعار تعرض OCR 4 فقط).

## الحدود التقنية

| الحد | القيمة | المصدر |
|---|---|---|
| حجم الملف الأقصى | **50 MB** | [basic_ocr FAQ](https://docs.mistral.ai/studio-api/document-processing/basic_ocr) |
| عدد الصفحات الأقصى | **1000 صفحة** | [basic_ocr FAQ](https://docs.mistral.ai/studio-api/document-processing/basic_ocr) |
| تحديد الصفحات | `pages` (0-indexed) — `"0-5"`, `"0,2-4"` | [api reference](https://docs.mistral.ai/api/endpoint/ocr) |
| Rate limits | غير منشورة (تعتمد على فئة الاشتراك) | **غير مؤكد** |

> نص الـ FAQ الحرفي: *"Uploaded document files must not exceed 50 MB in size and should be no longer than 1,000 pages."*
