# نظرة عامة — ما هو Mistral OCR

خدمة OCR سحابية من **Mistral AI** تُحوّل المستندات والصور إلى نص (Markdown) مع الحفاظ على البنية.

## الحقائق الأساسية

| البند | القيمة | المصدر |
|---|---|---|
| الإصدار الأول | 6 مارس 2025 | [mistral.ai/news/mistral-ocr](https://mistral.ai/news/mistral-ocr) |
| معرّف النموذج | `mistral-ocr-latest` (الأصلي `mistral-ocr-2503`) | [docs](https://docs.mistral.ai/api/endpoint/ocr) |
| نقطة الوصول | `POST https://api.mistral.ai/v1/ocr` | [docs](https://docs.mistral.ai/api/endpoint/ocr) |
| SDK | Python / TypeScript عبر `client.ocr.process(...)` | [docs](https://docs.mistral.ai/api/endpoint/ocr) |
| النوع | سحابي فقط (لا أوزان مفتوحة) | — |

## الإصدارات

```
OCR 25-03 → OCR 2 (25-05) → OCR 3 (25-12) → OCR 4 (يونيو 2026)
```

> [!warning] إهمال النموذج الأصلي
> صفحة الإعلان الأصلية تحمل لافتة: "هذا النموذج مهجور… استُبدل بنماذج OCR الأحدث الأقوى" (OCR 4, يونيو 2026). الاسم `mistral-ocr-latest` ما زال يعمل ويشير حالياً إلى الإصدار الأحدث.
> المصدر: [mistral.ai/news/mistral-ocr](https://mistral.ai/news/mistral-ocr) · [ocr-4 model card](https://docs.mistral.ai/models/model-cards/ocr-4-0)

## ما الذي يستخرجه

- نص الصفحة بصيغة **Markdown** (كل صفحة في `pages[i].markdown`)
- الصور المضمّنة مع إحداثياتها (`images[]` مع bbox)
- الجداول (markdown أو html)
- بنى مُنشأة (blocks) بعناوين/فقرات/جداول/معادلات — **OCR 4 فقط** عبر `include_blocks=True`

## الصيغ المقبولة

- **مستندات**: pdf, docx, pptx, xlsx, txt, epub, xml, rtf, odt وغيرها
- **صور**: png, jpeg, avif, tiff, gif, heic, bmp, webp

المصدر: [basic_ocr FAQ](https://docs.mistral.ai/studio-api/document-processing/basic_ocr)
