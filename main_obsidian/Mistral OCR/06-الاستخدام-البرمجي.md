# الاستخدام البرمجي (Python SDK)

## التثبيت

```bash
pip install mistralai
export MISTRAL_API_KEY="your_key"
```

## OCR عبر رابط مستند

```python
import os
from mistralai import Mistral

client = Mistral(api_key=os.environ["MISTRAL_API_KEY"])

resp = client.ocr.process(
    model="mistral-ocr-latest",
    document={
        "type": "document_url",
        "document_url": "https://example.com/doc.pdf",
    },
    include_image_base64=True,
)

for page in resp.pages:
    print(page.markdown)   # نص الصفحة بصيغة Markdown
    for img in page.images:  # الصور مع إحداثياتها
        print(img.id, img.top_left_x, img.top_left_y)
```

## OCR عبر ملف مرفوع (file id)

```python
uploaded = client.files.upload(
    file={"file_name": "doc.pdf", "content": open("doc.pdf", "rb")},
    purpose="ocr",
)
resp = client.ocr.process(
    model="mistral-ocr-latest",
    document={"type": "file", "file_id": uploaded.id},
)
```

## OCR عبر صورة base64

```python
import base64
b64 = base64.b64encode(open("img.png", "rb").read()).decode()
resp = client.ocr.process(
    model="mistral-ocr-latest",
    document={
        "type": "image_url",
        "image_url": f"data:image/png;base64,{b64}",
    },
)
```

## إخراج مُهيكل (Pydantic)

```python
from pydantic import BaseModel, Field

class Invoice(BaseModel):
    total: str = Field(description="المبلغ الإجمالي")
    date: str = Field(description="تاريخ المستند")

resp = client.ocr.process(
    model="mistral-ocr-latest",
    document={"type": "document_url", "document_url": url},
    document_annotation_format=response_format_from_pydantic_model(Invoice),
)
print(resp.document_annotation)  # JSON مُهيكل
```

## سؤال وجواب عن المستند

```python
chat = client.chat.complete(
    model="mistral-small-latest",
    messages=[{
        "role": "user",
        "content": [
            {"type": "document_url", "document_url": url},
            {"type": "text", "text": "لخص هذا المستند"},
        ],
    }],
)
```

## معاملات مفيدة

| المعامل | الوظيفة |
|---|---|
| `pages` | تحديد صفحات (0-indexed) — `[0,1,2]` أو `"0-5"` |
| `include_image_base64` | تضمين الصور base64 |
| `table_format` | `markdown` / `html` |
| `include_blocks` | كتل البنية (OCR 4 فقط) |
| `bbox_annotation_format` | مخطط لكل صورة |
| `document_annotation_format` | مخطط لكامل المستند |

المصدر: [docs.mistral.ai/api/endpoint/ocr](https://docs.mistral.ai/api/endpoint/ocr)
