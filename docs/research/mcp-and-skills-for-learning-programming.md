# خيارات MCP والمهارات لتعلّم البرمجة

تاريخ المراجعة: 4 نوفمبر 2026

## الخلاصة

`MCP` هو بروتوكول يتيح للمساعد استخدام أدوات أو قراءة بيانات من خدمات أخرى. أما `Skill` فهي تعليمات وموارد تنظّم طريقة إنجاز مهمة متكررة. لذلك، MCP مفيد لجلب التوثيق أو تشغيل الشيفرة، والـSkill مفيدة لتوجيه المساعد إلى أسلوب تدريس متدرّج. هذا التفريق استنتاج عملي من وصف MCP لقدرات الخادم، ومن تعريف Skills كسير عمل قابل لإعادة الاستخدام. [وثائق MCP Python SDK](https://py.sdk.modelcontextprotocol.io/get-started/first-steps/) · [شرح OpenAI للـSkills](https://developers.openai.com/plugins/concepts/skills)

لم أجد في قائمة الأدوات المتصلة بهذه الجلسة MCP مخصصًا لتعليم البرمجة. تتوفر أدوات للعمل مع الملفات والطرفية، وبيئة JavaScript، كما تتوفر مهارات محلية تساعد على الشرح والاختبار. لم أثبّت خادمًا أو مهارة خارجية.

## خوادم MCP المفيدة

| الخيار | فائدته للتعلم | حدود الاستخدام |
|---|---|---|
| **Jupyter MCP Server** من Datalayer | يربط المساعد بدفتر `Jupyter Notebook`، وهو دفتر تفاعلي يجمع الشرح والشيفرة والناتج. يمكن للمتعلم كتابة خلية Python، تشغيلها، ثم رؤية الناتج ومناقشة الخطأ. يدعم خوادم Jupyter محلية أو بعيدة، وخيارات تنفيذ معزولة. [الوثائق](https://jupyter-mcp-server.datalayer.tech/) · [دليل البدء وبيئات التنفيذ](https://jupyter-mcp-server.datalayer.tech/getting_started/) | يحتاج خادم Jupyter أو بيئة تنفيذ أخرى وإعداد اتصال. بما أنه ينفذ الشيفرة، ينبغي استخدام بيئة معزولة، وتفعيل المصادقة عند إتاحته عبر الشبكة. الخادم يوفر مكانًا للتجربة؛ لا يفرض منهجًا تعليميًا. [الأمان](https://jupyter-mcp-server.datalayer.tech/security/) |
| **Context7** | يجلب مقاطع من توثيق مكتبة محددة وأمثلة مرتبطة بإصدارها. يمكن تشغيله كـMCP أو باستخدام `CLI` (واجهة سطر الأوامر) مع Skill باسم `find-docs`. مفيد عندما يتعلم الطالب مكتبة أو إطار عمل، مثل البحث عن واجهة مكتبة بعد أن يفهم المفهوم الأساسي. [المستودع الرسمي](https://github.com/upstash/context7) · [شرح التثبيت والأدوات](https://github.com/upstash/context7/blob/master/docs/clients/cli.mdx) | ليس مدرسًا للمفاهيم الأساسية. يوضح المشروع أن محتوى المكتبات يساهم به أصحاب تلك المكتبات، ولا يضمن Context7 دقته أو أمانه؛ تحقّق من التوثيق الرسمي للمكتبة في المسائل المهمة. يتطلب اتصالًا بالخدمة، وقد يفيد مفتاح API في رفع حدود الاستخدام. |
| **GitHub MCP Server** من GitHub | يتيح قراءة المستودعات وملفات الشيفرة، ومقارنة أمثلة حقيقية لفهم تنظيم المشروع ومراجعة التغييرات. [المستودع الرسمي](https://github.com/github/github-mcp-server) | لا يشغّل الشيفرة. يتطلب المصادقة عند استخدام المستودعات الخاصة أو خصائص الحساب، ويمكن تقييد الأدوات بوضع القراءة فقط `--read-only`. وللقراءة من مستودع موجود محليًا، أدوات المشروع الحالية تكفي غالبًا. |

## المهارات المتاحة والمرشحة

### مهارات موجودة في المشروع

- [`assignment-solver`](../../.agents/skills/assignment-solver/SKILL.md) يشرح الواجبات بالعربية وينظم الحل في ملاحظة Obsidian. يفيد عند وجود تمرين محدد، لكنه موجّه لإكمال الحل، وليس لمسار عام يقيس الاستقلال في البرمجة. يمكن طلب التلميحات والمحاولة قبل كشف الحل.
- [`python-design-patterns`](../../.agents/skills/python-design-patterns/SKILL.md) يشرح مبادئ تنظيم مكوّنات Python. يفيد بعد فهم الأساسيات، مثل السؤال عن سبب فصل `config` و`renderer` و`preprocessing` و`ocr` و`pipeline` في بنية المشروع.
- [`python-testing-patterns`](../../.agents/skills/python-testing-patterns/SKILL.md) يشرح `pytest` (أداة لاكتشاف وتشغيل اختبارات Python) و`fixtures` (بيانات أو إعدادات مساعدة للاختبارات). يفيد في التدريب على كتابة اختبارات والتحقق من السلوك.

لم أجد في القائمة المتاحة Skill عامة متخصصة في تعليم البرمجة خطوة بخطوة.

### مهارات أخرى ظاهرة في كتالوج الجلسة

`systematic-debugging` للتشخيص المنظم، و`TDD` (التطوير المبني على الاختبارات)، و`clean-code` لجودة الشيفرة. تفيد في ممارسة محددة؛ لا تمثل منهجًا كاملًا لتعلّم البرمجة.

### مرشحان خارجيان غير رسميين

- **`learn` من `derwells/skills`** ينظم درسًا واحدًا أو مسار دراسة، ويتيح التعلم العابر دون حفظ ملفات. المسار المستمر يحفظ التقدم، وقد يحتاج أدوات إضافية عند استخدام الدفاتر. [ملف المهارة](https://raw.githubusercontent.com/derwells/skills/main/skills/learn/SKILL.md). لم أتحقق من دعم Windows في المصادر التي راجعتها، لذلك لا أتعامل معها كخيار جاهز لهذا الجهاز.
- **`teach-upgrade`** يصف نفسه بأنه Skill لتشخيص مستوى المتعلم، ورسم خريطة للموضوع، ثم التدريب إلى أن يستطيع المتعلم شرح الفكرة. يحفظ الحالة في مجلد `topics/`، ويذكر صاحبه إمكانية استخدام الملف مع Codex. [المستودع والشرح](https://github.com/casankalppawar/teach-upgrade). لكنه مشروع شخصي صغير وغير معتمد رسميًا؛ أظهرت صفحة GitHub صفر نجوم وسبعة تغييرات مسجلة وقت المراجعة. عدد النجوم ليس دليلًا كافيًا على الجودة أو الأمان؛ يلزم فحص المهارة والملفات التي تنشئها قبل إضافتها.

## مثال تطبيقي من هذا المشروع

يمكن بناء درس Python على بنية حزمة `arabic_pdf_ocr/` الموجودة فعلًا: يتتبع المتعلم دور `config` ثم `renderer` ثم `preprocessing` ثم `ocr` و`postprocessing` و`quality` ضمن `pipeline`. يبدأ الشرح ببيان وظيفة كل وحدة، ثم يطلب من المتعلم توقّع مكان حدوث خطوة معينة، وبعدها يناقش الإجابة ويفحص اختبارًا مناسبًا. هذه طريقة لا تحتاج MCP إضافيًا لقراءة ملفات المشروع؛ ويمكن إضافة Jupyter MCP إذا كان الهدف تشغيل خلايا تجريبية منفصلة.

### طريقة استخدام مقترحة

استخدم Skill أو تعليمات واضحة تطلب: شرحًا عربيًا بسيطًا، وإبقاء المصطلح التقني بالإنجليزية مع تعريف عربي موجز، ثم مثالًا من المشروع، ثم تمرينًا صغيرًا، وتلميحًا تدريجيًا قبل عرض الحل. استخدم MCP فقط عند الحاجة إلى تنفيذ الشيفرة أو جلب توثيق مكتبة. هذه الطريقة تجعل المساعد يوجّه التعلّم بدل الاكتفاء بإنتاج إجابة جاهزة.

تدعم دراسة تحليلية لـ225 دراسة جامعية في مجالات العلوم والهندسة والرياضيات استخدام التعلم النشط، ووجدت متوسط أداء أعلى في مجموعات التعلم النشط مقارنة بالمحاضرات التقليدية. نطاق الدراسة هو التعليم الجامعي في STEM؛ وهي لا تثبت أن Skill أو MCP بعينه يحسّن تعلم البرمجة. [دراسة PNAS](https://doi.org/10.1073/pnas.1319030111)

## التوصية

ابدأ بالمهارات المحلية الموجودة وبالشيفرة والاختبارات في المستودع. أضف **Jupyter MCP** إذا احتجت تشغيل تمارين Python داخل دفتر، و**Context7** إذا احتجت توثيق مكتبة أو إطار عمل بإصدار محدد. جرّب Skill خارجية مثل `teach-upgrade` فقط بعد مراجعة تعليماتها والملفات التي تنشئها. لا حاجة إلى GitHub MCP عند قراءة هذا المستودع المحلي، إلا إذا أردت دراسة مستودعات عامة أخرى.

للمبتدئ تمامًا، دورة Harvard المفتوحة **CS50’s Introduction to Programming with Python (CS50P)** تقول إنها مناسبة لمن لديه خبرة سابقة في البرمجة أو لا يملكها، وتضم وحدات عن المتغيرات والحلقات والاختبارات وتصحيح الأخطاء. دليل Python الرسمي يوضح أنه يفترض معرفة أساسية بالبرمجة؛ لذا يصلح أكثر لمن يعرف المبادئ ويريد تعلم Python. [دورة CS50P](https://cs50.harvard.edu/python/) · [Python Tutorial الرسمي](https://docs.python.org/3/tutorial/)
