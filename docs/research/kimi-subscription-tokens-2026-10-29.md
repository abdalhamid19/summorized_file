## النماذج وKimi Code

[جدول Kimi Code الرسمي](https://www.kimi.com/code/docs/en/kimi-code/models.html) يورد k3.1-pro وk3.1-pro-highspeed وk3 وk3-256k وkimi-for-coding ‏(K2.8 Preview) وkimi-for-coding-highspeed ‏(K2.7 Code Highspeed). Plus فأعلى لـ Code وPro فأعلى للنسخ عالية السرعة؛ K3 وK3.1 على Plus حتى 256K وفي Pro فأعلى حتى 1M داخل Code. تستعمل النسخة السريعة K3.1 ضعف الرصيد تقريبًا، وK3 1M ضعف K3 256K تقريبًا. نافذة السياق لا تساوي رصيدًا شهريًا.

الخطة الجديدة لها حد متحرك كل 5 ساعات وميزانية شهرية مشتركة، ولا حد أسبوعي؛ الخطط القديمة تحتفظ بالحد الأسبوعي. [قواعد Kimi Code](https://www.kimi.ai/help/kimi-code/benefits).

## قياس مستقل تقريبي غير مضمون

[قياس Wokey](https://wokey.ai/kimi-code-limits) يقدم قياسات لحسابات Kimi Code في الصين. لـ K3.1 Pro: خطة Max تعطي تقديريًا في نافذة 5 ساعات 11.8 مليون توكن إدخال غير مخزن أو 1.2 مليون توكن إخراج فقط؛ Pro نحو 3.3 مليون إدخال أو 347 ألف إخراج. أو تعني حالتين منفصلتين لا تجمعان. تقدير الشهر لنموذج Max نحو 12.5 نافذة إذا بقي الرصيد للاستخدام حصريًا في Code؛ النتائج تختلف وتبقى تجريبية، والمصدر يبيع خدمة منافسة وحدوده قابلة للتغير. المصدر يذكر أن دقة وزن المدخلات نحو ±20% وأن طلبات تتجاوز 256K لم تُقَس.
